## 建议结构

```
stm32/
├── README.md          # 本文件（你的模块说明）
├── firmware/          # STM32 固件工程（Keil/CubeMX）
│   └── ...            # 只提交源码+工程配置，别提交编译产物
└── screen/            # 淘晶驰工程导出/截图/说明（可放界面设计稿）
```

## 提交纪律（防仓库爆炸）
1. **编译产物别传**：`*.o / *.axf / *.hex(自动生成的) / Debug/ / Listings/` 等
   仓库根已有 `.gitignore`，如果某些文件还是被加了进来，右键文件 → 不跟踪即可
2. Keil 工程建议只传：`.uvprojx`、源码 `.c/.h`、需要的启动文件/库（体积大的库文件可以跟队长说一声放网盘，不硬塞 git）

## 与 FPGA 联调接口
- 数据协议：`../board/uart_protocol.md`（**v1.17**）—— 共享宪法，改前先全队说+升版本；§6 有常用帧速查表（含 TY=/扫频 0x8B）
- **FPGA 转发口(F1) 代码已完成(9/15)**：接线 N13(FPGA→STM32 RX) / R14(STM32→FPGA TX)，**460800-8N1**，数据与电脑侧完全一致（协议 §5）
- 固化新固件后即可真机联调；过渡期仍可用 `../board/sample_serial_log.txt` 喂屏测显示
