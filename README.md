# WaveCore

**基于 FPGA 的多功能信号测量与频谱分析系统**
A multi-function signal measurement & spectrum analysis system based on FPGA.

> 全国大学生嵌入式芯片与系统设计竞赛 2026 · FPGA 赛道（AMD）· 自主选题（初级组）
>
> **状态更新：2026-10-18** ｜ 串口 **460800-8N1** ｜ 协议 **v1.22**（命令 0x80~0x98）
>

## 一句话

一块 Artix-7，把 **信号产生 → 采集 → 参数测量 → 波形识别 → 频谱分析 → 可视化** 全部做进板内，
配合 PC 上位机呈现。**板内 DDS 经 DAC 输出、飞线回环到 ADC**，因此
**不接任何外部仪器也能完整自测**。

## 系统数据流（一条龙）

```
电脑(命令) ──串口下行──▶ FPGA
  ▲                          │
  │  DDS(NCO+正弦表) → 数字正弦 → DA(AD9708) → 模拟 → AD(AD9280) → 数字信号
  │                          │                 (DA→AD 回环 = 自测通道;
  │                          │                  外部信号也可直接从 AD 进)
  │                          ▼
  │              ┌─ 自动测量：频率(100Hz~1MHz<1%) + Vpp + 占空比/脉宽
  │              ├─ 波形识别：方波/正弦/三角（占比法 + 可信闸门）
  │              ├─ 频谱：厂商 IP 4096 点 ＋ 自研 1024 点（Hann 窗 + 抛物线插值）
  │              ├─ 触发采集（自由/上升沿/下降沿）+ 预触发（0/25/50/75%）
  │              ├─ 时基档位（0x8D）：同一信号换分辨率/量程
  │              └─ 波形上传(0x83) / 幅度谱帧(0x8E) → 上位机波形·频谱·瀑布图
  │                                   │
  └──────────────── PC 上位机 ◀───┘
```

## Features / 功能（均已上板验证 ✅）

| # | 功能 | 说明 | 验证数据 |
|---|------|------|---------|
| 1 | **DDS 信号源** | 32bit NCO + 正弦表；预设 100k/200k/500k/1M（按键/LED）；**任意频率 `0x85`（1Hz~12.5MHz）**；**双音合成 `0x87`** | 37.5kHz 自测 `F=0037500`；频率分辨率 **0.0116 Hz** |
| 2 | **ADC 采集** | AD9280（25MSPS）+ DA→AD 回环自测 | 回环 Vpp ≈ **5050 mV**（标定后） |

| 5 | **厂商 IP FFT** | **4096 点** @50kHz，Hann 加窗，双峰检测 | 1k+1.1k 双音分开：`S=1001 + A=1099` |
| 6 | **自研 FFT（对比）** | **1024 点 Radix-2 DIF**，`0x8A` 按需运行 → `SF=/S2=/S3=` 三峰行；[资源对比](report/resource_compare.md)：**502 LUT / 7 DSP** vs IP 1771 LUT / 9 DSP | 方波 `999 / 2998 / 4997`（真值 1000/3000/5000，**误差 <0.1%**） |
| 7 | **Hann 窗 + 抛物线插值** | 矩形窗频谱泄漏 **14.7% → 0.9%**（根除"假峰"）；峰值位置插值修正 **976Hz → 999Hz**（误差 2.4% → 0.1%） | `USE_HANN` / `USE_INTERP` 可回退 |
| 8 | **波形自动识别** | 占比法识别 方波/正弦/三角，输出 `TY=` 行（含**可信闸门**：测不准时报"其他"而非错误结论） | 五场景全对 |
| 9 | **触发采集 `0x89`** | 自由 / 上升沿 / 下降沿；**支持慢边沿**（v6.1 状态位"armed"检测）；帧首点＝触发点 | 1kHz / 100Hz 正弦均可触发 |
| 10 | **预触发 `0x8F`** | **0% / 25% / 50% / 75%** 四档；50% 时触发点落在数据帧**正中央**，可见触发沿之前的波形 | **四档逐点精确**（低电平点数 0/256/512/768，误差 0）；代价仅 +13 LUT / +29 FF / 0 DSP |
| 11 | **时基档位 `0x8D`** | **固件四档**：12.5k / 50k / 100k / 200k 等效采样率（decim 4000/1000/500/250）。⚠️ **上位机与演示只开放 T1(50k)/T2(12.5k)**，T3/T4 见下方"已知限制" | T1/T2 板测通过；换档后波形时间轴与频谱横轴同步变化 |
| 12 | **幅度谱帧 `0x8E`** | 512 点对数压缩幅度谱（518 B ≈ 11.2 ms）；上位机据此画**实时频谱 + 瀑布图** | 方波多柱 / 正弦单柱 / 扫频斜线，均正常 |
| 13 | **扫频 `0x8B`** | 1k→20k，步进 100Hz，50ms/步，循环（约 9.5s/圈） | 瀑布图呈斜线 ✅ |
| 14 | **波形上传 `0x83`** | 上传最近 **1024 点**波形；支持触发对齐与预触发回退 | PC 画出 1kHz 波形 ✅ |
| 15 | **资源与时序** | **LUT 7480 (36.00%) / FF 6521 (15.69%) / BRAM 11 (22.0%) / DSP 38 (42.22%)**；**WNS +1.128 ns**、WHS +0.041 ns，**0 失败端点** | 资源攻坚前 LUT 曾 **100.14% 超容**（见下） |

## 工程亮点（评审视角）

1. **同板双 FFT 对比**：厂商 IP（4096 点）与手写核（1024 点）并存，资源与精度**同口径**对比；
   自研核另做 IP 通路没有的两件事：**Hann 窗**与**抛物线插值**。
2. **测量通路与观察通路解耦**：频率计/波形识别直接测原始采集流，**不经时基抽取**；
   切换时基只改变"怎么看"，`F= / V= / D= / W= / TY=` 纹丝不动。
3. **资源攻坚**：实现阶段 LUT 一度 **20,829 > 20,800** 超容（只超 29 个就 `[DRC UTLZ-1]` 中止）。
   根因是 `fft_demo.v` 的 `f_ram`（4096×8）**从未进块 RAM** —— 读口的异步复位让 Vivado 放弃推断，
   退化成 32,768 个 FDRE + 4096:1 读 mux，独占全设计 86% LUT / 93% FF。
   改用教科书 SDP 模板后 **LUT 20,829 → 5,117（−75.4%）**。详见 `report/lut_slim_report.md`。
4. **四层数字抗噪 + 可信闸门**：不确定时输出"其他"，**不输出错误结论**。
5. **可复现**：所有结论都有脚本与数值金标准（`hw_analysis/`），协议帧全部过审计器。

## 怎么玩（快速上手）

**前置**：板子已固化 Flash，**插 USB 上电即出数据**（460800），无需 Vivado。

1. **接回环飞线**（DA 输出 → AD 输入），上电
2. 双击 `host/run_gui.bat` 打开上位机 → 应看到 `F=` `V=` `D=` `W=` `TY=` 实时刷新
3. **先设 1kHz**（上电默认是 100kHz 预设，而自研谱 fs=50kHz，100kHz 会混叠）：
   HEX 发 `5A A5 85 00 04 E8 03 00 00 74`
4. 常用命令（完整帧见 `board/uart_protocol.md` §4.1 与 §6 帧速查表）：

| 操作 | HEX 帧 |
|---|---|
| 设 1000Hz | `5A A5 85 00 04 E8 03 00 00 74` |
| 正弦 / 方波 / 三角 | `5A A5 88 00 01 00 89` / `… 01 8A` / `… 02 8B` |
| 触发：自由 / 上升 / 下降 | `5A A5 89 00 01 00 8A` / `… 01 8B` / `… 02 8C` |
| 请求 1024 点波形 | `5A A5 83 00 01 00 84` |
| 自研 FFT 运行 | `5A A5 8A 00 01 00 8B` |
| 扫频 开始 / 停止 | `5A A5 8B 00 01 01 8D` / `5A A5 8B 00 01 00 8C` |
| 时基 T1 / T2 | `5A A5 8D 00 01 00 8E` / `5A A5 8D 00 01 01 8F` |
| 预触发 0% / 25% / 50% / 75% | `5A A5 8F 00 01 00 90` / `… 01 91` / `… 02 92` / `… 03 93` |
| 幅度谱帧请求 | `5A A5 8E 00 00 8E` |
| 标定恢复默认（KN=37203） | `5A A5 8C 00 04 53 91 00 00 74` |
| 标定原始 LSB 透传 | `5A A5 8C 00 04 00 04 00 00 94` |

> ⚠️ **静默命令**（`0x8A / 0x8B / 0x8D / 0x8E`）**没有回显**，"发过去没反应"是正常的 ——
> 只能靠可观察量判断（谱峰 bin 号、波形周期数、瀑布图）。

5. 一键小工具（`host/`）：`run_gui.bat`（主界面）、`run_waterfall*.bat`（频谱/瀑布）、
   `run_check_interp.bat`（插值精度）、`run_check_pretrigger.bat`（预触发）、`run_link_scan.bat`（模拟链路频响）

## 已知限制（诚实说明）

| 限制 | 说明 |
|---|---|
| **时基只开放两档** | 固件实现四档（12.5k/50k/100k/200k），但 **T3/T4 在实机切换后无响应**、根因未定位，**已从上位机撤除**（2026-10-14）。详见 `report/t3t4_disable_2026-10-14.md` |
| **观察带宽 ≤25 kHz** | 自研谱 fs=50kHz，超过奈奎斯特（25kHz）会混叠。**频率测量本身不受此限**（100Hz~1MHz 误差<1%） |
| **波形 RAM 为单口** | 发送期间停止采集，存在"死区"；实测 **21.2 帧/s**（47.2ms/帧，效率 **91%**）。乒乓双缓冲可提升至 ~45 帧/s（见 `report/design_report.md` §9.1） |
| **模拟链路谐波衰减大** | 回环方波 3 次谐波实测 −30dB（理论 −9.5dB），**THD 演示不宜用回环方波** |
| 带内漂移 | 正弦占空比冷机 50% → 热机 46.8%（模拟链温漂），建议预热 3 分钟、以方波为基准 |

## How to Reproduce / 复现步骤

1. Vivado 2020.2 打开 `wavecore.xpr`（或按 `build/` 的 tcl 重建）
2. Add Sources：`src/*.v`；IP：`xfft_0`（4096 点 FFT）、`blk_mem_gen_0`（1024×8 波形缓存）、
   `blk_mem_gen_1`（自研 FFT 存储）、`hann_rom`、`ila_0`（`ILA_EN` 置 `1'b0` 可一键关闭）
3. 约束用 `board/wavecore.xdc`
4. 综合 → 实现 → 生成 bitstream → Program Device
5. 按"怎么玩"验证；若要断电自启，用 `build/gen_mcs.bat` + `build/program_flash.bat` 固化 Flash
