# 模拟链路频响实测（2026-10-01）

> 数据：`host/link_response.csv`（20 个频点）｜ 曲线：`host/link_response.png`
> 工具：`host/run_link_scan.bat`（板载 DDS 回环，**不需要外部信号发生器**）
> 原始记录：2026-10-01 23:06

## 一、结论（一句话）

**模拟链路 -3 dB 带宽 > 1 MHz。** 100 Hz ~ 1 MHz 全程 Vpp 稳定在 **1078 ~ 1093 mV**（波动 < 1.4%），
**1 MHz 处相对低频仅衰减 0.06 dB** —— 到扫描上限（1 MHz）都没能测到滚降点。

| 频段 | 实测表现 |
|---|---|
| 100 Hz ~ 5 kHz | Vpp = 1085 mV（基准），频率读数精确 |
| 10 kHz ~ 500 kHz | Vpp = 1085 ~ 1093 mV（**±0.06 dB 以内**） |
| 1 MHz | Vpp = 1078 mV（**−0.06 dB**） |

## 二、为什么这个结论重要（三个直接影响）

1. **T4 档（0x8D sel=3，fs=200 kHz，频谱覆盖 0~100 kHz）站得住**。
   100 kHz 远在链路平坦区内 —— 它不是"把一段噪声放大给人看"，而是**真实的带宽扩展**。
   （此前基于"方波 3 次谐波 −30 dB"的担心，实测被推翻：那条现象来自**信号源合成的方波本身谐波就少**，
   不是链路带宽不足。）
2. **频谱分析的量程上限由数字侧决定，不由模拟侧决定**。
   瓶颈不在硬件，而在"我们愿意把抽取比降到多少"（当前最低 decim=250）。
3. **给下一步留了空间**：若将来需要覆盖 0~200 kHz，可再加 decim=125 档（fs=400 kHz），
   链路平坦度支持这么做（本表 1 MHz 仍平坦）。

## 四、测量方法（为什么这份数据可信）

- **信号源**：板载 DDS 输出**正弦**（TY=1），不接外部仪器 —— 避免外部线缆/接头引入的频响
- **测量通路**：`freq_meter` / Vpp 走 **25 MSPS 原始 ADC 流**，**不受 0x8D 抽取比影响**
  → 它反映的是**真实模拟链路**（DAC 输出 → 回环线 → ADC 前端），与 FFT 通路的等效采样率无关
- **取数**：每频点稳定 0.4 s、采集 0.8 s（约 120 帧），取 Vpp 中位数（抗噪）
- **频率读数交叉验证**：1 kHz~1 MHz 逐点精确，说明信号源与测量均在规格内

## 五、两个附带发现（诚实边界，也是报告素材）

### 5.1 100 Hz 点的频率读数异常（报 1000 Hz）

- 现象：设定 100 Hz 时，实测报 1000 Hz（其余 19 个频点全部精确）。
- 原因：低频段测量窗更长（`1/(10ms + 32/f)`，100 Hz 时约 330 ms），脚本只稳定 **0.4 s**
  → 窗口尚未收敛，读到的是上一个频点（1 kHz）的残留。
- 处理：复验低频时把 `SETTLE_SECONDS` 加大到 **1.5 s**（脚本里可调）；
  **不影响 LF 段结论**（100 Hz 的 Vpp 与频率无关，Vpp 值仍可信）。

### 5.2 ≥ 10 kHz 后波形识别 TY 不稳定（0/3 交替）

- 现象：≤ 5 kHz 稳定报 **1（正弦）**；10 kHz 起在 **0（方波）/ 3（其它）** 之间跳。
- 原因：① 高频时一个识别窗内的采样点变少；② DDS 正弦在高频被量化成阶梯状（1 MHz 时约 50 点/周期），
  过零占比法容易误判。
- **这正是"可信闸门"的设计意图**：判不准时报 3（"其它"），**宁可不说，也不说错**。
- 报告里的表述建议：*"波形识别在 ≤5 kHz 五场景实测全对；≥10 kHz 时因采样点密度下降而进入'其它'态，
  这是刻意设计的安全行为。"*
