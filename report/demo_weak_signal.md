# 微弱信号演示：现场怎么走

> 双击 `host/run_demo_weak.bat` 即可跑完全程，约 2 分钟。
> 脚本会自动打印每一步的数据和最后的结论表。

## 一、这个演示要证明什么

一句话：

> **信号埋在噪声底下、常规方法读不出来的时候，这台仪器还能测。**

不是"测得更准"，是"换了一种看法"：

- 峰峰值检波问的是「最高的点有多高」—— 噪声的最高点当然很高；
- 锁相放大问的是「和参考同频的那部分有多少」—— 噪声没有固定频率。

## 二、为什么不用真传感器

现场要证明的是"能从噪声里捞出来"，不是"传感器好不好"。

用内部 DDS 产生已知幅度的信号，**真值可控**，才能当场算出误差。
接真传感器反而没有真值，只能看"稳不稳"，说服力更弱。

> 接传感器的方法见 `sensor_frontend_guide.md`。接上之后本脚本同样适用，
> 只是信号源换成传感器 —— 但那时就没有精确真值了，只能讲"稳不稳"。

## 三、现场怎么操作

### 准备

1. 板子通电，USB 接电脑
2. 关掉上位机（否则串口被占用）
3. 双击 `host/run_demo_weak.bat`

### 三步走

脚本会停下来等你按回车，每步之间可以讲解。

**第 0 步：干净信号（约 10 秒）**

```
基准   真值 4868 mV
  直接测量  4868 mV   误差    +0%
  锁相放大  4820 mV   误差  -1.0%
```

讲："两种方法在这时候都准。这只是确认仪器本身是好的。"

**第 1 步：信号功率 = 噪声功率（SNR ≈ −0.6 dB）**

```
真值 617 mV
  直接测量  1380 mV   误差  +124%   ← 读数不可信
  锁相放大   598 mV   误差  -3.1%   ← 仍然准确
```

讲："信号和噪声一样大。直接测量已经偏了一倍多，因为峰峰值检波量到的主要是噪声。"

**第 2 步：再差 18 dB（SNR ≈ −18.8 dB）**

```
真值 290 mV
  直接测量  3487 mV   误差 +1102%   ← 读数不可信
  锁相放大   288 mV   误差  -0.8%   ← 仍然准确
```

讲："信号只有噪声功率的 1/76。直接测量偏了 12 倍，完全不能用了；
锁相还是准的，误差不到 1%。"

**结论表（脚本自动打印）**

```
  直接测量  3487 mV  （真值 290 mV）
  锁相放大   288 mV  （真值 290 mV）
  误差相差 1331 倍。
```

## 四、评委可能问的问题

**Q：为什么信号要衰减？**

> 不衰减信号会顶到量程。满幅信号一叠噪声就削顶，削顶是信息的丢失，
> 锁相也救不回来（实测满幅加噪锁相偏 −21.9%）。
> 真实场景里微弱信号本来就不会顶满量程，所以先衰减更贴近实际。

**Q：锁相的代价是什么？**

> 三个：① 必须有同频参考（本质是"知道要找什么频率"）；
> ② 积分时间换信噪比，32 周期 @1kHz = 32ms；
> ③ 只能处理周期信号，噪声、瞬态、调制信号都锁不住。

**Q：能到多深？**

> 实测到 −18.8dB，误差 −0.8%。理论上再加积分周期还能往下，
> 但要牺牲响应速度。我们没继续往下推，因为已经超出演示需要。

**Q：这个和普通示波器有什么区别？**

> 普通示波器也能做平均，但那是"整段平均"，对周期性噪声无效。
> 锁相是"按频率挑"，只挑和参考同频的那一份，噪声无论多大都会被积分掉。

## 五、卡住了怎么办

| 现象 | 原因 | 处理 |
|---|---|---|
| 脚本报"读不到 V= 行" | 串口没打开 | 关掉上位机，或传端口参数 `run_demo_weak.bat COM3` |
| 第 0 步数字就不对（不是 4868） | DDS 回环线松了 | 检查板上 DA→AD 的连线 |
| 锁相读数一直是 0 | 锁相没开 | 脚本开头发了 `0x9A=1`，若仍为 0 检查 `lockin_core.v` 使能 |
| 噪声开了但读数不变 | `0x99` 没生效 | 先发 `0x9C` 设周期，再发 `0x99`（顺序有讲究，实测过） |
| 满幅时锁相偏很大 | 削顶 | **正常现象**，见第四节第一条 |

## 六、如果接了真传感器

`report/sensor_frontend_guide.md` 里写的是完整方案，要点：

- MAX9814 输出带 **1.25V 直流偏置**，必须先隔直（10µF 电容）；
- 安静房间输出约 50mV 峰值，**需要 17~70 倍放大**才能用满量程；
- 目标峰值 3.5V（70% 量程，约 96 码）。

接线之后，把本脚本的信号源换成传感器，**但不要再用"真值"那一栏**——
传感器的真实幅度不知道，只能对比"直接测量乱跳 vs 锁相稳定"。
