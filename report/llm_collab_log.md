### 2026-09-02 #002 · 任务：核对板级硬件数据（时钟/引脚/官方 AD-DA 例程）

- **日期/时间**：2026-09-02 11:32
- **本次目标**：把方案落实到真实管脚——确认系统时钟、复位、LED/KEY/串口、ATK_HS_AD_DA 模块管脚、XADC 管脚
- **我的提示词**：
  > 我先把板子的各种数据给你（达芬奇Pro 底板/核心板原理图 PDF + IO 引脚分配表 xlsx），你说要出真波，那你就改方案就行……
- **模型回答要点**：
  1. 系统时钟 sys_clk=R4（50MHz），复位 sys_rst_n=U7（低有效）
  2. USB 串口（CH340）：uart_rxd=E14 / uart_txd=D17；ATK 模块口：uart2_rxd=E13 / uart2_txd=D16
  3. 官方例程 29_hs_ad_da（资料盘 35t.zip）XDC：da_data[7:0]=C19 C18 B16 B15 C15 C14 B13 C13，da_clk=B20；ad_data[7:0]=B22 C22 B21 A21 D14 D15 E16 D16，ad_clk=D20，ad_otr=C20（LVCMOS33）
  4. XADC：XADC_VP=L10 / XADC_VN=M9（底板排针经 49.9Ω）
  5. 官方例程为 Vivado 2020.2 工程，2020.1 打不开 prj，但源码/XDC 可直接参考
- **我的验证/自我纠错轨迹**：
  1. 三张原理图 PDF 用 pypdf 提取文字，与 xlsx 引脚表逐项交叉核对（led/key/beep/uart 一致）
  2. 发现 ad_data[0]=D16 与 uart2_txd、ad_data[1]=E16 与 gbc_key 管脚重叠 → 确认"插高速 AD/DA 模块时禁用 4 针 ATK 模块口"，写入 pin_map.md 注意事项
  3. 表格文件解析通道失败后改用 openpyxl 本地直读（已向用户说明降级原因），数据与原理图文字互相印证
- **结论**：采纳，已写入方案"十、硬件实测信息"与 board/pin_map.md
- **沉淀技能包**：是（候选：xlsx 解析通道不可用时的降级流程；官方 XDC 优先于自制）
