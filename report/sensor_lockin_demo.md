# 用传感器演示锁相放大 —— 完整操作单

> 目标：拍出 17 秒，让评委看到**同一段声音，Vpp 读数被噪声抬高好几倍，锁相读数几乎不动**。
>
> ⚠️ 注意：Vpp 的"抖动"没有想象中大。仿真（`hw_analysis/sim_vpp_noise.py`）显示
> 抖动只有 9~13%，肉眼看不明显；**真正看得出来的是均值被抬高 2~3 倍**。
>
> **不用焊运放。** 你的模块自带 40/50/60 dB 增益，再串一级运放只会饱和。

---

## 一、为什么可以不焊

你的模块（MAX9814 类）输出规格：**2 Vpp max、DC offset 1.25 V、三档增益**。

把它直接接到 AD 模块输入端，先算清楚 ADC 看到多少：

| 距离 | 模块输出 | ADC 码数（1 码 = 36.33 mV） |
|---|---|---|
| 20 cm | ~1000 mVpp（AGC 压平） | 28 码 |
| 50 cm | ~600 mVpp | 17 码 |
| 1 m | ~350 mVpp | 10 码 |
| **2 m** | **~225 mVpp** | **6 码** |
| 4 m | ~112 mVpp | 3 码 |

**参考锚点**：锁相在 **290 mV（8 码）** 时实测误差 0.8%。
所以 2 m 那个位置信号刚好压在下限附近 —— **正适合演示**。

**1.25 V 直流偏置要不要挡？**

不用。理由三条：

1. AD 模块量程 ±5 V，**2.25 V（1.25 + 1.0 峰值）远在安全区**
2. Vpp 测的是**峰峰值**，直流被减掉了
3. 锁相是**交流解调**（和 sin/cos 参考相乘），直流分量积分为零

真要追求完美可以串一只 1µF，但**不串也能演示**。

## 二、接线（5 分钟，全程不用焊）

```
   手机/音箱                 MAX9814 模块              板子
  ┌────────┐              ┌──────────────┐        ┌──────────────┐
  │ 播 1kHz │  ~~~~声音~~~~ │ MIC          │        │              │
  │  正弦   │              │ OUT ─────────┼────────┤ AD 输入端     │
  └────────┘              │ GND ─────────┼────────┤ GND          │
                          │ VDD ─────────┼────────┤ 3.3V / 5V    │
                          │ GAIN  悬空    │        │              │
                          └──────────────┘        │  ✂ 回环飞线   │
                                                   │    必须拔掉   │
                                                   └──────────────┘
```

**四条线，全是杜邦线或鳄鱼夹：**

| # | 从 | 到 | 备注 |
|---|---|---|---|
| 1 | 模块 OUT | AD 模块输入端 | 信号 |
| 2 | 模块 GND | 板子 GND | **必须共地，少这条全乱** |
| 3 | 模块 VDD | 板子 3.3V 或 5V | 看模块标注 |
| 4 | 模块 GAIN | **留空** | 悬空 = 60 dB 档 |

**另外：拔掉 DA→AD 的回环飞线。** 不拔的话，DDS 的信号会和麦克风的信号叠在一起。

## 三、上位机设置（这一步容易漏）

打开 `host\run_gui.bat`，然后：

| 项 | 设成 | 为什么 |
|---|---|---|
| **DDS 频率** | **1000 Hz** | ⚠️ **锁相的参考频率来自 DDS 的 fcw**，不设对就锁不上 |
| 时基 | T1 | 50 kHz 采样，1 kHz 有 50 点/周期 |
| 波形 | 无所谓 | 不从 DDS 出信号，它只当参考 |
| 锁相积分 | 32 周期 | 默认值，够用 |

**⚠️ 两个坑：**

**① 板内噪声注入（0x99）对外部传感器无效。**
`sig_noise` 接在 DDS 之后、DAC 之前，只给**回环通路**加噪，不进 ADC。
所以别指望 `0x99` 帮你制造噪声 —— **信噪比完全由真实环境决定**。

**② 锁相参考是 DDS 的相位，不是从信号里提取的。**
所以声源必须**确实是 1 kHz**。手机播 1000 Hz 就是 1000 Hz，很准。

## 四、怎么让 Vpp 读数被抬高

这是整个演示最难的一步。**信号不弱，Vpp 就不会跳。**

按可控性排序，三个办法：

### 办法 A：拉远（最简单，效果一般）

从 20 cm 慢慢拉到 3~4 m。
- 20 cm：Vpp ≈ 1000 mV，稳
- 1 m：Vpp ≈ 350 mV，开始抖
- 3 m：Vpp ≈ 150 mV，开始被噪声主导

**缺点**：房间不够大就拉不开，而且走动会挡声。

### 办法 B：旁边加噪声源（推荐）

麦克风不动，**在旁边放第二个声源**：

- 手机播白噪声 / 吹风机 / 风扇
- **最简单：让旁边同学说话**

这样信号（54 dB SPL）和环境噪声（60 dB SPL）接近甚至反转，
Vpp 读数立刻被抬高（可能从 220 涨到 500~800），而锁相只认 1 kHz，基本不动。

### 办法 C：两个手机一起播（最可控）

```
手机 A：播 1000 Hz 正弦     → 这是信号
手机 B：播白噪声 / 音乐     → 这是噪声
```

两个都放在麦克风附近，**音量调 B 略大于 A**。

这样信噪比完全由你控制，随时能复现。**录制建议用这个。**

## 五、录制流程（17 秒）

打开 `host\run_sensor_monitor.bat`，屏幕会实时刷新：

```
  频率      F =   1001 Hz      波动 ±    1 Hz
  峰峰值    V =   1716 mV      波动 ±  212 mV    ██████████████████████████
  锁相      L =    419 mV      波动 ±    1 mV    ··························
                                            └─ 横条长度 = 波动大小，同一个标尺

  稳定度对比：Vpp 波动是锁相的 107.4 倍
  ✓ 这个比值就是演示要看的东西 —— 越大越有说服力
```

**按这个节奏拍：**

| 时间 | 动作 | 画面该有什么 |
|---|---|---|
| 0–3 s | 全景：麦克风 + 两个手机 | 看得到接线 |
| 3–8 s | 开噪声（手机 B），**关锁相**（按 `L`） | **Vpp 那条横条拉满，锁相显示"已关闭"** |
| 8–14 s | 按 `L` 开锁相 | **锁相横条缩成一条线，Vpp 还在跳** |
| 14–17 s | 停住，让观众看清对比 | 按 `S` 留快照 |

**关键：第 3–8 秒和第 8–14 秒要连着录，中间不要停。**

## 六、判断成功没有

看屏幕上这一行：

```
稳定度对比：Vpp 波动是锁相的 XX 倍
```

| 倍数 | 说明 |
|---|---|
| **> 20 倍** | ✓ 效果很好，直接能用 |
| 5~20 倍 | 可以，但可以再拉远一点 |
| < 5 倍 | 信号还不够弱，加噪声 / 拉远 |

**如果锁相读数也大幅跳动**（不是 Vpp 变，是锁相自己不稳）：
- DDS 频率没设成 1000 Hz → 回到第三节
- 声源不是 1 kHz → 换个音源
- 积分周期太短 → 用 `0x9C` 改成 64 或 128

---

## 七、拍不出来怎么办

**降级方案：不加噪声，只演示"幅度稳定"**

即使 Vpp 没被明显抬高，只要锁相读数和 Vpp 读数**一致**，也能说明锁相接得对、算得对。
视频里那 17 秒可以改成：

> "真实麦克风接入，锁相给出和峰峰值一致的幅度读数 —— 说明前端和算法都通了。"

**但这样说服力弱很多。** 评审说的"评分提升最大的一条"，指的就是"Vpp 失效而锁相有效"那一刻。

```
① 手机放远      50dB 档 + 手机退到 4~5 米

```

**推荐 ①，不动机器。**

```
□ GAIN 接 GND（50dB），不要悬空（60dB 太强）
```
