# 队友2 任务书：STM32 转发 + 淘晶驰串口屏 v1

> 前置：拉 GitHub wavecore 仓库（board/uart_protocol.md v1.2 + board/sample_serial_log.txt）
> 你的数据源 = FPGA 发的一行行文本（同队友1），你把它转发给屏显示。

## 一、整体链路（你要实现的一环）

```
FPGA ──UART(N13/R14, 待我接好, 波特率460800(协议v1.8))──▶ STM32F407
                                                   │ 解析+重组
                                                   ▼
淘晶驰串口屏 ◀──UART(屏口)── STM32
```

- 你**不碰 FPGA 代码**；你写 STM32 固件 + 淘晶驰屏界面
- 数据长什么样：`F=0001000Hz V=133` / `S=0001001` / `A=0001099`（见 sample 日志）

## 二、本周（9/5~9/12）你要做的 3 件事

### 1. 串口屏界面（可以马上做，用假数据先练）
淘晶驰开发工具（USART HMI 等，资料盘/官网有）：
- [ ] 建工程，放**三屏**：
  - 屏1 首页：标题 + 连接状态灯
  - 屏2 测量页：频率 F 大字、Vpp 大字、谱峰 S / A（各一个文本控件）
  - 屏3 控制页（先预留，等命令链路通再加按钮）
- [ ] 学会"往屏发一条文本就刷新"（如 `t0.txt="1000"` 这种指令）
- [ ] 用串口助手把 sample_serial_log.txt 里的行手发到屏，验证能显示
> 不需要真机：屏的 USB 口插电脑就能当"另一个串口屏"调试

### 2. STM32 转发固件框架（等 FPGA 转发口 F1，先写骨架）
- [ ] 配置 2 个 USART：A口接FPGA(**460800**-8N1, 协议v1.11)、B口接屏（波特率照屏的默认）
- [ ] A口收到一行(以 \r\n 结束) → 原样/加工 → B口发给屏
- [ ] 新手路线：先"收到就转发"(透传)跑通，再学解析按字段显示

### 3. 环境与学习
- 需要：STM32F407 开发环境(Keil/STM32CubeMX 任一) + 板子 + USB-TTL
- 建议学习关键词："STM32CubeMX USART 中断接收"、"淘晶驰 串口屏 指令 教程"

## 加分项（9/20 新增建议）：串口屏"频谱柱/瀑布"
- 数据来源：F1 转发口镜像流里的 `S=/A=`（频谱柱）——全部现成，**FPGA 无需改动**
- 屏端做法：定时器每 100ms 取一次主峰，循环填充柱状控件即可形成"频率-时间"滚动效果
- 注意：双音时 S/A 可能互换（协议 v1.11 起有说明），排序显示更稳
