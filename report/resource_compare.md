# 自研 FFT vs Xilinx xfft IP —— 资源与性能对比表（V1）

> 数据来源：Vivado 2020.2 实测（`util_hier.rpt` 综合后层级利用率 + `board_top_utilization_placed.rpt` 布局后）
> 日期：2026-09-20 ｜ 器件：XC7A35T-2FGG484 ｜ 时钟：50MHz

## 一、裸核对比（同口径：仅 FFT 核本体）

| 指标 | **自研 self_fft_1024** | **Xilinx xfft_0 (IP)** | 对比 |
|---|---|---|---|
| 点数 N | 1024 | 4096 | 1/4 规模 |
| LUTs | **502** | 1,771 | 自研 ≈ 28% |
| FFs | **346** | 2,550 | 自研 ≈ 14% |
| BRAM | 1×RAMB36 + 2×RAMB18 | 11×RAMB18 | 自研 ≈ 17%（按 36Kb 折算）|
| DSP | **7** | 9 | 相当 |
| 分辨率 (fs=50kHz) | 48.8 Hz | 12.2 Hz | 与 N 成比例（预期）|
| 每点资源 (LUT/点) | 0.49 | 0.43 | **同量级 → 手写质量达标** |
| 算法 | Radix-2 DIF 原地（自研 RTL） | Radix-4 Burst / BFP | 架构不同 |
| 控制复杂度 | 单 FSM 约 250 行（含等待时序）| IP 封装（黑盒参数化）| 自研全透明可讲解 |

## 四、结论与报告话术
1. **"轻量自研核"成立**：以 **502 LUT / 7 DSP** 实现 1024 点 FFT，资源约为 IP 裸核的 1/3（LUT）与 1/6（FF）
2. **"每点资源同量级"**：LUT/点 0.49 vs 0.43 → 证明手写 radix-2 的工程效率与厂商 IP 同一档
3. 代价：**分辨率 48.8Hz vs 12.2Hz**（点数减 4 倍的自然结果），且 2 拍 BRAM 读延迟需全链路对齐（SK-025）
4. 答辩建议：**"厂商 IP 保功能、自研核证功力"**——两张表并排放，一页讲完创新 30% + 资源 20%
