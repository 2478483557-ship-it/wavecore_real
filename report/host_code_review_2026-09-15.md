## 建议修改（按优先级）

### P0（小 bug / 兼容性）
1. **S 行到来时清空 A**（`wavecore_gui.py` 600-604 行）
   问题：双音时 A 行并非每帧都有，S 一来就把 A 显示清成 `-- Hz`，界面会闪、A 大部分时间为空。
   建议：**不要**在 S 时清 A；仅当"A 超过 1 秒未更新"或"主频变更"时清除（或干脆保留上次值）。
2. **波形点数硬编码 1024**（`protocol.py` 153 行）
   问题：固件将来若改点数（或换 512/256 版本）会直接报错。
   建议：改为按帧头 LEN 自适应（≥2 点即可画），仅提示"期望1024"。
3. **无帧头又无换行时缓冲无上限**
   建议：`StreamParser` 加保护——缓冲超过 8KB 且找不到帧头/换行时丢弃前半并回一个 `protocol_error`。

### P1（体验，演示加分）
4. 双音模式下 F 会因拍频晃动 → 面板角落加提示"双音:F 仅供参考，以 S/A 为准"（答辩很有用）。
5. 波特率写死 115200：我们正在做"串口提速"（P0 清单），建议 GUI 留一个波特率下拉（115200/460800/921600）。
6. 波形刷新可用 `set_data` 替代 `clear+plot`；若后续要连续刷新，换 pyqtgraph 更丝滑。

### 无需改
- CSV 用 `utf-8-sig`（Excel 中文友好）✓；线程安全（UI 变量只主线程碰）✓；断开重连逻辑 ✓
