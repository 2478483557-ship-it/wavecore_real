## 四、三处缺口的严重程度

### ★★★ 缺口 1：2.3.2 缺函数流程图与输入输出变量（**硬要求**）

**原文要求**：
> 2.3.2 软件各模块介绍（根据总体框图，给出各模块的具体设计说明。
> **从顶层到底层逐次给出各函数的流程图及其关键输入、输出变量**）

**现状**：12 个模块都有文字说明，写得也不薄（比如自研 FFT 那段把蝶形、旋转因子、L1 模都讲了）。
但缺两样东西：

1. **没有一个流程图** —— 要求明确写"各函数的流程图"
2. **没有"关键输入、输出变量"的明确标注** —— 现在散落在正文里，没有成表

**影响**：评委会对照模板逐项打分，2.3.2 是明确列出的子项，缺流程图属于"没按要求写"。

**补法**（工作量约 2~3 小时）：
给 5 个核心模块各画一张流程图，并在每张旁边标输入输出：

```
建议选这 5 个（覆盖数据主链路）：
  ① 命令解码 cmd_decoder      输入：串口字节流    输出：参数寄存器组
  ② 信号发生 dds_nco          输入：FCW/波形选择   输出：DA 数据
  ③ 采集与抽取 ad_driver      输入：ADC 8 位      输出：缓存样点
  ④ 自研 FFT self_fft_1024    输入：1024 点样点    输出：SF/S2/S3
  ⑤ 锁相放大 lockin_core      输入：I/Q 参考      输出：I/Q 累加值
```

再加一张上位机的数据流图（串口线程 → 解析 → 事件队列 → 界面刷新）。

### ★★ 缺口 2：2.2.3 缺电路原理图/PCB（**次要但明显**）

**原文要求**：给出"电路图、SCH 原理图、PCB 版图等截图，并标记出关键的输入、输出信号线"。

**现状**：只有一张板卡实物照，文字描述了 4 个接口。
问题是**这是成品开发板**，没有自绘的 PCB。

**补法**（工作量约 1 小时）：
两个选择：
- **A（推荐）**：画一张"接口连接示意图"——用方框和箭头标出
  AD9280 ↔ FPGA 的 8 位数据线、25MHz 时钟方向、DA9708 的锁存时钟、
  CH340 的 TX/RX、按键 LED 的引脚。这实质上是"模块级电路框图"，
  能替代"原理图"回应这一条要求。
  **并在正文加一句**："本作品使用成品开发板，未自行绘制 PCB；
  接口级连接关系如下图。"
- **B**：从开发板资料里找官方原理图截图（如果有）

> **诚实说明比硬凑图好。** 评委能看出来是不是自己画的 PCB。

```
命令解码 cmd_decoder   →  串口字节流 → 参数寄存器组
信号发生 dds_nco       →  fcw/wave_sel → da_data → AD9708
采集抽取 ad_driver     →  ad_cap → 中值滤波 → 抽取 → 1024 点缓存
自研 FFT self_fft_1024 →  1024 点 → 加窗 → 10 级蝶形 → 三峰 + 插值
锁相放大 lockin_core   →  I/Q 相乘 → 整周期累加 → i_out/q_out/n
上位机数据流           →  串口线程 → 事件队列 → Tkinter 主线程
```

"关键输入、输出变量"。
