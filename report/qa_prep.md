## 〇、一页速答卡（背下来）
| 问题 | 一句话答案 |
|---|---|
| 为什么用 FPGA？ | 测量/触发/FFT/识别全在 PL 侧硬件流水线并行跑：时延确定（纳秒级）、触发逻辑可自定义、系统可重构——MCU 轮询与商用仪器都给不了 |
| 和商业示波器/频谱仪区别？ | 我们把"信号源+测量+频谱+识别+扫频"做成一机、**断电即用**；且测量/识别算法完全自主可控、可随题改（开源级复现）|
| 自研 FFT 和 IP 差在哪？ | 同点数口径：**502 LUT/7 DSP（1024 点）** vs IP 1771 LUT/9 DSP（4096 点）；每点资源同量级（0.49 vs 0.43 LUT/点），运算 ~1ms@50MHz |
| 精度怎么保证？ | 回环自测 + PC 交叉验证 +（11 月）外部仪器标定；方波 1k~1M：F/D/W 逐项精确；正弦受模拟前端限制，指标以方波为准并标注 |
| 三种波形 Vpp 为什么不一样？ | 已统一：方波电平原来**写死在 RTL 里**是 `26/230`（Vpp 204 LSB），正弦表是 `1/255`（Vpp 254 LSB）-> 所以正弦 1085mV、方波 882mV。改成与正弦同幅的 `1/255` 后三者一致 |
| 自研 FFT 为什么报过"两个峰"？ | 自研通路原先**只加矩形窗**，1kHz 落非整数 bin 20.48，bin24 泄漏 13.6% 越过 12.5% 门限 -> 假峰。**已加 Hann 窗（根因修复）**，泄漏降到 0.9%（16 倍余量），正弦恢复单峰。仿真抓不到是因为它的激励正好落在整数 bin、泄漏恰为 0（SK-034）。**注意**：频谱图上主峰旁边仍会有"一片越来越矮的柱子"（主瓣+裙边），那是正常泄漏，不是杂波 |
| 资源怎么从超容优化到 24.6%？ | 定位到 `fft_demo.v` 的 `f_ram`（4096×8）**从未进块 RAM**——读口的异步复位让 Vivado 放弃推断，退化成 **32768 个触发器 + 4096:1 读 mux**，独占全设计 86% LUT / 93% FF。改教科书 SDP 模板（读口去异步复位）后 **LUT 20,829(100.14% 超容) → 5,117(24.60%)**，WNS 反升到 **+2.087ns**；闭环证据 = 原语类型由 `FDRE` 变 `RAMB36E1`（SK-029）。**最新构建（2026-10-02）**（在资源攻坚 + Hann 窗/ILA/统一 Vpp 之上，再叠 **0x8E 幅度谱帧 / 时基四档 0x8D / 频谱抛物线插值**）= **LUT 7050(33.89%) / FF 7326(17.61%) / BRAM 11(22.0%) / DSP 35(38.89%)，WNS +1.953ns**（资源增加了，时序反而比上一版好 0.118ns）|
| **时基档位是干嘛的？** | 四档等效采样率 12.5k/50k/100k/**200k Hz**（`0x8D` 切换）：同一台仪器在"看细节"（T2，Δf=12.2Hz）与"看宽范围"（T4，频谱覆盖 0~100kHz）之间切。**代价是物理定律**：点数固定 1024 时，范围 × 分辨率 = 常数 |
| **0.1% 的频率精度怎么来的？** | **抛物线插值**：把峰值的左右邻 bin 幅度代入 δ=0.5(c-a)/(2b-a-c)，把整数 bin 的量化误差（±24Hz）压到约 ±1Hz。上板实测 **999 / 2998 / 4997 Hz**（真值 1000/3000/5000），与数值模型逐字吻合；整数 bin 时 δ=0 逐字不变（天然负向对照）|
| **瀑布图的数据从哪来？** | FPGA 侧新增 **0x8E 幅度谱帧**：512 个 bin 的对数压缩幅度（17bit→8bit，动态范围约 96dB），**518 字节一帧、11.2ms 传完**，可 10~20 帧/s 连续请求；上位机边收边画，扫频时就是一条斜线 |

## 一、必答题（评委高频）
**Q1 你们和 STM32/PC 方案的本质区别？**
A：三件事：①**并行**——测频/占空比/脉宽/FFT/串口在 50MHz 下同时跑；MCU 是排队执行。②**确定性**——25 点/µs 的采样与 20ns 分辨的时间戳，中断方案做不到。③**可重构**——触发逻辑、识别算法、扫频节奏都是"我们造的电路"，赛场上可现场改。

**Q2 测量精度怎么保证？对标过什么仪器？**
A：见 `accuracy_calibration.md`。现阶段：自环回 + PC 抓图交叉（如 Vpp 读数与 PC 侧抓图逐窗一致）；指标：方波 1k/100k/1M 的 F 逐字精确、D=49.9~50.4%、W=500µs/6µs；11 月用外部信号源/示波器补正式标定表（预留行已建）。

**Q3 "抗噪"具体几层？各解决什么？**
A：四层递进（详见 `denoise_experiments.md`）：①穿越+重武装"连续 2 拍确认"治正弦 ×2 假穿越；②占空比施密特迟滞治毛刺切碎时段；③5 点中值滤波（9 比较器）清 ≥2 拍尖刺（V:201→140 三步证据）；④窗口级 3 窗中值拒绝偶发坏窗（修后 100kHz 方波 V 恒定、D 稳 050.x）。

**Q4 自研 FFT 是"高性能"实现吗？**
A：诚实说——**它是"正确性优先"的迭代式设计**：运算 ~1ms/帧@50MHz，全链路 21ms（其中 20.5ms 是 50kHz×1024 的采集窗，任何实现都躲不开；对比 IP 4096 链路采集窗 82ms）。价值在于**完全掌控定点精度与资源**（502 LUT/7 DSP），并与 IP 做了同口径对比。

**Q5 为什么不做 4096 点自研？**
A：两个原因：①主设计**当时** LUT 已 95.5%（现已优化到 24.6%，详见 `lut_slim_report.md`），当时不冒险加塞；②对比采用"**同口径独立综合**"（自研 4096 版 OOC 数据 vs xfft 裸核），公平且零风险。（若评委追问"想不想做"：RTL 参数化扩展 +4~5 BRAM/+~100 LUT 即可，蝶形核不随 N 增长——**且现在资源余量已从 0 变成 75%，完全放得下**。）

**Q6 460800 波特率够吗？刷新率多少？**
A：见 `bandwidth_budget.md`：460800-8N1≈45kB/s；测量帧 45B/10ms（≈4.5kB/s，占 10%）；波形帧 1022B/22ms；S/A 行 22B；**Spectrogram 以 10~100Hz 取 S/A 完全可行**。不做整段频谱上传（4096B/帧≈89ms）是**带宽-信息量的主动取舍**。

**Q7 波形识别准确率？**
A：方法=占比法（近极端占比：方波≈100%/正弦≈46%/三角≈25%）+ 双闸门（>25kHz 混叠或频率波动>1.5% 时报"其他"）。实测五场景全对：1k 正弦/方波/三角=1/0/2；混叠、双音=3。**宁可不给结论也不给错误结论**是设计原则。

**Q8 温漂（正弦 D 从 50 掉到 46.8）怎么解释？**
A：模拟链路热平衡现象（SK-028）：冷机 50.0%/V≈140 → 热机 46.8%/V≈153（当时 `V=` 是 LSB 口径；v1.17 起为 mV，140 LSB ≈ 1094 mV）；方波免疫（只看时序对称）。处置：预热 3 分钟 / 方波做基准 / 终验外部源标定。**我们把它写进了报告案例，而不是藏起来。**

**Q9 数据可信度？（"怎么证明不是碰巧"）**
A：方法论：**"复现硬件式仿真"**——把硬件异常数字当假设变体建模，逐字复现即定案（如 BRAM 2 拍延迟案：1k/2k 两组数据 [1367,1318,1709]/[2686,3369,8740] 完全一致）。全过程沉淀 38 条技能包。

**Q10 为什么单通道/8bit ADC？（初级组定位）**
A：题目定位"口袋仪器"：8bit@50kHz 回环覆盖 100Hz~1MHz 测量与 ≤25kHz 频谱展示；我们选择把**工程完整度**（触发/协议/识别/固化/复现）做满，而不是堆通道数与采样率。扩展路径（双通道/更高采样率）在架构上已预留（多路 MUX + 多档 fs）。

**Q11 自研 FFT 的 SF/S2/S3 是"三个独立峰"吗？**
A：**要看波形，而且我们已经把"假峰"堵掉了。** SF/S2/S3 是幅度谱上**最强的三条谱线**（Δf=48.8Hz）：
- **1kHz 正弦**：`SF=976 / S2=0 / S3=0` —— **单峰**。这就是"无假峰"的直接证据。
- **1kHz 方波**：`SF=976`（基波 bin20）/ `S2=2978`（3 次谐波 bin61）/ `S3=4980`（5 次谐波 bin102）—— 这是**真实存在的谐波**，不是伪峰。（±1 bin 容差；Δf=48.8Hz，1000Hz 落 bin20.48。）
- **假峰是怎么来的、怎么没的（这是本项目的第二个"仿真掩盖的坑"）**：自研通路原先**只有矩形窗**（没加窗，Hann 窗只在 IP 通路）。1kHz 落在**非整数 bin 20.48**，矩形窗的 Dirichlet 核在离主峰 4 个 bin 的 bin24 处泄漏 **13.6%**，刚好越过"主峰/8 = 12.5%"的幅度门限 -> 被报成"第二峰"（上板实测 `S2=1171Hz` = bin24）。
- **根因修复 = 给自研通路也加 Hann 窗**（复用 IP 通路同一份 `hann_1024.hex` / `hann_rom` 模块），泄漏由 13.6% 压到 **0.9%**，对 12.5% 的门限有 **16 倍余量**。
- **为什么仿真永远抓不到它**：仿真激励是"1024 点正好 k 个整周期"，谱线**精确落在整数 bin**，而矩形窗在整数 bin 处的泄漏**恰好为 0**。所以激励不覆盖"非整数 bin"就永远看不见 —— 本项目**第二次"仿真通过 ≠ 硬件正确"**（SK-034）。
- **后来怎么补的（这句最加分：把 bug 变成资产）**：回归仿真已扩到 **5 场景**，新增"正弦 **20.5** 周期 = **非整数 bin**"这一条；把 `.USE_HANN` 改回 `1'b0` 它会立刻报出 `S2=1171`（负向对照证明这个测试真的能抓到那个 bug）。
口径：说"**三条最强谱线（基波 + 真实谐波）**"，**不说"三个独立峰"**。被追问判据 -> **门限本身就是判据**（相隔 ≥6 bin + 幅度 ≥1/8 主峰）。

**Q12 号称覆盖 1MHz，可采样率只有 50kHz，是不是夸大？**
A：两条通路、两个口径，报告中必须分开写：
- **频率/占空比/脉宽测量通路：100Hz ~ 1MHz**（闸门计数 + 测周法，只依赖边沿，与采样率无关）
- **波形上传与 FFT：50kHz 采样（fs）→ 可观察带宽 ≤25kHz**（奈奎斯特），>25kHz 属混叠区
混淆这两句才叫夸大；TY 识别也带可信闸门（>25kHz 或频率波动 >1.5% 强制报"其他"）。

**Q13 一句话应用场景（"到底解决什么实际问题"）**
A：**"没有示波器和信号源时的口袋体检仪"**——给一块电路板做体检：它既是**信号源**（1Hz~12.5MHz 正弦/方波/三角/双音/扫频），又能**测回路的频率、占空比、脉宽、峰峰值并自动判断波形类型**，断电重启即用。
典型场景：实验室快速自检、维修现场判断时钟/传感器输出是否正常、DSP 课程教学演示。（扩展：F1 转发口代码已预留，可接 STM32/屏做手持终端。）

**Q14 三种波形的 Vpp 一致吗？**
A：**现在一致了。** 之前方波电平在 RTL 里**写死成 `26/230`**（Vpp 只有 204 LSB），而正弦表是 `1/255`、三角是 `0/254`（Vpp 254 LSB），所以同一块板子上正弦读 `1085mV`、方波读 `882mV`（比值 0.813，与数字比 `204/254 = 0.803` 吻合 —— 不是故障，是常量）。
已把方波改成**与正弦同幅的 `1/255`**，三种波形 Vpp 现在一致。
（诚实边界：**绝对毫伏数要等外部仪器标定 `KN` 之后才敢说"准"**；标定前只信波形之间的比例。0x8C 就是为此预留的。）
影响面已核对：波形识别全程用 `mn/mx/span` **归一化**、占空比/脉宽只看跳变位置、自研 FFT 的 `SF/S2/S3` 经数值模型验证**一个数都没变**。

**Q15 板上还留着 ILA（逻辑分析仪）？不占资源吗？**
A：留着，而且这是**资源优化换来的红利**：资源攻坚前 LUT 超容（100.14%），ILA 被迫关掉；把 `f_ram` 请进块 RAM 后 LUT 降到 24.6%，余量足够，就把 ILA 重新打开了（`board_top.v` 的 `ILA_EN`）。它是**上板可视调试**手段，能抓频率计与上报模块的 FSM 状态、定位时序问题。
若评委追问"这不是浪费资源吗" -> 回"改一个 `1'b0` 就把它连同调试桥一起 generate 掉，**零功能影响、零残留代价**，我们已经把开关留好了"。

**Q16 你怎么保证"改一处不会碰坏别处"？**
A：三件套：①**一键回退开关**（本次三处改动全是 `localparam` 开关，改一个 0/1 就回到上一版）；②**改变量最小化**（例如加 Hann 窗后 `GAP` 仍保留 6 而不是顺手改回 4 —— 少动一处就少一份回归风险）；③**板上判据"只认该变的那个数"**（GAP 修复那一轮，正弦 `S2` 从 1171 变 0，而 `V/D/W/TY/S/A` **逐字不变** —— 这就是零副作用的最强证据）。

## 二、现场演示串词（3 分钟）
1. 上电即出数据（不接电脑，固化版）→"开箱即测"

6. 双音：S=1001+A=1099 → 分辨率

## 三、诚实边界（评委问到要大方说）
- 正弦绝对占空比受模拟前端限制（46.8~49.6 随温度/频段）；方波为计量基准
- 高频（>25kHz）频谱混叠：设计使然（fs=50k），有 fs 多档方案但**未实施**（资源）
- 音乐彩蛋/高采样率通道：**未做**，属可选扩展
