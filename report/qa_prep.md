## 〇、一页速答卡（背下来）
| 问题 | 一句话答案 |
|---|---|
| 为什么用 FPGA？ | 测量/触发/FFT/识别全在 PL 侧硬件流水线并行跑：时延确定（纳秒级）、触发逻辑可自定义、系统可重构——MCU 轮询与商用仪器都给不了 |
| 和商业示波器/频谱仪区别？ | 我们把"信号源+测量+频谱+识别+扫频"做成一机、**断电即用**；且测量/识别算法完全自主可控、可随题改（开源级复现）|
| 自研 FFT 和 IP 差在哪？ | 同点数口径：**502 LUT/7 DSP（1024 点）** vs IP 1771 LUT/9 DSP（4096 点）；每点资源同量级（0.49 vs 0.43 LUT/点），运算 ~1ms@50MHz |
| 精度怎么保证？ | 回环自测 + PC 交叉验证 +（11 月）外部仪器标定；方波 1k~1M：F/D/W 逐项精确；正弦受模拟前端限制，指标以方波为准并标注 |
| 95% 资源怎么放下的？ | 大表全走 BRAM、无 ILA 版时序收敛 WNS +1.277ns；自研 FFT 按需静默（0x8A）——**资源紧恰恰是优化功力的展示** |

## 一、必答题（评委高频）
**Q1 你们和 STM32/PC 方案的本质区别？**
A：三件事：①**并行**——测频/占空比/脉宽/FFT/串口在 50MHz 下同时跑；MCU 是排队执行。②**确定性**——25 点/µs 的采样与 20ns 分辨的时间戳，中断方案做不到。③**可重构**——触发逻辑、识别算法、扫频节奏都是"我们造的电路"，赛场上可现场改。

**Q2 测量精度怎么保证？对标过什么仪器？**
A：见 `accuracy_calibration.md`。现阶段：自环回 + PC 抓图交叉（如 V=140 与 PC 139 一致）；指标：方波 1k/100k/1M 的 F 逐字精确、D=49.9~50.4%、W=500µs/6µs；11 月用外部信号源/示波器补正式标定表（预留行已建）。

**Q3 "抗噪"具体几层？各解决什么？**
A：四层递进（详见 `denoise_experiments.md`）：①穿越+重武装"连续 2 拍确认"治正弦 ×2 假穿越；②占空比施密特迟滞治毛刺切碎时段；③5 点中值滤波（9 比较器）清 ≥2 拍尖刺（V:201→140 三步证据）；④窗口级 3 窗中值拒绝偶发坏窗（修后 100kHz 方波 V 恒定、D 稳 050.x）。

**Q4 自研 FFT 是"高性能"实现吗？**
A：诚实说——**它是"正确性优先"的迭代式设计**：运算 ~1ms/帧@50MHz，全链路 21ms（其中 20.5ms 是 50kHz×1024 的采集窗，任何实现都躲不开；对比 IP 4096 链路采集窗 82ms）。价值在于**完全掌控定点精度与资源**（502 LUT/7 DSP），并与 IP 做了同口径对比。

**Q5 为什么不做 4096 点自研？**
A：两个原因：①主设计 LUT 95.5%，**不冒险加塞**；②对比采用"**同口径独立综合**"（自研 4096 版 OOC 数据 vs xfft 裸核），公平且零风险。（若评委追问"想不想做"：RTL 参数化扩展 +4~5 BRAM/+~100 LUT 即可，蝶形核不随 N 增长——但工程上我们不赌稳定性。）

**Q6 460800 波特率够吗？刷新率多少？**
A：见 `bandwidth_budget.md`：460800-8N1≈45kB/s；测量帧 45B/10ms（≈4.5kB/s，占 10%）；波形帧 1022B/22ms；S/A 行 22B；**Spectrogram 以 10~100Hz 取 S/A 完全可行**。不做整段频谱上传（4096B/帧≈89ms）是**带宽-信息量的主动取舍**。

**Q7 波形识别准确率？**
A：方法=占比法（近极端占比：方波≈100%/正弦≈46%/三角≈25%）+ 双闸门（>25kHz 混叠或频率波动>1.5% 时报"其他"）。实测五场景全对：1k 正弦/方波/三角=1/0/2；混叠、双音=3。**宁可不给结论也不给错误结论**是设计原则。

**Q8 温漂（正弦 D 从 50 掉到 46.8）怎么解释？**
A：模拟链路热平衡现象（SK-028）：冷机 50.0%/V≈140 → 热机 46.8%/V≈153；方波免疫（只看时序对称）。处置：预热 3 分钟 / 方波做基准 / 终验外部源标定。**我们把它写进了报告案例，而不是藏起来。**

**Q9 数据可信度？（"怎么证明不是碰巧"）**
A：方法论：**"复现硬件式仿真"**——把硬件异常数字当假设变体建模，逐字复现即定案（如 BRAM 2 拍延迟案：1k/2k 两组数据 [1367,1318,1709]/[2686,3369,8740] 完全一致）。全过程沉淀 28 条技能包。

**Q10 为什么单通道/8bit ADC？（初级组定位）**
A：题目定位"口袋仪器"：8bit@50kHz 回环覆盖 100Hz~1MHz 测量与 ≤25kHz 频谱展示；我们选择把**工程完整度**（触发/协议/识别/固化/复现）做满，而不是堆通道数与采样率。扩展路径（双通道/更高采样率）在架构上已预留（多路 MUX + 多档 fs）。

## 二、现场演示串词（3 分钟）
1. 上电即出数据（不接电脑，固化版）→"开箱即测"
2. 方波 1k：F/D/W/V 全屏 → 指标硬
3. 切正弦：TY=1，F 仍精确 → 识别+鲁棒
4. 发 0x8A：SF/S2/S3 三行 → 自研 FFT 实证
5. 发 0x8B：扫频跑起来 + 上位机 Spectrogram 斜线 → 演示王炸
6. 双音：S=1001+A=1099 → 分辨率

## 三、诚实边界（评委问到要大方说）
- 正弦绝对占空比受模拟前端限制（46.8~49.6 随温度/频段）；方波为计量基准
- 高频（>25kHz）频谱混叠：设计使然（fs=50k），有 fs 多档方案但**未实施**（资源）
- 音乐彩蛋/高采样率通道：**未做**，属可选扩展
