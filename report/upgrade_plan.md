# 升级与差异化功能规划（WaveCore 2026-09-03）

> 目标：把"仪器类经典题"做出竞赛深度与差异化。评分权重参考：创新 30 / 资源优化 20 / 功能完整 20 / LLM+技能包 15 / 文档 15。

## 选型原则
1. 先补"硬指标缺口"（现场可能被评委实测，翻车点优先）
2. 再做"评分抓手"（资源对比、创新点、可复现）
3. 最后加"演示记忆点"（彩蛋、扫频、上位机大屏）

## P0 必做（防翻车 + 验收达标）

| 功能 | 为什么 | 工作量 |
|---|---|---|
| 串口"任意频率设置"命令 | 现在是 4 档；评委现场可能要求"给我出个 37.5kHz"——任意 Hz 输入→算 fcw→输出，RX 链路已通，性价比最高 | 小（解析+计算+设 fcw） |
| 低频测频升级（测周法/等精度） | 10ms 闸门在 ≤1kHz 误差爆炸；方案验收 100Hz~1MHz<1% 目前未达标，评委拿信号源实测会露馅 | 中 |
| 信号源/测量/FFT 状态机总控 | 多模式切换（测量/扫频/音乐）规范管理 | 中 |

## P1 高分（对应"资源优化 20%"+"功能 20%"）

| 功能 | 为什么 | 工作量 |
|---|---|---|
| FFT：IP 核 vs 自研(Radix-2)双实现 + 资源对比表 | 赛题点名的对比思路；报告最硬的素材 | 大 |
| 频谱降采样链（多档采样率） | 解决 25M/1024=24.4kHz 分辨不了 1k/1.1k 的问题；低频高分辨 | 大 |
| 一键自动测量 + 结果 PASS/FAIL 判定 | "智能仪器"感；演示直观 | 小中 |

## P2 出彩（创新 30% + 演示记忆点）

| 功能 | 为什么 | 工作量 |
|---|---|---|
| 扫频模式（DDS 自动 10Hz~1M 步进扫描） | 配合上位机/串口屏画"频响曲线"，极像专业仪器；实现只需 fcw 步进 | 小 |
| 波形扩展：方波/三角波 | 信号源从"单波形"变"多功能"（对比获奖作品 8 波形） | 小中 |
| 音乐彩蛋 → 音符识别 | 复用 FFT，识别主频→显示音符名；演示第二幕的惊喜点 | 中 |
| 连续调频（编码器/长按按键粗调） | 4 档 → 连续可调，专业感 | 小中 |
| 阈值越限告警（LED/蜂鸣） | 呼应"自动检测"应用场景 | 小 |

## 建议路线（9 月余量充足，按序推进）
1. P0 三件（约 1 周）：任意频率命令 → 低频测频升级 → 状态机总控
2. P1：FFT 双实现 + 降采样（约 2~3 周，最重）
3. P2 精选 2~3 项：扫频 + 方波/三角 + 音符识别（彩蛋）
4. 终验与叙事：示波器补测 + 三幕演示视频（专业感→技术感→音乐彩蛋）

## 现场防翻车清单（评委可能做的事）
- [ ] 让我出任意频率信号（如 37.5kHz）→ P0-1
- [ ] 拿信号源给个 500Hz~1kHz 低频让我测 → P0-2
- [ ] 让我分辨两个相近频率 → P1-2
- [ ] 问资源占用和优化依据 → P1-1 数据
