## 第 0 步 · 先确认买到的是什么（2 分钟）

拿起模块，**看引脚丝印**：

| 模块 | 应该有的引脚 | 关键 |
|---|---|---|
| **MAX9814 麦克风** | `VDD` / `GND` / `OUT`（可能还有 `GAIN` / `SHDN`）| ✅ **有 OUT** |
| **振动模块** | `VCC` / `GND` / `DO` / **`AO`** | ✅ **必须有 AO** |

**⚠️ 如果振动模块只有 DO、没有 AO** → **做不了频谱** ✗
（只能接空闲 IO 做"振动超限告警"，那是另一个用途）

---

## 第 1 步 · 验振动模块的 AO（**最优先，5 分钟**）

**为什么先做**：它决定"这个模块能不能做频谱"，早验早省事。

**做法**
```
1. 振动模块接 5V（VCC→5V，GND→GND）—— 先不接 FPGA 也行
2. 示波器探头接 AO，夹子接 GND
3. 敲一下桌子
```

**判据**

| 示波器上看到 | 结论 | 下一步 |
|---|---|---|
| **衰减振荡波形**（能看到起伏频率）| ✅ **真模拟输出** | 能做频谱 ✓ 继续第 2 步 |
| 只有**缓慢起伏的包络** | ⚠️ 是包络（内部整流过）| 频谱改用**压电片** |
| 一直平直 | ✗ 接线错 / 模块坏 | 查线，或换个模块 |

**没有示波器时**：万用表**直流档**接 AO —— 静止时有个固定电压，**敲桌子会跳一下** ✓
（能证明"是模拟输出"，但区分不了波形/包络）

---

## 第 2 步 · 接 MAX9814 到板子（10 分钟）

**接线**（三根）
```
MAX9814  VDD → 板子 5V 排针
MAX9814  GND → 板子 GND          ← 必须共地！
MAX9814  OUT → AD 模块的输入端（原来插回环飞线的那个点）
```

**⚠️ 三条禁忌**
1. **先拔掉回环飞线** —— AD 模块只有一路输入
2. **必须共地** —— 不共地读数会乱飘
3. **绝不动 AD/DA 模块上的电位器** —— 电压标定（KN=37203）是绑在它当前位置的

**接完先快速验证**
```
串口发：5A A5 83 00 01 00 84     （请求波形）
上位机「波形」页看
```
| 现象 | 说明 |
|---|---|
| 安静时是**低幅度随机噪声** | ✅ 正常（麦克风底噪）|
| **吹口哨**时波形幅度明显变化 | ✅ 信号通了 |
| 一直是一条直线 / 满幅削顶 | ✗ 检查接线、增益 |

---

## 第 3 步 · 看频谱（**这步最好看**）

```
1. 时基保持 T1（默认 50kHz）
2. 双击 run_waterfall.bat
3. 对着麦克风吹口哨
```

**判据**

| 动作 | 频谱上应该看到 |
|---|---|
| 安静 | 底噪低、谱线平坦 |
| **吹口哨** | **一根清晰的谱峰** ⭐ —— 视频里最值钱的镜头 |
| 拍手 | 全频段瞬间抬高，随后回落 |
| 说话 | 多个峰随音节起伏 |

**没反应时的排查顺序**
1. OUT 是不是接到了 **AD 模块输入端**（不是接到 FPGA 的 IO！）
2. GND 是否真的共地
3. **信号太小** → MAX9814 有 `GAIN` 引脚，接法决定 40/50/60 dB 增益，换一档试试
4. 确认回环飞线**已拔掉**（否则 AD 输入可能是别的信号）

---

## 第 4 步 · 振动模块实测

**接线**（AO → AD 输入端；麦克风那根先拔掉，两个不能同时接）
```
振动模块  VCC → 5V
振动模块  GND → GND
振动模块  AO  → AD 模块输入端
```

**动作**：敲桌子 / 轻拍板子 / 用手机震动贴上去

| 现象 | 说明 |
|---|---|
| 敲击瞬间频谱**低频段抬起** | ✅ 通了（冲击是宽带信号）|
| 连续振动（如贴手机震动）→ 出现**周期性谱线** | ✅ 更好看 |
