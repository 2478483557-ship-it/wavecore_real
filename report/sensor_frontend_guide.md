## 一、选型结论：**光敏不合适，选麦克风或压电片**

| 方案 | 成本 | 需要放大 | 频谱演示效果 | 结论 |
|---|---|---|---|---|
| **驻极体麦克风** | 1~2 元（裸）/ 15 元（模块）| 是（40~60dB）| ★★★★★ 拍手/口哨 → 清晰谱峰 | **首选** |
| **压电振动片** | 0.5~2 元 | 是（20~40dB）| ★★★★ 敲击 → 振动谱 | **次选**（你既然会搭放大，成本最低）|
| ~~光敏/热敏电阻~~ | 1 元 | 否 | ★ 变化仅几 Hz，**频谱上没东西可看** | ❌ **不建议** |

**⚠️ 判断依据**：我们是**频谱分析仪**，需要的是"**含有丰富频谱成分**"的信号。

- 光强/温度是**慢变量**（DC ~ 几 Hz）→ 频谱图上**什么都看不到** ✗（**上一条推荐光敏是错的，此处纠正**）
- **麦克风**：20Hz~20kHz，谐波丰富 ✓
- **压电片**：敲击 = 宽带冲击 + 结构衰减 ✓ —— 两者都是频谱仪的主场

**两个都买也就 20 元以内，建议都备着**（演示时切换，故事更饱满）。

## 二、放大电路设计要点（5 个关键参数）

### 1. 供电与偏置：**信号必须以 0V 为中心，不要偏置到 2.5V**

> **[2026-10-23 修正]** 本节原先写的是"单电源 5V + 偏置到 2.5V"。核过量程后发现那会
> 白白浪费一半动态范围，现改为下面的方案。

先把换算摆清楚（ATK_HS_AD_DA 模块）：

```
模块输入端 ±5V  <->  ADC 0~2V  <->  0~255 码
1 LSB = 36.33 mV（模块输入端，已由 0x8C 标定 KN=37203 确认）

输入 0V    -> ADC 1.0V -> 码 128   ← 正中
输入 2.5V  -> ADC 1.5V -> 码 192   ← 只往上剩 2.5V，往下只剩 0V
```

**结论：**

- **模块内部已经有偏置了**（把 0V 映射到 AD 中点），**外部不需要再加偏置**。
  再加偏置等于把工作点推歪，可用摆幅减半。
- 运放应输出**以 0V 为中心的双极性信号**，±3.5V 为目标（占 70% 量程）。
- 因此**需要 ±5V 双电源**（可从 AD 模块取），或单电源 + 输出隔直电容
  + 电阻下拉到地重新定义 0V。

**★ 更要紧的一条：必须隔掉传感器模块自带的直流。**
MAX9814 输出带约 1.25V 直流偏置，放大 100 倍就是 125V —— 直接饱和。

```
传感器 ──[1µF 隔直]──> 运放 ──[100Ω]──> 模块输入端
                                     （0V 为中心）
```

### 2. 增益（按实测信号幅度反算）

目标：峰值 **3.5V**（70% 量程，约 96 码）。 **增益 G = 3.5V ÷ 传感器输出峰值。**

| 信号源 | 传感器输出峰值 | 所需增益 |
|---|---|---|
| MAX9814 麦克风（说话，AGC 后） | ~200 mV | **17×** |
| MAX9814（安静房间） | ~50 mV | **70×** |
| MAX9814（大声 / 近讲） | ~1 V | **3.5×** |
| 801S 振动（轻敲） | ~20 mV | **175×** |
| 801S（持续振动） | ~100 mV | **35×** |

**一个可调 3~200 的增益即可覆盖全部**，不要定死。

对应系统分辨率（1 LSB ÷ G）：

```
G = 20×   ->  1.8 mV
G = 100×  ->  0.36 mV
G = 200×  ->  0.18 mV
```

> ⚠️ **下限由 ADC 量化决定**：8 位、1 LSB = 36.33mV，信号低于约 3~4 LSB（≈120mV 峰峰）
> 时信息在量化那一步就丢了，**锁相的相干平均救不回来**（量化是确定性误差，不是随机噪声）。

### 2.1 选型与带宽

**INA128（或 AD620）仪表放大器**，G = 1 + 50k/Rg：

| 增益 | Rg |
|---|---|
| 10× | 5.6 kΩ |
| 20× | 2.6 kΩ |
| 100× | 505 Ω |
| 200× | 251 Ω |

用一只 10k 电位器串固定电阻即可连续可调。

**带宽要留意**：INA128 的 GBW 是 1.3MHz，单级 G=100 时带宽只剩 **13kHz**。
- 振动信号（< 1kHz）：单级足够
- 麦克风要听到 20kHz：**改成两级级联（10× × 10×）**，带宽回到 130kHz
- 每级之间串隔直电容，并加一级低通（约 100kHz）防自激

### 2.2 前置条件：锁相必须有同频激励

**这一条容易忽略，但不满足则整个演示不成立：**

- 麦克风：需要一个喇叭放 DDS 的单音（如 1kHz），麦克风接收 → 才能锁相。
  **光听环境声是锁不了的**（没有参考频率）。
- 振动：需要一个振动源（小喇叭顶在传感器上 / 压电片）由 DDS 驱动。

没有激励源时，锁相无参考可用，只能退回普通频谱分析。

**单级 1000 倍不现实**（自激风险高）→ **两级级联**，例如 **100× × 10×**，
级间串隔直电容 + 每级加低通（如 100kHz）防止高频自激。

### 3. 运放选型（**带宽必须够，这是最关键的一条**）

- 我们的 ADC 是 **25MSPS**；T3/T4 档要观察到 **~100kHz** → 运放 **GBW ≥ 10MHz**
- ✅ **NE5532**（GBW 10MHz）/ **AD8056**（同 AD 模块上用的型号）—— 推荐
- ⚠️ TL072（3MHz）勉强
- **LM358（1MHz）：看不了高频频谱，但做 1kHz 锁相演示完全够**（G=100 时带宽 10kHz）。
  > 原文写的是「LM358 不够」，那是针对 T3/T4 高频频谱。
  > 只做锁相演示的话，手上有 LM358 / LM324 就别扔 —— 具体接法见 `sensor_amp_circuit.md`。

### 4. 输出保护（**这一步别省**）

- 输出串 **100Ω** 限流
- 输出对地并**两只肖特基二极管**（如 BAT54S）钳位，**防止超压打坏 AD9280** ✓
- 上电顺序：**先接好地，再给信号**，避免瞬间高压

### 5. 耦合

- 传感器 → 运放：**1µF**
- 运放 → AD 输入：**10µF**（隔直，只留交流成分）

## 三、接到哪里（**不需要用 FPGA 的 IO 口**）

```
传感器 ──> 放大电路 ──> AD 模块【输入端】（此时拔掉回环飞线）
                        AD 模块【GND】 ── 电路的 GND   ← 必须共地！
```

⚠️ **AD 模块只有一路输入** → 演示流程必须是：
**先演板内 DDS 自测（回环飞线在位）→ 再拔线接传感器**。

## 六、演示脚本（3 分钟，视频里最好看的片段）

1. **拍手** → 宽带冲击，**频谱整片抬高**（最能体现"实时频谱"）
2. **吹口哨 / 手机放单音** → **一根清晰谱峰**（最能说明这是频谱仪）
3. **敲桌子（压电片）** → 振动谱 + 衰减包络
4. **对照**：切回板内 DDS 1kHz 方波 → 三峰 1k/3k/5k —— **证明系统本身是准的**

## 七、验收判据

| 检查 | 预期 |
|---|---|
| 接麦克风，安静时 | 底噪低、谱线平坦 |
| 拍手 | 全频段瞬时抬高，随后回落 |
| 吹口哨 | **单根谱峰**，且峰值频率与音高一致 |
| 敲击压电片 | 低频段出现冲击谱 |
| 示波器看放大输出 | 幅度在 **±4V 以内**（不超 AD 量程）|
