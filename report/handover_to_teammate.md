## 三、你要做的事（4 项，详见 `report/teammate1_task.md` v1.4）

| 优先级 | 需求 | 数据源 |
|---|---|---|
| **P0** | **波形自动刷新（连续采集）** | 定时发 `0x83` |
| **P0** | **频谱柱状图 + 瀑布图** | `0x8E` 谱帧（**可参考 `host/spectrum_waterfall.py` 的现成实现**）|
| **P0** | **时基档位下拉** + 波形 x 轴按 fs 标注 | `0x8D`（协议库已提供 `command_set_timebase()`）|
| P1 | 量程标注小字：`分辨率 36.3 mV/LSB ｜ 输入范围 ±5V` | — |

**协议库已经帮你准备好了**（直接用，不用自己拼帧）：

```python
from protocol import (command_set_timebase, timebase_fs_hz,
                      command_request_spectrum, parse_spectrum_frame,
                      command_set_pretrigger)

ser.write(command_set_timebase(3))     # 0=T1 50k / 1=T2 12.5k / 2=T3 100k / 3=T4 200k
fs = timebase_fs_hz(tier)              # 给频谱 x 轴标刻度（谱帧本身不带 fs！）
ser.write(command_request_spectrum())  # 请求一帧 518 字节幅度谱
bins = parse_spectrum_frame(frame)     # -> 512 个幅度码；校验失败返回 None
```

**三个坑**：① `0x8A/0x8B/0x8D/0x8E/0x8F` 都是**静默命令**（无 ACK，"没反应"是正常的）；
② 谱帧**不带 fs**，上位机要自己记当前档位；③ 幅度码是**对数压缩的相对量，不是 mV**。
