# 传感器放大电路：按运放型号选方案（2026-10-24）

> 这份是**可照做**的接线单，不是原理讨论。
> 总原则见 `sensor_frontend_guide.md`，本文只回答"我手上这个运放怎么接"。

## 零、先确认一件事：你要做哪个演示

| 演示 | 需要多高带宽 | 谁能用 |
|---|---|---|
| **锁相提取微弱 1kHz**（本项目主线） | 10kHz 足够 | **LM358 也能用** ✓ |
| 敲击频谱（看宽带共振） | 100kHz | 需要 GBW ≥ 10MHz |

**指南里那句"LM358 不够"是针对高频频谱的。**
如果只做 1kHz 锁相演示（推荐），LM358 / LM2904 / LM324 全部够用 —— 别扔。

---

## 一、零运放方案（如果有 MAX9814 模块）

MAX9814 模块**自带 AGC 和放大**，输出 0~2V，串一个电容就能直接进板子。

```
MAX9814        ┌──── 10µF ────┐
  OUT ─────────┤              ├──── AD 模块 IN
               └──── 100Ω ────┘  （100Ω 串在信号线上，限流）
  GND ─────────────────────────── AD 模块 GND      ← 必须共地！
  VDD ─────────── 3.3V 或 5V（按模块标注）
```

**就这么简单。** 电容隔掉模块自带的 1.25V 直流，剩下以 0V 为中心的小信号。

实测参考值（安静房间）：输出约 50mV 峰值 = 100mV 峰峰 ≈ **2.7 LSB**。
偏低，但说话/敲击时能到 200~400mV 峰值 = **11~22 LSB**，够用。

**缺点**：AGC 会压缩动态范围，不适合做定量测量。

---

## 二、LM358 / LM2904 / LM324 方案（最常见的型号）

适用：**1kHz 锁相演示**。GBW = 1MHz，G=100 时带宽 10kHz，1kHz 绰绰有余。

### 供电：单 5V + 虚拟地

板上没有 ±5V 的话用这个，最简单。

```
        +5V
         │
    ┌────┴────┐
    │        │
   10k      10k
    │        │
    ├────────┼──── 虚拟地 VG（2.5V）
    │        │
    ├── 10µF ─┴── GND     ← 去耦，别省
    │
   GND
```

### 放大电路（同相放大，G = 101）

```
                      ┌──── 100kΩ ────┐
                      │               │
   IN ── 1µF ──┬──── (+)            (−)────┬──── OUT ── 10µF ── 100Ω ── AD IN
               │                            │
              10kΩ                          1kΩ
               │                            │
              VG                           VG
```

- **G = 1 + 100k / 1k = 101 倍**
- 输入 1µF 隔直（挡掉传感器自带的直流偏置）
- 同相端 10kΩ 下拉到 VG（定义直流工作点）
- 输出 10µF 隔直（把 2.5V 中心变成 0V 中心，才能进 AD）
- 输出 100Ω 限流

### 关键元件值

| 元件 | 值 | 作用 | 能不能换 |
|---|---|---|---|
| 输入电容 | 1µF | 隔直 | 0.1~10µF 都行，越小低频越差 |
| 输出电容 | 10µF | 隔直 + 建立 0V 中心 | 别小于 1µF |
| 反馈电阻 Rf | 100kΩ | 决定增益 | 见下表 |
| 反馈电阻 Rg | 1kΩ | 决定增益 | 见下表 |
| 分压电阻 | 10kΩ × 2 | 造虚拟地 | 1k~100k 都行，两只要一样 |
| 限流电阻 | 100Ω | 保护 AD 输入 | 别省 |

### 增益怎么选

**G = 1 + Rf / Rg**

| 目标增益 | Rf | Rg | 1kHz 时带宽 | 适合 |
|---|---|---|---|---|
| 10× | 9.1k | 1k | 100kHz | 大声/近讲 |
| 47× | 47k | 1k | 21kHz | 说话（推荐） |
| 101× | 100k | 1k | 10kHz | 安静房间 |
| 220× | 220k | 1k | 4.5kHz | 极弱信号 |

> **别超过 220×**：LM358 在高增益下噪声和失调会很明显，
> 而且带宽掉到 4.5kHz，说话声的高频部分就没了。

### 想做可调？

把 Rf 换成 **100kΩ 电位器**串 **1kΩ 固定电阻**：

```
     ┌── 100k 电位器 ──┐
     │                 │
     ├── 1kΩ ──────────┤  ← 这个 1k 保证最小增益不小于 2
     │                 │
    (−)               OUT
```

转动电位器，增益在 2~101 之间连续可调。**现场调最方便。**

## 三、NE5532 / TL072 方案（如果有）

接法和 LM358 完全一样，只是可以推到更高频率：

| 运放 | GBW | G=100 时带宽 | 1kHz 锁相 | 敲击频谱 |
|---|---|---|---|---|
| LM358 / LM324 | 1 MHz | 10 kHz | ✓ | ✗ |
| TL072 | 3 MHz | 30 kHz | ✓ | 勉强 |
| **NE5532** | 10 MHz | 100 kHz | ✓ | ✓ |
| AD8056 | 100 MHz | 1 MHz | ✓ | ✓✓ |

**NE5532 是甜点**：带宽够、噪声低、便宜。有的话优先用它。

## 四、压电片方案（最便宜，1 块钱）

27mm 两线压电片，既能当**发声器**也能当**拾音器**。

### 当声源（接 DA 输出）

```
DA 输出 ── 100Ω ── 压电片正极
GND ─────────────── 压电片负极
```

DA 输出 ±5V 直接驱动压电片，响度不大但够近场用。

### 当传感器（接运放输入）

```
压电片 ── 1µF ── 运放 IN
```

压电片内阻很高（几 MΩ），**运放输入阻抗必须够高**：
- LM358 输入阻抗约 10^12 Ω ✓ 没问题
- 但要在压电片两端并一个 **1MΩ 电阻到地**，给偏置电流一条路，否则输出会漂

```
压电片 ──┬── 1MΩ ── GND
         │
         └── 1µF ── 运放 IN
```

## 五、接线检查清单（接错了不工作）

```
□ 传感器 GND、运放 GND、AD 模块 GND 三者连在一起
□ 原来的 DA→AD 回环飞线已经拔掉
□ 运放供电正常（量一下 V+ 和 V−，别接反）
□ 虚拟地量出来是 2.5V 左右（±0.2V 都算正常）
□ 运放输出端量出来也是 2.5V 左右（没有信号时）
□ AD 输入端量出来是 0V 左右（隔直电容之后）
```

**最后一条最容易出问题**：如果 AD 输入端量到 2.5V，说明隔直电容没接上或者接反了。

---

## 六、上电顺序

1. 先接好所有地线
2. 再给运放上电
3. 最后给信号（或者让声源开始响）

**不要带电插拔传感器。**

---

## 七、调不出来怎么查

| 现象 | 先查这个 |
|---|---|
| Vpp 一直是 0 | 回环飞线拔了吗？AD 真收到信号了吗？ |
| Vpp 有小值但不跟着声源变 | 隔直电容失效 / 运放没供电 |
| 输出饱和（Vpp 顶到 5000mV） | 增益太大，换小 Rf |
| 输出一直在 0 附近不动 | 虚拟地没建立 / 同相端没接 VG |
| 频率读数是噪声值 | 信号太弱被环境噪声盖住，先贴近声源 |
| 锁相读 0 | 锁相没开（0x9A=1）/ 参考频率和信号对不上 |
