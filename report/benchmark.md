# 对标分析：同类获奖作品 vs WaveCore（2026-09-03）

> 目的：回答"我们的题目难度是否合理、进度是否太快"。资料来源：GitHub 公开获奖仓库 + 高校获奖新闻（2024/2025 全国大学生嵌入式芯片与系统设计竞赛 FPGA 赛道）。

## 二、诚实结论

1. **题目本身完全合理**：仪器类(信号源+测量+频谱)是 FPGA 赛道最常见、评委最熟悉公平的舞台，初级组尤其看重"完整度+小而精"，不要求研究生组那种 SoC/AI 深度。
2. **目前的进度快是"假象"**：已完成部分(M1~M5a)≈ fans963 的课程作业水平线——前半段全是教程级内容(官方例程同款)，快是正常的。
3. **真正的难度分水岭在后面**，也是与"课程作业"拉开差距的地方：
   - **低频测频精度**(我们 10ms 闸门计数在 ≤1kHz 时误差爆炸，达不到方案 100Hz~1MHz<1% 的验收线)——需测周法/等精度或自适应闸门
   - **FFT 分辨率**(25M 采样/1024 点=24.4kHz，分辨不了 1k/1.1k)——需降采样链+长点数
   - 获奖作品的共性差异点我们可选：**IP 核 vs 自研 FFT 资源对比、一键自动化测量、阈值告警、微弱信号/音调识别彩蛋、上位机大屏**（评分"创新 30%+资源优化 20%"的抓手）

## 三、差距行动清单（写进后续里程碑）

1. M4b+：测量模块升级——多档闸门/测周法，补 100Hz~10kHz 精度（当前 10ms 闸门只覆盖 ≥10kHz）
2. M6 FFT：降采样链设计 → 低频高分辨；做"IP 核 vs 自研"资源对比（SK 素材+评分）
3. 差异化算法(可选加分)：音乐彩蛋加"主频→音符"识别；测量结果自动比对判 PASS
4. 团队协同：队友1 上位机大屏（波形/仪表/Spectrogram）；演示叙事练熟（9/20 起屏端方案取消，统一 PC 大屏）
5. 终验：有示波器后补"实测误差表+波形截图"，做成可信证据链

## 对标案例（09-15）：智能信号分析与诊断系统（紫光同创 676 系列）

> 来源：竞赛作品海报（用户提供）。定位：**数字示波器+频谱仪+AI识别 三合一**

### 对方配置（高端）
| 维度 | 指标 |
|---|---|
| 采集 | 16bit 双通道 **130MSps**、带宽 ~10MHz、**8Gb DDR**（500M 点存储） |
| 频谱 | **8192 点 FFT**、STFT 时频瀑布图、分辨率 1Hz（长时模式） |
| 测量 | 相位差法测频 **<0.01%**、相位 ±0.02°、10Hz~3MHz |
| 智能 | **KNN + TensorFlow Lite Micro** 信号识别 + 异常智能触发 |
| 显示/交互 | 1920×1080 **≥60fps**、触摸屏+旋钮+上位机+**语音**、ESP32 WiFi |

### 差距判断（重要）
- 对方大概率是**高级组/大器件平台**（紫光 676 + DDR + 130MSps）——与 35T 初级组**不在一个重量级**
- 我们**不追**：130MSps 采集、DDR 缓存、8192 点、STFT 瀑布、TFLite（超 35T 与题意）
- 我们的评分主战场仍是：**创新30 / 资源20 / 功能20 / LLM协作15 / 文档15**

### 低成本可抄点（进 backlog）
| 借鉴点 | 我们怎么做 | 成本 |
|---|---|---|
| **信号类型粗识别** | 用现有 FFT 幅度做**谐波能量比**判正弦/方波/三角（无需 AI 推理） | ~+200 LUT，标签价值大 ⭐ |
| **历史谱轨迹/简易瀑布** | 上位机把逐帧 S/A 画"频率-时间"轨迹（纯软件） | 0 LUT，队友1 可做 |
| **智能触发** | 已在 P0（边沿+预触发）；"异常触发"暂不做 | 已排期 |
| 高精度测频 | 我们当前 <1%；相位法作为**远期可选**（毕业前有余力再议） | 高复杂度，暂缓 |
| ≥60fps 显示 | 靠 **串口提速**（P0）+ pyqtgraph 上位机 | 已排期 |
