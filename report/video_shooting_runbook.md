## 一、T-30 分钟 · 准备

### 1.1 器材清单（打勾）

- [ ] 开发板 ＋ 电源 ＋ USB 线
- [ ] AD/DA 模块 ＋ **回环飞线**（**先接好**）
- [ ] 信号发生器 ＋ BNC 转 SMA 线
- [ ] 示波器 ＋ 探头（**用 1×/10× 高阻档，不要 50Ω**）
- [ ] 传感器：MAX9814 麦克风 ＋ 振动模块
- [ ] 手机/相机 ＋ **支架**（别手持）
- [ ] 电脑（跑 GUI）＋ 电源（**别拍一半没电**）

### 1.2 桌面摆位（**关键**）

```
   [示波器]          [信号发生器]
          \            /
       [板子 + AD/DA 模块]        ← 放中间，镜头能拍到
              |
        [电脑屏幕]                ← 稍微靠前、朝向镜头
```

**三个要点**
1. **三个设备要能同框** —— 段落 10、11 靠它
2. **屏幕可读** —— 亮度拉满、界面字体调大、把窗口拉宽
3. **光线** —— 白天靠窗自然光；**别开闪光灯**（金属/屏幕反光）

### 1.3 开拍前状态确认（5 分钟，**任一项不过就先解决**）

```
① 板子上电 → 串口 V= 是否 ≈5050？        （标定在不在）
② 双击 run_gui.bat → 能否连上串口？
③ 双击 run_waterfall.bat → 频谱能否出图？
④ 信号发生器输出 1kHz 方波 / 2V → 示波器确认波形正常
⑤ 确认回环飞线接着（第一幕要用）
```

## 二、录制 · 逐段执行

### 段落 1｜片头（0:10）—— 后期做，不用录

标题：项目名 ＋「全国大学生嵌入式芯片与系统设计竞赛 2026」＋ 队员姓名。

---

### 段落 2｜上电即测（0:10–1:00，50 秒）

**动作**
1. 拍**板子全景** 3 秒（含 AD/DA 模块、飞线）
2. 拍**插电源**的动作（体现"上电"）
3. 切到**屏幕**：读数自动出现
4. **特写**：`F=0001000Hz  V=0050.0%  W=00500us  V=5050`

**旁白**
> "WaveCore 上电即可工作。板内 DDS 产生信号，经 DAC 输出、飞线回环到 ADC，
> 系统自动测出频率、峰峰值、占空比和脉宽。**所有参数均已固化，无需任何配置**。"

**⚠️ 关键**：**只上电、不点任何按钮** —— "上电即测"的说服力全在这里。

---

### 段落 3｜任意频率（1:00–1:20，20 秒）

**动作**：界面上依次设 **1k → 10k → 100k**，每次停 3 秒看读数变化

**旁白**："频率可在 100Hz 到 1MHz 范围内任意设置，实时重测。"

---

### 段落 4｜波形识别（1:20–1:40，20 秒）

**动作**：切换输出**正弦 → 方波 → 三角**，看 `TY` 字段自动变化

**旁白**："系统还能自动识别波形类型，用于判断信号性质。"

---

### 段落 5｜触发 ＋ 预触发（1:40–2:10，30 秒）⭐

**动作**
```
1. 「触发」选  上升沿 → 点「应用触发」
2. 点「请求1024点波形」→ 波形稳定（触发沿在帧首）
3. 「预触发」选 50% → 点「应用预触发」→ 再请求波形
   → 触发沿跑到图【正中间】，能看到左侧的波形
4. 「预触发」选 75% → 再请求一次
```

**旁白**
> "触发支持自由、上升沿、下降沿三种模式。我们还实现了**预触发比例**——
> 50% 时触发点位于数据帧正中央，这样能看到**触发沿之前**的波形，
> 和示波器的行为一致。"

**⚠️ 这是重点段落**：它是"外部评审提出无预触发 → 我们实现 → 界面可操作"的完整答复。

---

### 段落 6｜自研 FFT ＋ 插值精度（2:10–2:40，30 秒）

**动作**：双击 `run_check_interp.bat`，拍它的**判定输出**（`SF=999 / S2=2998 / S3=4997`）

**旁白**
> "1024 点自研 FFT，配合汉宁窗抑制频谱泄漏、抛物线插值修正峰值位置，
> 把频率误差压到 **0.1% 以内**（真实值 1000/3000/5000Hz）。"

---

### 段落 7｜频谱：单峰 vs 三峰（2:40–3:00，20 秒）

**动作**
```
双击 run_waterfall_1k_sin.bat  → 一根谱线
双击 run_waterfall_1k_sq.bat   → 三根谱线（1k/3k/5k）
```

**旁白**："正弦是一根谱线，方波是三根谐波——与理论完全一致。"

---

### 段落 8｜扫频瀑布图（3:00–3:25，25 秒）⭐⭐

**动作**：双击 `run_waterfall_sweep.bat`，**让它跑 15 秒以上**，拍斜线滚动

**旁白**："扫频模式下，频率随时间线性变化，瀑布图把整个过程记录成一条斜线。"

**⚠️ 全片最抓眼的镜头** —— 如果只保留一个镜头，就留这个。

---

### 段落 9｜时基四档（3:25–3:50，25 秒）

**动作**：「采样时基」依次选 T1 → T2 → T3 → T4，各点一次「应用时基」再看频谱

**旁白**
> "四档时基覆盖 12.5kHz 到 200kHz 的等效采样率，
> 在**频率分辨率**和**观察带宽**之间提供不同取舍。"

---

### 段落 10｜同框证明 A：发生器 vs 本机（3:50–4:10，20 秒）⭐⭐

**动作**：**保持三设备同框**，发生器依次设 **1V / 2V / 4V**，每次给屏幕读数一个特写

| 发生器 | 屏幕应显示 |
|---|---|
| 1.0 V | 约 1017 mV |
| 2.0 V | 约 1998 mV |
| 4.0 V | 约 3887 mV |

**旁白**
> "以信号发生器为基准实测：1 到 4 V 范围内，本机读数**最大偏差 2.8%、平均 0.8%**。"

**⚠️ 这是"我们测得准"的唯一硬证据** —— 没有它，前面所有数字都只是"自己说的"。

---

### 段落 11｜同框证明 B：示波器 vs 上位机（4:10–4:30，20 秒）⭐⭐

**动作**：示波器探头接 **DA 输出**（板内 DDS 的信号），**同框拍**示波器波形 ＋ 屏幕采集结果

**旁白**
> "左边是示波器看到的实际输出波形，右边是系统采集并解析出的结果——
> **两者完全一致**，占空比 50%、脉宽 500 微秒。"

**这一个镜头同时证明**：DDS 输出正确 ＋ 采集通路正确 ＋ 参数计算正确。

**⚠️ 探头用高阻档**（50Ω 会加载信号，读数就变了）

---

### 段落 12｜传感器实测（4:30–5:00，30 秒）⭐⭐

**动作**
```
1. 拔掉回环飞线 → 接 MAX9814（VDD→5V, GND→GND, OUT→AD 输入端）
2. 【吹口哨】→ 频谱出现单根谱峰 → 定格 2 秒
3. 【拍手】→ 全频段瞬间抬起
4. 换振动模块（AO→AD 输入端）→ 敲桌子 → 振动冲击谱
```

**旁白**
> "接上传感器后，它就从一台实验仪器，变成了**设备状态监测 / 声音频谱分析**的终端——
> 采集、频谱分析、异常判定全部在板内完成。"

**⚠️ 别忘了**：录完把**回环飞线插回去**。

---

### 段落 13｜片尾（5:00–5:15）—— 后期做

三条卖点 ＋ 板子全景：
1. **自研低资源 FFT ＋ 峰值校正**（1024 点 ＋ Hann 窗 ＋ 抛物线插值）
2. **多时基采集与实时测量链路**（四档 fs 12.5k~200kHz）
3. **产生—采集—识别—频谱的完整闭环**（板内 DDS→DAC→回环→ADC，无外部仪器即可自测）

## 四、剪辑顺序建议

1. **先铺时间轴**：按段落顺序拖入，**先不管转场**
2. **掐头去尾**：每段只留最关键的 10~20 秒，**总长压到 4~5 分钟**
3. **加标题卡**：每段前 1~2 秒（"① 上电即测"）
4. **关键帧定格**：段落 8 瀑布图、段落 10 对照表、段落 12 单峰谱各定格 1~2 秒
5. **打字幕**：所有关键数字（2.8%、0.1%、21 帧/s、四档时基）
6. **铺旁白**：按上面的稿子念，语速放慢
7. **片尾**：三条卖点 ＋ LOGO/学校
