## 二、今天真正的收获：一个"不可能现象"揪出的 bug

### 2.1 起疑点

重写仿真台后，四个场景跑出来：

```
A 1kHz 方波 : SF=976  S2=2929  S3=4882
B 1kHz 正弦 : SF=976  S2=2929  S3=4882   ← 和方波一字不差?!
```

**方波和正弦的频谱不可能完全一样。** 这只有两个可能：信号没进去，或者输入被改形了。

### 2.2 根因

`src/self_fft_1024.v` 采集行写的是：

```verilog
din <= {ad_cap, 24'd0};          // ← 旧写法
```

而蝶形运算和找峰全程按 **有符号（补码）** 读 `dout[31:16]`。
AD9280 输出的是 **偏移二进制**（中点 128）——所以这个写法**等价于把 ad_cap 当"有符号 8 位"用**：

| ad_cap（原始码） | 想要的 | 旧写法读回来 | 后果 |
|---|---|---|---|
| 128（中点） | 0 | **−32768** | 满量程负 ⇒ 直流分量爆炸 |
| 228 | +100 | −7168 | 跨过 128 处出现**断崖** |
| 28 | −100 | +7168 | — |

于是一个 29~227 的**正弦被断崖劈成锯齿**，**凭空长出 3 次、5 次谐波**——
这正是 S2/S3 看起来"总有东西"的原因。
而**方波是 28/228，恰好映射成 ±28，不跨断崖**，所以它一直"看着很对"。

### 2.3 为什么前四轮验证全都没抓到

因为 **SK-024 那轮验证只用了方波**。
"数值与模型逐字一致"这个结论，是在一个**错误的输入映射**上得到的。
教训一句话：**"仿真通过"只在"激励和现场一样"时才等于"硬件正确"。**

### 2.4 修复（2 处，都很小）

```verilog
// 1) 偏移二进制 -> 补码 (异或 0x80 = 减 128 mod 256)：128->0, 228->+100, 28->-100
din <= {(ad_cap ^ 8'h80), 24'd0};

// 2) 找峰显式跳过 bin0（直流不是频率分量，也是防残余偏置把 SF 顶成 0Hz 的兜底）
if (cur_bin >= 10'd1 && cur_bin <= 10'd511) ...
```

**对照**：IP 通路 `fft_demo.v` 一直是 `$signed({8'd0,m_q}) - 16'sd128`，**本来就是对的**。
两条通路对同一个 ADC 字节的解释曾经不一致——这正是"两条通路边跑边对照"的价值。

## 三、三峰判据：现在的行为（可直接对外讲）

改动：**最小间隔 `GAP = 4 bin`（=主瓣宽度 195Hz）+ 幅度门限 `≥ 主峰/8`（−18dB）**，
三趟扫描逐级选峰，不满足门限就报 `0000000`（= 没有有效峰）。

| 输入 | 输出 | 说明 |
|---|---|---|
| 1kHz 方波 | `SF=976` / `S2=2929` / `S3=4882` | 基波 + 3 次 + 5 次谐波，**是真峰** |
| 1kHz 正弦 | `SF=976` / `S2=0` / `S3=0` | 单峰，**无假峰**（修复前是 976/2929/4882）|
| 双音 相距 2 bin | `S2=S3=0` | 物理上分不开，**诚实报单峰** |
| 双音 相距 80 bin | `SF=976` / `S2=4882` / `S3=0` | 确有两个真峰时，能分开 |

> 旧的 `S2=0001025`（bin21，与基波同主瓣）**已不再出现**。
> 协议升至 **v1.16**（帧格式不变，仅语义收紧，上位机不用改解析）。

## 四、怎么复跑（回归证据）

```bash
cd sim/fft_check
bash run_fft_check.sh
```

输出末尾会直接打一行总结果：

```
RESULT: PASS=4  FAIL=0
*** 全部通过 ***
```

- `gen_tables.py` 生成四张整数查表激励（**整数个周期，无泄漏，期望值纯算术推出**）
- `tb_self_fft.v` 内嵌 PASS/FAIL 自动判读 + 激励样点自证 + top6 谱线诊断
- 采用 `DECIM=1` 实例化，仿真快 1000 倍（DECIM 只影响"采满 1024 点要多久"，不参与 FFT 数学）
- 环境变量在 `xenv.sh`（**PATH 必须写 `/d/...`，写 `D:/...` 会被 MSYS 切碎**）
