| 任意频率   | `0x85`           | 小端 4B Hz；**1Hz ~ 12.5MHz**（超限自动钳制）；32 位 NCO@50MHz → 分辨率 **0.0116Hz** | 方波 1k/5k/37.5k/100k/1M 逐字精确；正弦 1k/100k 精确 | ~~12.5MHz 是数字上限，~~模拟链可用带宽另计 |
| 四档预设   | `0x81` / 板载 key0 | 100k / 200k / 500k / 1M 循环；LED0~3 指示档位                               | 已上板                                       | —                           |
| 双音输出   | `0x87`           | 第二频率（小端 4B）；f1+f2 叠加；发任意 `0x85` 即回单音                                 | 1k+1.1k 在频谱上可分辨（1001+1099）                | 双音下 `F=` 因拍频晃动属正常           |
| 波形选择   | `0x88`           | `0`正弦 / `1`方波 / `2`三角                                                | 三种全部验证                                    | 无锯齿/脉冲/噪声                   |

| 输出链路   | —                | 256 点查表 + 相位截断；AD9708 8bit/125MSPS                                   | —                                         | 幅度=模块电位器（物理旋钮），无数字幅度控制      |

### 1.2 采集与触发

| 功能     | 规格                                                                          | 实测/验证   | 边界                        |
| ------ | --------------------------------------------------------------------------- | ------- | ------------------------- |
| ADC 采集 | AD9280 8bit；采集流 **25MSPS**；波形帧/FFT 用 50kHz 抽取                               | 全链验证    | 芯片输入 0~2V（模块把 ±5V 衰减进来）   |
| 波形帧上传  | `0x83`；**1024 点 × 8bit**；帧总长 **1030B ≈ 22.4ms**@460800；时间轴 20µs/点（20.5ms 窗） | 上位机画图正常 | **≤20kHz** 看波形（≥25kHz 混叠） |
| 触发     | `0x89`：`0`自由 / `1`上升沿 / `2`下降沿；**帧首点 = 触发点**                                | 已上板     | 无预触发、电平不可调（→ 优化 #5 / #13） |

### 1.3 实时测量（~10ms 一周期，3 行约 45B，链路占用 ~10%）

| 字段         | 规格                                                                               | 实测                                                     | 边界/备注                                       |
| ---------- | -------------------------------------------------------------------------------- | ------------------------------------------------------ | ------------------------------------------- |
| `F=` 频率    | 双模式自动切换：高频 **10ms 闸门**（f=N×100）；低频 **32 周期测周法**（f=1.6e9/N）                       | **100Hz~1MHz 误差<1%（实测≈逐字精确）**                          | 实测上限 1MHz；下限 100Hz（→ #16）                   |
| `V=` 峰峰值   | 毫伏，0~~9999 饱和；`mV = 计数 × KN ÷ 1024`；默认 KN=8000（7.8125mV/LSB，0~~2V 假设）；`0x8C` 可标定 | 1kHz 方波=正弦=**1078mV**（差 0%）；10k/20k = 1085/1093（±1.4%） | **绝对精度待万用表标定**；标定值断电不保留（→ #12）              |
| `D=` 占空比   | `xxx.x%`（0.0~100.0）                                                              | 方波 49.9~50.4%                                          | 正弦受模拟链温漂（46.8~50），预热 3 分钟、以方波为基准（SK-028）    |
| `W=` 脉宽    | 高电平时间，5 位 µs（0~99999）                                                            | 1k→500µs / 100k→6µs                                    | 100kHz 6→5µs 取整待修（→ #6）；20kHz 31µs 疑点（→ #7） |
| `TY=` 波形识别 | `0`方波 / `1`正弦 / `2`三角 / `3`其他；占比法（方波≈100%/正弦≈46%/三角≈25%）；刷新 ~82ms                | 已上板                                                    | 可信闸门：>25kHz 或帧内频率变化>1.5% → 强制 3             |
| 抗噪         | 四层：2 拍确认 / 施密特迟滞 / 5 点中值 / **3 窗中值**                                             | —                                                      | 代价：D/W/V 突变后 **2 帧≈20ms 滞后**（已知、非 bug）      |

### 1.4 频谱分析（同板双通路）

| 项        | IP 通路（厂商 xfft）                            | 自研通路（手写 Radix-2 DIF）                                    |
| -------- | ----------------------------------------- | ------------------------------------------------------- |
| 点数 / 采样率 | 4096 @50kHz                               | 1024 @50kHz                                             |
| 分辨率 Δf   | **12.207Hz**                              | **48.828Hz**                                            |
| 窗        | Hann                                      | Hann（`USE_HANN` 一键回退）                                   |
| 输出       | `S=` 主峰 + `A=` 次峰（门限：≥主峰 1/8 且 >2bin）     | `SF=/S2=/S3=` 三峰（门限：≥4bin 间隔 + ≥主峰/8；跳过 DC）；`0x8A` 按需触发 |
| 实测       | 1k→**1001**；双音→1001+1099；方波→1001+**3003** | 1k 方波→**976/2978/4980**；正弦→976/0/0                      |
| 精度       | 半 bin ≈ ±6Hz（量化）                          | ✅ **插值已实现 + 板测通过（10/01）**：实测 1kHz **999**、方波 **999/2998/4997**（真值 1000/3000/5000）；整数 bin 逐字不变（`USE_INTERP` 可回退） |
| 代价       | LUT 1771 / FF 2550 / DSP 9                | **502 LUT / 346 FF / 7 DSP**；运算 ≈0.92ms/帧               |
| 互证       | 两条通路互为对照（同信号 → 两种实现 → 同一读数）               | 同上                                                      |
| 频率换算     | 32 位（位宽修复后，全 bin 扫描 0 错）                  | 同左（全 bin 0 错）                                           |

- **扫频** `0x8B`：**1kHz→20kHz，步进 100Hz，每步 50ms，约 9.5s/圈**；LED 全亮；扫频中 TY 可能常显 3（预期）。
- 边界：**0~25kHz**（fs=50kHz 设计使然）；自研两音间距 <195Hz 时诚实报 0；~~无幅度谱~~ → **0x8E 谱帧已实现（v1.18，待板测）**。
