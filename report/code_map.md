## 一、按技能包索引
### SK-019/017 正弦 ×2 与四层抗噪
- 现象：正弦 F 近似 ×2/乱跳；D 与 PC 矛盾
- 根因：模拟毛刺造成"假穿越"与时段被切碎
- 解法与代码：
  - 「连续 2 拍确认」：`freq_meter.v:85`（hi2_ok = hi_now_q && hi_prev_q）
  - 施密特判高：`freq_meter.v:93`（hi_set = ad_med_r >= next_h）
  - 5 点中值打拍：`freq_meter.v:161`（ad_med_r <= c8_hi）
- 复测：正弦 1k/100k → F 精确、D≈49.6~50.0

### SK-021 触发采集（单写者 + 归零）
- 现象：触发帧首点不是边沿
- 根因：环形缓存直接读=触发前历史；且状态机写指针=多驱动 DRC
- 解法与代码：`wave_frame.v:92`（fill_rst 声明）→ `:121`（每拍清）→ `:52`（采集块执行归零）
- 复测：上升沿→帧前 6 点全高；下降沿→全低（check_duty）

### SK-022 双峰检测（三连环坑）
- 现象：方波第二峰不出（双音却正常）
- 根因：①主峰晚一拍被存为候选 ②Hann 旁瓣 0.5 顶掉谐波 0.33
- 解法与代码：`fft_demo.v:174`（相隔>2 才降级的级联）、`fft_demo.v:198`（门限 ≥1/8 且相隔>2）
- 复测：方波 1k → S=1001 + A=3003；单音无 A；双音 A=1099

### SK-023 case-default 吞 NBA
- 现象：FSM 永不前进（采集正常）
- 根因：同拍 default 覆盖 st 赋值（last-write-wins）
- 解法与代码：`self_fft_1024.v:155`（S_CAP: ; 空项）
- 复测：0x8A → SF 行出现（核心跑完）

### SK-025 BRAM 2 拍读延迟
- 现象："蝶形对、找峰错"（1k→1367Hz）
- 根因：读地址到取数需 2 拍，找峰未等待
- 解法与代码：`self_fft_1024.v:45`（w1_go 声明）、`:163`（蝶形等待）、`:215-217`（找峰 pk_go 等待）
- 复测：SF=976/S2=1025/S3=2978（与模型逐字一致）

### SK-024 表错/镜像
- 解法与代码：`self_fft_1024.v:220`（正半轴约束 rev10≤511）；旋转因子表 `tw_cos.hex/tw_sin.hex`（1024 行，k=1 非零即对）
- 复测：金标准与硬件同 bin

### SK-026 统计窗口采样率
- 现象：波形识别"怎么调都是 3"
- 根因：逐时钟取样 → 窗口只有 41µs
- 解法与代码：`wave_id.v:18`（tick = dcnt==999 → 50kHz 降采样）、`:76`（abs_d>th3 统计）
- 复测：五场景 TY=1/0/2/3/3

### SK-028/窗口平滑 偶发坏窗
- 现象：V 135↔151 闪烁 + 紧随 D 掉 047
- 根因：单窗被宽毛刺污染 max/min
- 解法与代码：`measure_report.v:48-50`（med16 函数）、`:179`（V 3 窗中值）、`:193-194`（D/W 3 窗中值）
- 复测：100k 方波 V 恒定 135、D=049.9~050.4
