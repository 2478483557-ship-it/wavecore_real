一阶有源低通 · 实测波特图（含直通校准）
============================================================
日期        2026-10-26
被测件      一阶有源低通  R=2.2kΩ  C=4.7nF  NE5532  ±12V
方法        直通校准法（thru 归一化），同真网络分析仪
扫频        DDS 0x85 逐点设频；锁相 0x9A/0x9B 读幅度与相位
频点        19 个，1kHz → 1MHz，每十倍频程 6 点

一、系统自身响应（直通，DUT 拔掉）
------------------------------------------------------------
  1 kHz     +0.000 dB      基准
  10 kHz    -0.005 dB
  100 kHz   +0.006 dB
  464 kHz   -0.004 dB
  1 MHz     -0.034 dB
  => 系统在 1MHz 内平坦度优于 0.04 dB

二、被测件拟合结果（已除掉系统响应）
------------------------------------------------------------
  截止频率   fc = 15370 Hz
  标称值     1/(2πRC) = 15393 Hz
  相对误差   0.15%

  滚降斜率   100k→1M   -19.03 dB/十倍频
             46k→464k  -19.45 dB/十倍频
             32k→316k  -19.35 dB/十倍频
             理论值    -20.00 dB/十倍频

  幅度残差   1k~68k 全部优于 1.2%，最大 2.3%（21.5kHz 处）

三、★ 相位：直通校准验证了延迟归属
------------------------------------------------------------
  校准前（DUT 绝对值拟合）
      Td = 0.33 µs   约 8.3 个 25MSPS 采样点
  校准后（DUT − THRU 拟合）
      Td = 0.04 µs   约 1.1 个采样点

  => 那 0.29 µs 是系统（DAC + AD 驱动 + 采样保持）的传播延迟，
     不是滤波器的。直通校准把它分离出来了。

四、★ 该滤波器是【反相】的
------------------------------------------------------------
  1 kHz 处相位差 = −175°，本质就是 180°。
  一阶【反相】低通：φ(f) = 180° − arctan(f/fc)
  1 kHz 理论 176°，实测 185°，差 9°。

  含义：接的是反相拓扑（如反相输入放大/多路反馈型），
        不是跟随器。幅度特性完全一致，只是相位差 180°。

  对演示无影响（只看幅度）；若答辩被问，可说"反相一阶低通"。

五、量程交界（实测，非仿真）
------------------------------------------------------------
   100 kHz   锁相 736 mV    Vpp 762 mV    一致
   316 kHz   锁相 225 mV    Vpp 326 mV    Vpp 反高 45%，已被噪声撑住
   1 MHz     锁相  82 mV    Vpp 363 mV    Vpp 完全失效
  => 直接测峰峰值在 300 kHz 附近失效，锁相续到 1 MHz
