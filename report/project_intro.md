## 一、标准版（约 400 字，"作品简介"主栏）

**标题：FPGA信号测量与频谱分析系统（WaveCore）**

WaveCore 用一块 AMD Artix-7 XC7A35T（正点原子达芬奇Pro）构建了一套"小型仪器栈"：在同一颗 FPGA 中并行实现**信号发生器**（32 位 NCO，任意频率 1Hz~12.5MHz、双音合成、正弦/方波/三角）、**全参数测量**（频率 100Hz~1MHz 误差<1%、Vpp、占空比、脉宽，含三层数字抗噪）、**频谱分析**（4096 点 FFT 双峰检测，并另装一套**自研 1024 点 RTL FFT** 做"同信号双实现"对比）、**波形上传与触发采集**（上升/下降沿捕获，帧首点即触发点）、**波形自动识别**（正弦/方波/三角/异常自动判别）与**扫频模式**（1kHz→20kHz 循环）。

数据链路统一为 460800-8N1 自定义帧协议，全部结果（测量行/谱峰行/波形帧/识别结果）直连 PC 上位机：可显示实时波形、频谱瀑布图（Spectrogram）与仪表面板，实现"一块板即一台多合一仪器"。

**技术亮点**：①三层数字抗噪（2 拍确认/施密特迟滞/5 点中值滤波）根治正弦假穿越；②自研 1024 点 FFT 仅 502 LUT/7 DSP，读数与 Python 模型逐字一致；③"用错误变体复现硬件数据"的闭环排障方法论，沉淀技能包 38 条。设计已 Flash 固化，上电即用，时序 WNS +2.385ns 全收敛。

## 二、短版（约 130 字）

FPGA信号测量与频谱分析系统（WaveCore）：一块 XC7A35T 集成信号发生器（任意频/双音/三种波形）、全参数测量（频率/Vpp/占空比/脉宽，三层抗噪）、频谱分析（厂商 4096 点 + 自研 1024 点 FFT 对比）、波形上传/触发、波形自动识别与扫频；串口 460800 直连 PC 上位机（波形 + 频谱瀑布图），已 Flash 固化、断电即用。

## 三、创新点（分栏填写）
1. **架构创新**：信号源 + 测量 + 频谱 + 可视化四台仪器在一颗 35T 上并行共跑，体现 FPGA"真并行 + 纳秒确定性 + 可重构"；
2. **算法自研**：手写 Radix-2 DIF FFT（1024 点）与厂商 IP 同板对比，资源约为 IP 裸核的 1/3（LUT），读数与金标准逐字一致；
3. **测量鲁棒性**：三层数字抗噪 + 可信闸门（测不准时输出"其他"而非错误结论）；
4. **工程方法论**："数据→假设→变体仿真→上板复现"闭环排障法，7 类典型问题沉淀为 38 条可复用技能包。

"一块 35T，四台仪器；频率、波形、频谱、触发，全部在 PC 上一屏可玩——这就是 FPGA 的并行与确定性带来的底气。"
