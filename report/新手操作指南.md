### 1.1 万一"黑框一闪就关了"（2026-09-30 踩过，已修）

**这不是你点错了，是脚本本身坏了。** 说清楚原因，免得以后再困惑：

旧的 `rebuild_bitstream.bat` 是 **UTF-8 编码 + 中文注释 + LF 换行**。
Windows 的 cmd 读批处理文件用的是**系统代码页（中文系统 = GBK）**，
所以中文注释被"解码"成乱码字节，其中一些正好是 cmd 眼里的**命令分隔符**（`)` `&` `|`）——
结果**命令被劈成两半，最关键的那行启动 Vivado 的语句被吃掉了**。

铁证：那段时间 `rebuild_bitstream.log` **根本不存在**，
说明 Vivado **一次都没被启动过**（11:06 那次综合是图形界面自己跑出来的，跟这个 bat 无关）。

现在已经重写成**纯 ASCII + CRLF**，并且实测能正确拉起 Vivado。

**怎么确认你用的是新版**：双击后窗口里应该出现 `[1/5]` 这一行。
如果什么都没有、窗口直接消失，就把这个文件发我：

```
D:\Verilog_project\wavecore\rebuild_steps.log
```

这个文件是脚本自己的"日记"（带时间戳、记到第几步），
**它是"脚本到底跑没跑"的唯一证据**。

### 5.3 按顺序点这几下（顺序不能乱！）

> ⚠️ **为什么顺序不能乱**：板子**上电默认是 100 kHz 档**，而自研 FFT 的采样率只有 50 kHz，
> 100 kHz 直接混叠，`SF` 永远出不来 976。所以**第一条命令必须是"设 1000 Hz"**。

| 顺序 | 在界面上做什么 | 期望结果 |
|---|---|---|
| ① | 在**「主频」**框里输入 `1000`，点 **「设置主频」** | 板子开始输出 1 kHz |
| ② | **「输出波形」**下拉框选 **正弦**，点 **「应用波形」** | — |
| ③ | 点 **「运行自研FFT」** | 卡片"自研FFT SF/S2/S3"应显示 `976 / 0 / 0` |
| ④ | **「输出波形」**改选 **方波**，点 **「应用波形」** | — |
| ⑤ | 再点 **「运行自研FFT」** | 应显示 `976 / 2978 / 4980`（±1 bin，即 ±49Hz） |

> 注意：「预设档位」那排按钮只有 100k / 200k / 500k / 1M，**没有 1 kHz**，
> 所以 1 kHz **必须手输**，这就是要你自己填的原因。

### 5.4 顺便验证电压改成 mV 了

### 5.6 "频谱图上怎么这么多柱子？"—— 三句话看懂（2026-10-01 补）

第一次打开瀑布图/频谱图的人几乎都会问这个。完整版见 `report/demo_package.md` §2.1，这里给最短版：

1. **柱子的格子编号 = bin**。T1 档每格 **48.83Hz**，"bin 20" = 976.6Hz ≈ 1kHz。
2. **一根谱线 = 一片柱子**（中间高、两侧矮）。因为 1kHz 落在**第 20.48 格**、不正好卡在格子里，
   能量会摊到相邻几格 —— **这是正常的，不是杂波。**
3. **只看"哪几片明显高出底噪"**：真峰又高又稳（位置每帧不动），噪声又矮又乱。
   所以"方波三柱" = **三片主瓣**（1k/3k/5kHz），不是"屏幕上只有三根柱子"。

> 同一信号换档位，**只改格子号、不改频率位置**：1kHz 在 T1 是 bin 20、T2 是 82、T3 是 10、T4 是 5。
