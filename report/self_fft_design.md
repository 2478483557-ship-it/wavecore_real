## 1. 为什么做（设计动机）
1. **评分**：创新 30% + 资源 20% 是最高权重；自研算法核 vs 纯 IP 堆功能，是"创新"叙事的硬材料
2. **赛道契合**：初级组考察"逻辑设计/状态机/时序/接口"——自研 FFT 正好全部覆盖
3. **对比演示**：同一串口并排输出 `S=`（Xilinx IP，4096点）与 `SF=`（自研，1024点）→ 一张表讲清"两种实现"
4. **技能沉淀**：旋转因子、DIF 调度、Q15 定标、位反转、单口 RAM 分时调度

## 2. 技术方案
| 项 | 内容 |
|---|---|
| 算法 | 1024 点 Radix-2 **DIF 原地**（输入自然序，输出位反转）|
| 定点 | 16bit，每级 >>1（总增益 1/1024）|
| 调度 | 与 `hw_analysis` 金标准逐拍一致；每蝴蝶 8 拍（读2/算/写2/推进）|
| 旋转因子 | 1024×16 Q1.15 双表（cos / -sin），块 ROM |
| 存储 | `blk_mem_gen_1`（1024×32 单口，无输出寄存器）|
| 触发 | **0x8A 按需运行一次**（默认静默）|
| 验证 | Python 金标准：1kHz 输入 → bin20（理论 20.48）✅ |
| 预期单次耗时 | 约 (1024×1000 + 5120×8 + ~2k) 拍 ≈ **21.4ms** |

## 3. 褒（优点 / 价值）
- ⭐ 创新与资源双评分的**硬素材**（可量化对比表）
- ⭐ 纯 RTL，不依赖厂商 FFT IP，答辩可讲透每个环节
- ⭐ 可关闭设计（0x8A 按需）：**不占演示主链路**
- ⭐ 学习价值高，沉淀多条技能包（SK 相关条目）

## 4.5 干扰机理补充：是不是"布线"导致的？（2026-09-16 讨论）
- **不完全是"某根线"的问题，而是"开关电流 × 电流回路"的系统问题**，可能途径：
  1. **电源/地网络（PDN）**：大逻辑运行瞬间电流突变（di/dt）→ 电源轨压降/地弹 → 通过共用电源耦合进 DA/AD 模拟供电
  2. **布线耦合/串扰**：FPGA 高速翻转的 IO/时钟走线紧邻模拟信号线 → 容性/感性耦合
  3. **去耦不足**：板级去耦电容对高频瞬态"来不及补电"
- **结论**：与"自制IP核"无必然关系（任何大逻辑都一样），但**我们的模块体量大、突发运行**，是典型"噪声源"；同一块板上厂商 IP 的 FFT 若常驻运行，理论上也会贡献类似噪声（只是架构/节流不同）
- **缓解措施（由易到难）**：
  1. ✅ 按需运行 + 默认静默（已做）
  2. 运行时降载：分阶段/降频/门控不用的子模块
  3. 物理层：DA/AD 信号线远离 FPGA 高频区、缩短走线、必要时加屏蔽/磁珠
  4. 板级：加强去耦（手改板子，慎做）
  5. 终验：11 月示波器看电源纹波与耦合路径后定论
- **诚实声明**：目前为"隔离实验证实关联 + 机理推断"，**"噪声耦合"尚待示波器直接测量确认**
