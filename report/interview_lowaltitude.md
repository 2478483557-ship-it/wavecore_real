# 低空通信俱乐部 · 面试准备（2026-09-26）

## 一、低空通信扫盲（1 分钟能复述的版本）
- **低空经济**：300~1000 米以下空域的产业活动——无人机物流、巡检、农业植保、应急救援、eVTOL（城市空中交通）。国家已把它写进战略（2024 年起）。
- **低空通信 = 让飞行器"连得上、管得住、看得见"的通信网络**，大致四类手段：
  1. **网联（蜂窝对空）**：4G/5G/5G-A 基站向天空覆盖（"低空智联网"，运营商在试点）
  2. **直连链路**：无人机遥控/图传（2.4G/5.8G/900M），Mesh 自组网
  3. **通感一体（ISAC）**：同一套基站既通信又当"雷达"感知（发现/跟踪无人机）——**当下最热的方向**
  4. **卫星补充**：北斗短报文/低轨卫星，覆盖无蜂窝区域
- **三大技术挑战**：①高速移动的**多普勒**与快速切换 ②**三维立体覆盖**（地面网是二维的）③干扰与频谱管理、时延与可靠性（适航要求）
- **一句话总结**：低空通信就是"把地面通信网向天空延伸 + 用通信信号顺带做感知"，是通信、信号处理、嵌入式的交叉战场。
