## 五、附：提交表单另外几个字段的建议答案

- **三个关键词描述作品**：
  1. **口袋仪器**（一机集成信号源/测量/频谱/采集）
  2. **自研 FFT**（与厂商 IP 同板对照）
  3. **闭环自测**（不接外部仪器即可全链路验证）
- **创新关键词**（建议 5~8 个，按含金量排序）：
  1. **同板双 FFT 架构**（厂商 4096 点 IP + 自研 1024 点核，同信号交叉验证）
  2. **频谱抛物线插值**（1kHz 从 976Hz 修到 999Hz，误差 2.4%→0.1%）
  3. **可配置时基四档**（12.5k~200kHz 等效采样率，频谱覆盖 6.25k~100kHz）
  4. **Hann 窗根因修复**（矩形窗泄漏 14.7%→0.9%，消除非整数 bin 假峰）
  5. **幅度谱帧 + 瀑布图**（0x8E，512bin/518B/11.2ms，扫频成斜线）
  6. **无仪器闭环验证**（板内 DDS→DAC→回环→ADC→测量→FFT，全链路自测）
  7. **三层数字抗噪 + 可信闸门**（判不准时报"其他"，宁可不说也不说错）
  8. **工程方法论沉淀**（38 条可复用技能包 + 12 个完整排障案例）
