# 波形识别的频率上限：实测与改进方案

> 2026-10-21。起因：评审指出"波形识别到不了 25kHz 就开始不准"。
> 结论：**比这更糟 —— 正弦/三角在 5kHz 就失效，可靠上限约 1.5kHz。**

---

## 一、实测数据（上板，DDS 回环）

判据：每点 `TY` 上报值（0=方波 1=正弦 2=三角 3=其他），三档各自扫频。

| 频率 | 每周期样点数 | 正弦 | 方波 | 三角 | 判定 |
|---|---|---|---|---|---|
| 1 kHz | 50.0 | 1 ✓ | 0 ✓ | 2 ✓ | 全对 |
| 3 kHz | 16.7 | 1 ✓ | 0 ✓ | 2 ✓ | 全对 |
| **5 kHz** | **10.0** | **3 ✗** | 0 ✓ | **3 ✗** | 正弦/三角丢失 |
| 8 kHz | 6.2 | **2 ✗** | 0 ✓ | 3 ✗ | 正弦误判成三角 |
| 10 kHz | 5.0 | 3 ✗ | 0 ✓ | 3 ✗ | — |
| 15 kHz | 3.3 | 3 ✗ | 0 ✓ | 3 ✗ | — |
| 20 kHz | 2.5 | **2 ✗** | 0 ✓ | 2 | 乱判 |
| 25 kHz | 2.0 | **0 ✗** | 0 | **0 ✗** | 全错 |

**只有方波撑得住**（因为它的判据值恒为 1.0，与样点数无关）；
**正弦和三角在 5kHz 就崩，8kHz 时正弦被误判成三角。**

---

## 二、根因：不是中值滤波，是「每周期样点太少」

### 判据本身是对的

`wave_id` 的判据是：

```
占空比型统计：|x - mid| > 3/8 × span 的样点占比
  > 0.84         → 方波
  0.40 ~ 0.62    → 正弦
  0.18 ~ 0.38    → 三角
```

理想连续信号的占比：**方波 1.00 / 正弦 0.46 / 三角 0.25** —— 分离得很好。

### 问题在于离散化

采样率固定 **fs = 50kHz**（每 1000 个 50MHz 拍取 1 点），信号频率却可变，
于是「每周期样点数 spp = 50000 / F」随频率变化。

用数值仿真扫遍采样相位、取最坏情况：

| spp | 正弦占比 | 三角占比 | 能否区分 |
|---|---|---|---|
| 2 | 0.07 ~ 1.00 | 0.07 ~ 1.00 | ❌ 完全重叠 |
| 3 | 0.67 ~ 1.00 | 0.67 ~ 1.00 | ❌ 完全重叠 |
| 4 | 0.50 | 0.50 | ❌ 完全相同 |
| **8** | **0.25 ~ 0.50** | **0.25 ~ 0.50** | ❌ **区间完全重叠** |
| 10 | 0.40 ~ 0.60 | 0.20 ~ 0.40 | ⚠️ 边界擦边 |
| 16 | 0.38 ~ 0.50 | 0.25 ~ 0.26 | ⚠️ 正弦下界跌破 0.40 |
| **32** | **0.44 ~ 0.50** | **0.25 ~ 0.26** | ✅ 干净分离 |
| 64 | 0.47 | 0.25 | ✅ |
| 256 | 0.46 | 0.25 | ✅ |

**关键现象：spp=8 时正弦和三角的占比区间完全重合（都是 0.25~0.50）。**
这不是"精度差"，是**信息不足**——每周期只有 8 个点，两种波形采样下来长得一样。

### 换算成频率上限

```
spp = 50000 / F  ≥ 32   →   F ≤ 1562 Hz
```

**所以可靠上限约 1.5kHz**，与实测（1k/3k 对、5k 崩）完全吻合。

### 顺带排除：中值滤波不是元凶

一开始怀疑 3 点中值滤波把正弦峰值削平了。数值对比：

| 频率 | 中值后 | 无中值 |
|---|---|---|
| 正弦 5kHz | 0.399 | 0.400 |
| 正弦 8kHz | 0.479 | 0.479 |

**几乎一样。** 中值滤波对判据影响 < 0.01，可以留着抗噪。

## 三、改进方案（三档，按代价排序）

### 方案 A · 诚实的门限（5 分钟，零风险，但功能变窄）

把上位机的闸门从 `F ≤ 25kHz` 改成按样点数判断：

```python
spp = 50000.0 / max(freq_hz, 1)
ty_ok = (spp >= 32) and f_stable      # 即 F ≤ 1.5kHz
```

**优点**：立刻不再输出错误答案。
**缺点**：识别范围只剩 1.5kHz，评审看着更差。
**建议**：只作为「方案 B 没做完时的保底」。

---

### 方案 B · 自适应抽取（真正的解法，约半天）

**思路**：让抽取比随频率变化，始终保持每周期样点 ≥ 32。

```
decim = 390625 / F        (兼顾 spp≈128 与窗口内 ≥16 个周期)
```

推导（两条约束）：

```
① 形状分辨率   spp = 50e6/(decim·F) ≥ 32   →  decim ≤ 1.5625e6 / F
② 统计样本量   2048·decim·F/50e6 ≥ 8 周期  →  decim ≥ 195312 / F
```

两者之比 8 倍，中间取值有充足余量。

**效果预估**：

| 频率 | 抽取比 | 每周期样点 | 窗口内周期数 |
|---|---|---|---|
| 1 kHz | ~390 | 128 | 16 |
| 5 kHz | 78 | 128 | 16 |
| 10 kHz | 39 | 128 | 16 |
| 25 kHz | 16 | 125 | 16 |
| 100 kHz | 4 | 125 | 16 |
| 200 kHz | 2 | 125 | 16 |
| 1 MHz | 1 | 50 | **0.1 ← 不够** |

**上限约 200kHz**（受"窗口内至少 8 个周期"约束）。
比现在的 1.5kHz 提升 **130 倍**。

**改动面**：
- `wave_id.v`：`dcnt == 999` 改成可变阈值，输入一个 `decim_cfg`
- `board_top.v`：把已测的 `F` 送进 `wave_id`，算出 `decim_cfg`
- 需要一个除法器，或**查表**（按 F 分 8~16 档，最省）

**风险**：中等。新逻辑要重新综合 + 上板复验三档波形 × 多频点。
**但不改动其他通路**，F/V/D 完全不受影响。

---

### 方案 C · 用谐波比判定（最强，但工作量最大）

方波三次谐波 = 1/3，三角 = 1/9，正弦无谐波。
**这个判据与幅度无关、与频率无关**，理论上是波形识别最稳的方法。

但需要看到 3F 处的谱线，所以采样率必须 > 6F。
配合方案 B 的自适应抽取后，可直接用自研 FFT 的 `S2`（二次峰）来判。

**缺点**：要改 FFT 路径或加一个专门的谐波检测器，工作量最大。

---

## 四、推荐路线

```
今天（半天）   方案 B：自适应抽取，目标 200kHz
              ↓ 综合 + 上板扫频复验
              如果时间不够 → 先上方案 A 保底，别输出错答案
可选           方案 C：把谐波比作为第二判据，与形状判据投票
```

**为什么不建议只做方案 A**：它只是把错误藏起来，识别范围反而从"名义 25kHz"
缩到"实际 1.5kHz"，文档里会很难写。方案 B 才是把能力真的做上去。

---

## 五、对文档/答辩的影响

当前技术文档若写了"波形识别 100Hz~1MHz"或"25kHz 内可靠"，**必须改**。
在方案 B 落地前，如实写：

> 波形识别在每周期样点 ≥32 时可靠，对应输入频率 ≤1.5kHz；
> 更高频率下系统报"其他"，不给不可信结论。

这比被评委现场测出来强。

# 六、改进实施结果（2026-10-21 上午，已上板验证）

## 6.1 做了什么

给 `wave_id` 增加了 `decim_cfg` 输入，由 `board_top` 按实测频率给出抽取比：

| 实测频率 F | 抽取比 | fs | 每周期样点 |
|---|---|---|---|
| < 763 Hz | 1023 | 48.9 kHz | ≥64 |
| 763 ~ 1526 | 512 | 97.7 kHz | ≥64 |
| 1526 ~ 3052 | 256 | 195 kHz | ≥64 |
| 3052 ~ 6104 | 128 | 391 kHz | ≥64 |
| 6104 ~ 12207 | 64 | 781 kHz | ≥64 |
| 12207 ~ 24414 | 32 | 1.56 MHz | ≥64 |
| ≥ 24414 | **32（下限）** | 1.56 MHz | 随 F 下降 |

**下限锁在 32 是实测结论**，不是理论推导：

```
decim=32 (fs=1.56MHz)  24kHz → 稳定 5/5 ✓
decim=16 (fs=3.13MHz)  26kHz → 全错 0/5 ✗   ← 注意 spp 反而更高（120）
```

**样点更多反而更差**，说明限制不在样点数，而在采样率本身
（怀疑 DDS 是 50MHz 台阶输出，采得越快台阶/毛刺占比越大）。这条待外部信号源验证。

## 6.2 实测结果

| 频率 | 正弦 | 方波 | 三角 | 连测 |
|---|---|---|---|---|
| 1 kHz | ✓ | ✓ | ✓ | 3/3 |
| 5 kHz | ✓ | ✓ | ✓ | 3/3 |
| 10 kHz | ✓ | ✓ | ✓ | 3/3 |
| 15 kHz | ✓ | ✓ | ✓ | 3/3 |
| 20 kHz | ✓ | ✓ | ✓ | 3/3 |
| 22 kHz | ✓ | ✓ | ✓ | 3/3 |
| 25 kHz | ✓ | ✓ | ✓ | 3/3 |
| 30 kHz 以上 | 3 | 3 | 3 | 报"其他"，不给错答案 |

**1k~25kHz 三档全对且可重复。**

## 6.3 前后对比

| 指标 | 改前 | 改后 |
|---|---|---|
| 三档全对上限 | **3 kHz** | **25 kHz** |
| 5~25kHz 的表现 | **输出错误答案**（正弦被判成三角） | 全部正确 |
| 25kHz 以上 | 输出错误答案 | 报"其他"（诚实） |
| 资源 | LUT 7397 | LUT 7480（+83） |
| WNS | +1.215 ns | +1.128 ns |

**提升 8 倍，且 25kHz 这个对外宣称的数字现在是真实的。**

## 6.4 为什么没能更高

30kHz 起失效，且与抽取比无关（25k 和 30k 都用 decim=32）。
`spp` 在两者分别是 62.5 和 52，都远高于所需的 32 —— **不是样点数问题**。

**下一步验证（需要外部信号源）**：
把信号发生器直接接 ADC 输入，测 30k/50k/100k。
- 若外部源正常 → 限制来自板上 DDS 回环（台阶/毛刺），可考虑加一级低通或改用平均抽取
- 若外部源也失效 → 限制在 ADC 采样或 `wave_id` 内部，需要开 ILA 抓 `ad_cap` 波形

## 6.5 顺带发现

`wave_id` 原设计里相 0（测幅）用 `s0` 原始点统计 min/max，
相 1（计数）用 `med` 中值后数据比较。两者源不一致，在低样点时会让
`span` 与 `hi_cnt` 略不同步。当前 spp≥52 影响很小，未改动。
