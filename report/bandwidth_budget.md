# 串口带宽与刷新率量化 · 2026-09-21

> 用途：回答评委"460800 够吗/刷新率多少"；报告"通信设计"一节。

## 一、物理层
- 460800-8N1 → 有效速率 ≈ **46,080 B/s（45 kB/s）**（每字节 10 bit）
- 帧上限：一字节 21.7µs

## 二、帧长与耗时表
| 帧 | 长度 | 传输耗时 | 发送节拍 | 带宽占用 |
|---|---|---|---|---|
| 测量帧（F+D/W+TY 三行）| 45 B | 0.98 ms | **高频档 ~99 Hz（≈10.1ms/帧，恒定）；低频档 ≈10ms+32/f（1kHz≈42ms→~24Hz；100Hz≈330ms→~3Hz）** | 高频档 ≈ 4.5 kB/s ≈ 10%；低频档 ≈ 1 kB/s ≈ 2% |
| S 行 / A 行 | 11 B each | 0.24 ms | ~1 Hz（每 FFT 帧）| 可忽略 |
| SF/S2/S3 三行 | 42 B | 0.91 ms | 按需（0x8A）| 一次一发 |
| 波形帧（0x83）| 1022 B | 22.2 ms | 按需 | 峰值占用 ~100%（22ms 内）|

## 三、刷新率能力
| 场景 | 刷新率（理论）| 实际设计值 | 说明 |
|---|---|---|---|
| 测量参数面板 | 由测量窗决定 | **~99 Hz（≥10kHz，恒定）／低频=1/(10ms+32/f)** | 高于显示需要 |
| Spectrogram（取 S/A）| 46 kB/s ÷ 22B ≈ **2000 Hz 上限** | **10~100 Hz**（接收端自由取帧）| 带宽绰绰有余 |
| 波形图（1022B）| 45 帧/s 上限 | 按需刷新（1~5 Hz 舒适）| 22ms/帧 |
| FFT 谱峰行 | ~90 Hz 上限 | ~1 Hz（FFT 帧率）| — |

## 四、设计权衡（为什么不上传整段频谱）
- 若每帧上传 4096 点幅度（1B/点）：4096B ≈ 89ms/帧 → 仅 11 帧/s，且占满带宽
- 我们的选择：**上行"谱峰行（S/A/SF/S2/S3）+ 按需波形帧"** —— 信息量足够（显示与自动化），把带宽留给了测量节拍
- 结论话术：**"带宽预算 = 主动设计"**：常态 10% 占用、按需突发、无阻塞

## 五、Kimi 提问对照
- "460800 传 4096 点频谱+波形要多久？" → 一节表列明细：单帧 89ms（全谱）/ 22ms（1024 波形）/ 0.98ms（测量行）
- "瀑布图刷新率？" → 接收端取 10~100 Hz（取 S/A 时上限 ~2000 Hz）→ 足够流畅
