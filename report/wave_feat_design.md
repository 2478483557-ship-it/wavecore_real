## 一、要算什么（与 `train_wave_nn.py` 的 `feats()` 逐条对齐）

设 1024 个补码 8bit 样点 `x[n] ∈ [-128,127]`，`pk = max|x|`：

| 特征 | 公式 | 说明 |
|---|---|---|
| f0 | `cnt(x>0) / 1024` | 占空比 |
| f1 | `\|mean(x)\| / pk` | 归一化均值 |
| f2 | `min(kurt/3, 1)`，`kurt = m4/m2²` | 峭度 |
| f3 | `min(rms/pk, 1)` | 波峰因数 |
| f4 | `min(mean\|dx\|/pk·2, 1)` | 归一化斜率 |
| f5 | `过零次数 / 1024` | 过零率 |

**输出 Q15（0..32767）**，直接喂 `wave_nn` 的 f0..f5。

---

## 二、★ 关键设计决策

### 1. 只有 `pk` 需要除 → 累加器全在 x 域做
不要"先把每个样点除以 pk 再统计"（那是 1024 次除法）。
先把 6 个累加器加起来，**最后统一除 pk**，一帧只除几次。

### 2. f2 里的 pk 会**自然约掉**
```
m4 = (1/N)Σ(x/pk)⁴ = Σx⁴/(N·pk⁴)
m2 = (1/N)Σ(x/pk)² = Σx²/(N·pk²)
kurt = m4/m2² = Σx⁴·N / (Σx²)²      <- pk 消掉了
```
所以 f2 **一次 pk 都不用除**。

### 3. 累加器位宽（按最大值定，别拍脑袋）
| 累加器 | 最大值 | 位宽 |
|---|---|---|
| `cnt(x>0)` | 1024 | 11 |
| `Σx` | 1024×128 = 131072 | signed 21 |
| `Σ\|x\|` | 131072 | 19 |
| `Σx²` | 1024×16384 = 16.8e6 | 27 |
| **`Σx⁴`** | 1024×2.68e8 = **2.7e11** | **40** ← 最宽 |
| `Σ\|Δx\|` | 1024×255 ≈ 2.6e5 | 20 |
| 过零数 | 1024 | 11 |

⚠️ `pk` 要 **9 位**：`|-128| = 128` 溢出 8 位。

## 三、5 次除法 + 1 次开方（共用一个单元）

除法的**被除数/除数与预期商**：

| 步骤 | 被除数 | 除数 | 得到 |
|---|---|---|---|
| 1 | `\|Σx\| << 5` | `pk` | `f1` (≤ 32767) |
| 2 | `Σ\|Δx\| << 6` | `pk` | `f4`（再夹到 32767） |
| 3 | — | — | **开方** `√(Σx²)` |
| 4 | `√(Σx²) << 10` | `pk` | `f3` (≤ 32767) |
| 5 | `Σx⁴` | `Σx²` | `d4 ≈ 1.6e4` |
| 6 | `d4 << 25` | `3·Σx²` | `f2`（再夹到 32767） |

- 第 6 步的被除数 `d4<<25 ≈ 5.4e11` → **40 位够用** ✓
- 除数最大 `3·Σx² ≈ 5.1e7` → **26 位够用** ✓
- 故 **一个 40位/26位 顺序除法器（40 拍）** 覆盖全部 5 次

**开方**：32 位 → 16 位，标准"移位-相减"法，16 拍：
```
r=0; b=0x8000; q=0
重复16次: t=(r<<2)|(x>>30); x<<=2
          if t >= ((b<<2)|1) then r=t-((b<<2)|1); q|=b
          b>>=1
```

**总开销**：5×40 + 16 ≈ **216 拍**。一帧 100 万拍（20ms）→ 可忽略。

## 四、状态机

```
S_IDLE --start--> S_ACC --采满1024--> S_DIV --6步串行--> S_FIN --> S_DONE
```
- `S_ACC`：每个 `din_valid` 更新 7 个累加器
- `S_DIV`：`step` 计数 0..5，每次启动一次除法（或开方），完成后把商存入 `d1..d5`
- `S_FIN`：按上表算 6 个特征，写 `f0..f5`，拉 `done`

## 五、验证方案（照搬 wave_nn 的成功做法）

1. Python 生成测试向量：对每类波形算出**定点特征**与**定点推理结果**，写成 hex
2. tb 喂样点 → 读 `f0..f5` → 与 Python 的定点特征**逐个比对**（容差 ±1 LSB）
3. 再接 `wave_nn`，验证**端到端分类**与 Python 一致

⚠️ **教训（wave_nn 踩过的）**：累加器与权重**必须声明 signed**——
Verilog 规定"有一个操作数无符号则整体按无符号算"，负值会被当成巨大正数。
那一个 bug 就让 64 条向量错 48 条。

## 六、为什么不做"更省资源的特征版本"

试过两轮，**都失败**（详见 2026-10-16 日志）：
- 换掉 `crest`（要开方）→ 量化准确率从 **94% 掉到 75.8%**
- 隐层权重再平衡 → 掉到 **25%**

**结论**：这套特征值这个代价。开方单元 16 拍、一帧一次，**比降 18 个点准确率划算得多**。
