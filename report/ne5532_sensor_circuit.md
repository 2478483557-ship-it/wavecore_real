# NE5532 + 双电源：传感器放大电路接线单

> 适用条件：**NE5532（或 NE5532P / NE5532N）+ 有 ±5V 或 ±12V 双电源**
> 这是最好配的一种组合：带宽够（10MHz）、双电源输出天然以 0V 为中心、不用做虚拟地。

---

## ★★★ 先看这一条：NE5532 的 4 脚是负电源，不是地

```
        ┌────∪────┐
   OUTA ┤1       8├ V+        ← 正电源（+5V 或 +12V）
   INA− ┤2       7├ OUTB
   INA+ ┤3       6├ INB−
  V−/GND┤4       5├ INB+      ← ★ 4 脚是 V−（负电源 −5V/−12V）
        └─────────┘
```

**4 脚接 −5V 或 −12V，不是接 GND。**

单电源运放（LM358）的 4 脚才是 GND。NE5532 是双电源运放，
把 4 脚接地，运放直接不工作，严重时发烫。

---

## 一、供电怎么选（**这里有个坑，先看完再动手**）

目标摆幅是 **±3.5V 峰值**（70% 量程，约 96 码）。NE5532 的实际输出能力：

| 供电 | 输出摆幅（典型） | 够不够 ±3.5V | 对 AD 是否安全 |
|---|---|---|---|
| **±5V** | 约 **±2.5~3V** | **✗ 不够** | ✓ 安全 |
| **±12V** | 约 ±10V | ✓ 充裕 | **✗ 会打坏 AD9280** |
| ±15V | 约 ±13V | ✓ | ✗ 更危险 |

**两个都不完美：**

- **±5V 不够用** —— NE5532 不是轨到轨运放，输出比电源轨低 2V 左右。
  ±5V 供电时最大只能摆到 ±3V，达不到 3.5V。
- **±12V 会超压** —— 输出能到 ±10V，而 AD9280 输入上限是 ±5V。

### 两种可行做法

**做法 A（推荐）：用 ±12V + 钳位二极管**

正常工作时靠增益控制把输出压在 3.5V 以内，钳位只在异常时兜底。
动态范围最大，电路只是多两只二极管。

**做法 B：用 ±5V，接受 ±3V 摆幅**

够约 82 码（满量程 255 的 32%）。锁相演示完全能用，只是动态范围小一些。
好处是绝对安全，不用二极管。

> **不要用 ±5V 硬凑 3.5V** —— 运放会削顶，削顶的信号锁相也救不回来
> （这一点在 `lockin_snr_curve.md` 第八节已经实测过：满幅加噪时误差 21.9%）。

**所以：如果手上能有 ±12V，走做法 A；只有 ±5V 就走做法 B，别硬调。**

## 二、主电路：同相放大，G = 101

```
                        ┌──── Rf 100kΩ ────┐
                        │                  │
   传感器 ── C1 ────┬───┤3 (INA+)      (INA−)2 ──┬──── 1 (OUTA)
                    │   │                       │
                   R1  │                        Rg 1kΩ
                   10kΩ│                         │
                    │   │                        │
                   GND  │                       GND
                        │
                    （4 脚接 −5V，8 脚接 +5V）
                        │
        1 (OUTA) ── 100Ω ──┬── C2 10µF ── AD 模块 IN
                          │
                     [钳位二极管，见第四节]
```

### 元件清单

| 位号 | 值 | 说明 |
|---|---|---|
| **C1** | **1µF** | 输入隔直。挡掉传感器自带的直流偏置（MAX9814 有 1.25V） |
| **R1** | **10kΩ** | 同相端到地，给输入偏置电流一条路。**不接会漂** |
| **Rf** | **100kΩ** | 反馈电阻，决定增益 |
| **Rg** | **1kΩ** | 反馈电阻，决定增益 |
| **C2** | **10µF** | 输出隔直。双电源时理论上可省，但留着更安全 |
| **R2** | **100Ω** | 输出限流，保护 AD 输入 |
| 电源去耦 | 100nF × 2 | 一只并在 +5V 到 GND，一只并在 −5V 到 GND，**紧挨运放引脚** |

### 增益怎么算

**G = 1 + Rf / Rg = 1 + 100k / 1k = 101 倍**

| 目标增益 | Rf | Rg | 适用场景 |
|---|---|---|---|
| 21× | 20kΩ | 1kΩ | 大声说话、近距离 |
| **51×** | **51kΩ** | **1kΩ** | 说话（推荐起点） |
| 101× | 100kΩ | 1kΩ | 安静房间 |
| 201× | 200kΩ | 1kΩ | 极弱信号（压电片轻敲） |

> NE5532 GBW = 10MHz，G=101 时带宽还有 **100kHz**，做 1kHz 锁相和敲击频谱都够。

### 想现场可调？

把 Rf 换成 **100kΩ 电位器 + 1kΩ 固定电阻串联**：

```
       ┌── 100k 电位器 ──┐
   OUTA┤                 ├──── INA−
       └── 1kΩ ──────────┘
```

增益在 2~101 之间连续可调，现场转着找最合适的档。

## 三、传感器侧怎么接

### 情况 A：MAX9814 麦克风模块

```
MAX9814 OUT ── C1 1µF ── 运放 IN+
MAX9814 GND ───────────── 公共地
MAX9814 VDD ───────────── 3.3V 或 5V（按模块标注）
```

**注意**：MAX9814 自带 AGC 和 40/50/60dB 增益，接运放时把它的增益设到**最低档**
（GAIN 引脚接 GND），否则两级叠加会饱和。

### 情况 B：27mm 压电片（两线）

```
压电片 正极 ──┬── 1MΩ ── GND      ← 这个电阻必须有！给偏置电流通路
              │
              └── C1 1µF ── 运放 IN+
压电片 负极 ───────────── 公共地
```

压电片内阻很高，没有 1MΩ 下拉会一直漂到电源轨。

### 情况 C：801S 振动模块

```
801S AO ── C1 1µF ── 运放 IN+
801S GND ──────────── 公共地
801S VCC ──────────── 5V
```

801S 模块板载调理，输出幅度约 20~100mV（轻敲/持续振动）。

## 四、输出保护（做法 A 必做，做法 B 可省）

运放在 ±12V 下输出能到 ±10V，而 AD9280 输入上限是 ±5V（模块输入端）。
**超压会永久损坏 ADC。**

```
                 +5V
                  │
                 ─┴─  D1（1N5819 或 BAT54S）
                 ─┬─
                  │
运放输出 ──100Ω──┼──── AD 模块 IN
                  │
                 ─┴─  D2（反接）
                 ─┬─
                  │
                 −5V
```

两只二极管分别钳在 +5V 和 −5V，超过就导通泄放。

**用 ±5V（做法 B）的话，输出最大约 ±3V，本来就进不了超压区，可以省掉这一节。**

## 五、接线检查清单

上电前逐条打勾：

```
□ NE5532 的 4 脚接的是 −5V，不是 GND          ← 最容易错
□ 8 脚接 +5V
□ 电源去耦电容（100nF×2）已经紧挨引脚焊好
□ 传感器 GND、运放 GND（这里指电源中点）、AD 模块 GND 三者连通
□ 原来的 DA→AD 回环飞线已经拔掉
□ 运放 IN+ 上有 10kΩ 到地（或压电片有 1MΩ 到地）
```

上电后量三个电压：

```
□ 运放 8 脚对地 = +5V（±0.3V）
□ 运放 4 脚对地 = −5V（±0.3V）
□ 运放输出（1 脚）对地 = 0V 左右（±50mV）   ← 没有信号时应该是 0V
□ AD 输入端对地 = 0V 左右（C2 之后）
```

**最后一条如果量到 2.5V**，说明隔直电容 C2 没接上或者已经击穿。

## 六、上电顺序

1. 关掉所有电源
2. 接好所有连线（特别是地）
3. 先上运放的 ±5V
4. 量一下输出是不是 0V
5. 再上传感器的电
6. 最后让声源开始响

**不要带电插拔传感器或运放。**

## 七、调不出来怎么查

| 现象 | 最可能的原因 |
|---|---|
| 运放发烫 | **4 脚接了 GND**（应该接 −5V） |
| 输出一直是 +4V 或 −4V | 输入没隔直，或者 IN+ 上的 10k 没接 |
| 输出一直是 0V，怎么动都不变 | 运放没供电 / ±5V 反了 / C1 开路 |
| 输出有信号但很小 | 增益不够，加大 Rf |
| 输出削顶（波形变方） | 增益太大或输入信号太大，减小 Rf |
| Vpp 读数乱跳 | 信号太弱被环境噪声盖住，先贴近声源 |
| 频率读数是噪声 | 同理，信噪比不够 |
| 锁相读 0 | 锁相没开（先发 `0x9A=1`）/ 参考与信号频率不符 |

## 八、推荐的调试顺序（别跳步）

```
第 1 步  只焊供电，不接信号
         量 8 脚 = +5V，4 脚 = −5V，输出 = 0V
         ↓ 通过再做下一步

第 2 步  接 Rf/Rg，不接传感器
         IN+ 上用手指碰一下（注入 50Hz 工频干扰）
         输出应该能看到明显波动 —— 说明放大链路通了
         ↓ 通过再做下一步

第 3 步  接传感器，贴近声源
         跑 host\run_demo_sensor.bat，看第 1 步的三个读数
         ↓ 频率对上了，说明整条链路通了

第 4 步  拉远做衰减演示
```

**第 2 步很重要**：用手指碰 IN+ 是最快的"运放活没活"判断法。
碰了没反应，说明前面两步有问题，别往下走。
