## 你要交付
1. **串口通信层**：能连板卡(115200-8N1)、收发按协议、异常重连
2. **实时测量面板（v1 核心）**：大字显示 F(Hz) 与 Vpp，并排显示 S/A 谱峰；历史曲线(可选)
3. **控制区**：频率输入框 → 发 0x85；按钮"开双音" → 发 0x87；档位按钮 → 0x81
4. 数据存 CSV（加分）
5. UI 用 tkinter / PyQt 均可，先跑通串口逻辑再看界面
