## 你要交付
1. **串口通信层**：能连板卡(**460800**-8N1)、收发按协议、异常重连
2. **实时测量面板（v1 核心）**：大字显示 F(Hz) 与 Vpp，并排显示 S/A 谱峰；**解析 D=/W= 行显示"占空比/脉宽"**（正则 `^D=(\d{3}\.\d)% W=(\d{5})us$`）；历史曲线(可选)
3. **控制区**：频率输入框 → 发 0x85；按钮"开双音" → 0x87；档位按钮 → 0x81；**波形下拉(正弦/方波/三角) → 0x88；触发下拉(自由/上升/下降) → 0x89**
4. **波形面板（必做）**：按钮"请求波形"→ 发 0x83 → 收 1024 点 → 画波形图
   （入门可先弹窗画一次，进阶做定时自动刷新/嵌入画布）
5. 数据存 CSV（加分）
6. UI 用 tkinter / PyQt 均可，先跑通串口逻辑再看界面
