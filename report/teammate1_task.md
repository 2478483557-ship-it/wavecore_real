### 协议库已就绪的四个新函数（直接 import 用）

```python
from protocol import (command_set_timebase, timebase_fs_hz,
                      command_request_spectrum, parse_spectrum_frame)

ser.write(command_set_timebase(3))     # 0=T1 50k(默认) / 1=T2 12.5k / 2=T3 100k / 3=T4 200k
fs = timebase_fs_hz(tier)              # 给频谱 x 轴标刻度用
ser.write(command_request_spectrum())  # 请求一帧 518 字节幅度谱
bins = parse_spectrum_frame(frame)     # -> 512 个幅度码(bytes)；非法帧返回 None（丢帧重来）
```

### ⚠️ 三个必须知道的坑

1. **`0x8A / 0x8B / 0x8D / 0x8E` 都是静默命令（无 ACK / 无回执行）** ——
   发完**不会回任何东西**，"没反应"是**正常**的；只能靠后续数据判断生效。
2. **谱帧本身不带 fs** —— 上位机必须**自己记住当前档位**，否则频率轴会标错
   （`timebase_fs_hz(tier)` 就是干这个的，别在代码里写死 50000）。
3. **幅度码是对数压缩的相对量（不是 mV）** —— 判读只看"哪几个 bin 明显高出底噪"，
   不要试图换算成电压。底噪约 15，主峰 200+。
