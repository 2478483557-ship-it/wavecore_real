## 你要交付
1. **串口通信层**：能连板卡(**460800**-8N1)、收发按协议、异常重连
2. **实时测量面板（v1 核心）**：大字显示 F(Hz) 与 Vpp，并排显示 S/A 谱峰；**解析 D=/W= 行显示"占空比/脉宽"**（正则 `^D=(\d{3}\.\d)% W=(\d{5})us$`）；历史曲线(可选)
3. **控制区**：频率输入框 → 发 0x85；按钮"开双音" → 0x87；档位按钮 → 0x81；**波形下拉(正弦/方波/三角) → 0x88；触发下拉(自由/上升/下降) → 0x89**
4. **波形面板（必做）**：按钮"请求波形"→ 发 0x83 → 收 1024 点 → 画波形图
   （入门可先弹窗画一次，进阶做定时自动刷新/嵌入画布）
5. 数据存 CSV（加分）
6. UI 用 tkinter / PyQt 均可，先跑通串口逻辑再看界面

## v1.1 增补（2026-09-27）：演示版界面需求

> 背景：要拍 3~5 分钟演示视频（脚本见 `report/demo_video_script.md`），上位机必须"一眼看得到"下面这些。
> **协议零新增**——全部是现成数据流，只是界面要显示出来。

| 优先级 | 需求 | 数据源 | 验收标准 |
|---|---|---|---|
| P0 | 大字显示 F / Vpp / 占空比 / 脉宽 | `F=` `V=` `D=` `W=` 行 | 1kHz 方波：F≈1000、D≈050.0%、W≈00500us |
| P0 | **波形类型 TY 字段**（中文映射：0=方波 1=正弦 2=三角 3=其他）| `TY=` 行（v1.14 新增）| 发 0x88 切三种波形，界面同步变化 |
| P0 | 波形面板（1024 点）+ "请求波形"按钮 | `0x83`（`5A A5 83 00 01 00 84`）| 1kHz 画出约 20 个周期 |
| P0 | 控制区：频率输入框 / 波形下拉 / 触发下拉 | `0x85` / `0x88` / `0x89` | 输入 37500 → 显示 F=37500 |
| P1 | **自研 FFT 三行**（SF / S2 / S3）| 发 `0x8A` 后的 `SF=` `S2=` `S3=` | 1kHz 方波：976 / 1025 / 2978 |
| P1 | **扫频按钮 + 瀑布图** | `0x8B` 开始/停止 + `S=`/`A=` 或 `F=` | 扫频时出现自左下到右上的斜线（无瀑布图则用 F= 折线兜底）|
| P2 | 双音按钮 | `0x87` | 出现 S=1001 + A=1099 两峰 |
| P2 | 一键全屏 / 数据存 CSV | — | 录屏方便；CSV 供报告截图 |

**注意事项**
- 扫频期间 `TY=` 常显 3、LED 全亮**属预期**（频率步进被视为"不稳"），界面不要报错
- 频率输入上限 12.5MHz，超限板卡会自动钳制
- 双音时 `F=` 行晃动是拍频物理现象，不是解析 bug
- 瀑布图若来不及：用 `F=` 随时间画折线（扫频时是一条上升斜坡），同样好看且零 FPGA 改动
