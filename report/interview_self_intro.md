# 面试自我介绍稿（FPGA 首项目版，2026-09-26）

> 定位：大二、FPGA 初学者、**第一个项目**——用"诚实 + 数字 + 方法论"打动人，而不是装专家。

## 一、30 秒版（开场用）
> "我大二，电子信息工程专业。这是我第一次正式做 FPGA——项目叫 WaveCore，**基于 XC7A35T 的多功能信号测量与频谱分析系统**，参加了今年的嵌入式芯片与系统设计竞赛。
> 一个月里我完成了从信号发生、参数测量、频谱分析到串口协议、触发采集、Flash 固化的全套功能，**全部上板验证并固化**；指标上，频率测量 100Hz~1MHz 误差小于 1%，自研 1024 点 FFT 只占 502 个 LUT，时序余量 +1.835ns。
> 我想用这个项目说明两件事：**我能从零学会一门技术**，以及**我做东西是讲证据的**。"

## 二、2 分钟版（被"介绍一下"时）
1. **为什么做**：课程学完数电模电基础后想找一个"够真"的练手项目，正好赶上竞赛，选择"仪器类"方向——信号源+测量+频谱一机集成。
2. **我做了什么**：一颗 35T 上跑四台"仪器"：DDS 信号源（任意频/双音/三种波形）、全参数测量（频率/占空比/脉宽/Vpp，含四层数字抗噪）、双 FFT（厂商 IP + 自研核对比）、波形上传与触发采集；还有串口协议（19 条命令）、波形自动识别、扫频和 Flash 固化。
3. **最有价值的困难（挑 1~2 个讲）**：
   - 正弦频率"翻倍/乱跳"：**定位到是毛刺假穿越**，做了三层数字抗噪（2 拍确认/施密特/中值滤波），最后读数与电脑抓图逐字一致；
   - 自研 FFT "稳定但错误"：用"**读前一地址**"的假设仿真，在两组频率上**逐字复现**硬件错误读数，锁定 BRAM 2 拍读延迟；
   - 触发器波形起点不对：改成"**触发瞬间指针归零 + 单写者规则**"。
4. **方法**：我总结成一句话——"**数据不对先建模，用错误变体复现硬件，命中即根因**"。全过程沉淀了 38 条可复用技能包与全部文档。
5. **我知道自己的边界**：傅里叶的数学我还在补（已在学 3Blue1Brown），现场手写 Verilog 每天在练——**不懂的我会直说，但我有路径弄懂它**。

## 三、被追问的标准答法
| 问题 | 答法 |
|---|---|
| "为什么用 FPGA 不用 STM32？" | 并行（同时跑测量/FFT/识别/串口）、确定性（20ns 时间分辨、触发到拍）、可重构（逻辑按题定制）|
| "自研 FFT vs 厂商 IP？" | 同口径每点 LUT 0.49 vs 0.43 同量级；总量 502 vs 1771（约 1/3）；代价是串行慢（0.92ms），但我们按需运行够用 |
| **"代码是你自己写的吗？"（关键）** | "RTL 由我在 AI 辅助下完成——我负责需求定义、方案选择、验证和**全部上板调试**；每个模块的取舍和踩坑修复我都能讲清（技能包就是我整理的）。这也正是大赛要求的'大模型协作能力'。" **不撒谎、不心虚** |
| "遇到最大的困难？" | 讲 FFT 四连坑或正弦抗噪（上面第 3 点），强调"验证闭环"而非"我多牛" |
| "如果现在手写个状态机？" | 口头讲四态 UART TX 思路（IDLE→START→DATA→STOP + 每 DIV 拍换位）；手写时先起框架再填动作 |
| "你还能做什么？" | "给我两周和文档，我能把任何 FPGA 项目拆成模块认下来——这个项目就是证明。" |
