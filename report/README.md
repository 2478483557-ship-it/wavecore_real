# report/ — 设计报告 + 大模型协作记录

本目录是评分的"文档质量与可复现性"（15%）和"大模型协作与技能包"（15%）的阵地，**从第一天开始积累**，不要最后赶工。

## 文件清单

| 文件 | 内容 | 更新节奏 |
|------|------|----------|
| `design_report_outline.md` | 设计报告框架（按 5 项评分组织） | 每周同步进展 |
| `llm_collab_log.md` | 大模型协作记录（提示词/回答/自我纠错轨迹） | 每次用 AI 记一条 |
| `progress_log.md` | （建议）每周开发进度 + 踩坑流水 | 每周日写 |

> 建议再加一个 `progress_log.md` 记录每周做了什么、下周做什么 —— 这是 git 提交历史之外最好的"投入证据"。
