# WaveCore 状态板（2026-09-20 重写，权威版）

> 本文是**唯一权威**的"已完成 / 待办 / 可选 / 不做"清单；历史规划存档见 `upgrade_plan.md`（9/3）。
> 资源现状：**LUT 95.5% / FF 91.4% / BRAM 18% / DSP 26.7%，WNS +1.28ns** —— 余量薄，新增功能必须先评估或先"减肥"。

## A. ✅ 已完成并上板验证（勿重复做）

| 板块 | 内容 |
|---|---|
| 信号源 | 预设 4 档(0x81) ／ 任意频率 0x85 ／ 双音 0x87 ／ 波形 0x88(正弦/方波/三角) |
| 测量套件 | 频率(100Hz~1MHz<1%) ／ Vpp ／ 占空比 ／ 脉宽；**三层抗噪+窗口级平滑**（样点→事件→窗口） |
| 频谱分析 | 厂商 4096 点 FFT 双峰 S/A（含谐波 A≈3×f）／ **自研 1024 点 FFT 三峰 SF/S2/S3** ＋资源对比表 |
| 采集与触发 | 波形上传 0x83 ／ 触发 0x89（自由/上升/下降，帧首点=触发点） |
| 智能识别 | **波形自动识别 TY=0/1/2/3**（含可信闸门） |
| 扫频 | **0x8B 扫频**（1k→20k / 100Hz步 / 50ms，循环） |
| 通信 | 串口 460800-8N1 ／ 协议 **v1.15**（§6 全帧速查表）／ F1 转发口（uart_mirror，备用） |
| 工程保障 | **Flash 固化**（断电自启，flash_guide.md＋SK-027）／ 技能包 **28 条** ／ 资源对比表 ／ 报告章节初稿（engineering_challenges）／ 作品简介定稿／ 温漂案例（SK-028） |
