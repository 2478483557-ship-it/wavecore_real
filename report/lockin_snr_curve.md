## 一、结论先行

**在 −18.8 dB（信号功率只有噪声的 1/76）时，直接测量偏 1225%，锁相仍以 3.3% 的误差给出幅度。**

这是本作品最强的一组数字。演示时按这个顺序讲：

1. 先给评委看**直接测量**：噪声一开，Vpp 从 608mV 跳到 4396mV（偏 6 倍），读数完全不可信；
2. 再切**锁相**：同一信号，601mV，误差 1.2%；
3. 最后亮这张表——**误差不是"稍微好一点"，是跨越两个数量级**。

## 三、SNR 是怎么算的

```python
sig_lsb  = 基准峰值码 / 2^att              # att 每加 1，信号减半
nz_rms   = (127 >> (8-level)) / 2 / √3     # LFSR 取高 8 位，近似均匀分布
SNR_dB   = 20·log10(sig_lsb / nz_rms)
```

- `att` 是 `0x99` 的第 2 字节，取值 0~7，对应右移 0~7 位；
- `level` 是第 1 字节，1~8 档，满档时噪声幅度约 ±127 LSB；
- 基准峰值码 = 4868mV ÷ 2 ÷ 36.33 ≈ 67 LSB。

## 四、为什么能做到

| 机制 | 作用 |
|---|---|
| 正交相干解调 | 只有与参考**同频同相**的分量能在积分中累加，噪声因随机相位自我抵消 |
| 整周期积分（32 周期） | 噪声抑制比 ≈ √(2·N·周期数)，理论约 24dB |
| 参考 NCO 用 2 倍 DDS 频率字 | 同频是**结构保证**，不是调出来的；不存在频差导致的慢漂 |
| 复用 FFT 旋转因子 ROM | BRAM 零增量 |

## 五、能力的边界（要主动讲，别等人问）

- **必须有同频参考**。锁相的本质是"知道要找什么频率"。没有参考源时退化为普通测量。
- **积分时间换信噪比**。32 周期 @1kHz = 32ms。频率越低积分越久，
  100Hz 时同样 32 周期要 320ms —— 这是锁相的固有代价。
- **信噪比再低就要加积分周期**。当前 32 周期到 −18.8dB；
  推到 128 周期理论上还能再降 6dB，代价是响应变慢（1kHz 下 128ms）。
- **不适合非周期信号**。噪声、瞬态、调制信号都锁不住。

## 六、和"双实现对照"主线的衔接

这条曲线本身就是一组对照：**同一信号，两条路径给出两个答案，差 1225%**。

答辩时可以这么说：

> "误差 1225% 不是我们测错了，是这个信号在常规方法下本来就测不出来 ——
> 噪声的峰值比信号大 13 倍，峰峰值检测量到的是噪声。
> 锁相之所以能测，是因为它不接受'峰值'，它只接受'和参考同频的那一部分'。"

## 八、2026-10-24 补记：真值算法本身会让锁相"背锅"

### 问题

最初算误差用的是 `真值 = 基准 / 2^att`。按这个算法，−18.8dB 时锁相偏 −5.5%，
像是锁相在大噪声下有系统误差。

**但这个真值是错的。**

信号衰减在 RTL 里是整数右移：

```verilog
wire signed [8:0] sig1 = (shift > 3'd4) ? 9'sd0 : (sig0 >>> shift);
```

base 是 4868mV ≈ 67 码峰值。`67 >> 4 = 4`（截断，实际 4.19）。
所以硬件真实输出是 **4 码 ≈ 290mV**，不是 `4868/16 = 304mV`。

用 304 当分母，会把 4.6% 的截断误差记到锁相头上。

### 改正后的做法

**每个衰减档位单独测一次"无噪声时的读数"，用它当该档位的真值。**

| att | 理论真值<br>(base/2^att) | 实测真值<br>(无噪读数) | 差多少 |
|---:|---:|---:|---:|
| 0 | 4868 | 4868 | 0 |
| 2 | 1217 | 1198 | −1.6% |
| 3 | 609 | 617 | +1.3% |
| 4 | 304 | 290 | **−4.6%** |

### 改正后的数据

| att | 真值 | 开噪后直接测量 | 开噪后锁相 | 锁相误差 |
|---:|---:|---:|---:|---:|
| 0（满幅） | 4868 | 5050 | 3803 | **−21.9%** |
| 2 | 1198 | 4214 | 1137 | −5.1% |
| 3 | 617 | 3778 | 582 | −5.7% |
| 4（−18.8dB） | 290 | 3487 | 288 | **−0.8%** |

**−18.8dB 下锁相误差从 −5.5% 修正到 −0.8%。** 之前那 5% 是我们自己的真值算错，
不是锁相的问题。

### 副产品：一个必须知道的限制

**满幅信号加噪声时，锁相也会偏 −21.9%。**

原因不是锁相失效，是**削顶**：4868mV 已经接近 ±5V 量程，
噪声叠上去之后正负峰值都被削平。削顶丢的是信息，不是噪声 ——
**锁相能从噪声里捞信号，但捞不回已经削掉的部分。**

演示时的正确做法：信号源先衰减 8 倍（att=3 或 4），再叠噪声。
这也符合真实场景——微弱信号本来就不会顶满量程。
