> 版本: v1.19 | 日期: 2026-10-01(新增 0x8D 时基档位) | 维护: FPGA 队长（改协议请全队确认后升版本号）
> 变更史: v1.18 新增 0x8E 幅度谱帧(9/30) | v1.17 `V=` 改 mV + 0x8C 标定 | ...
> 用途: 达芬奇Pro(FPGA) 通过 USB 串口与 PC 上位机通信（另具 F1 转发口，可外接 STM32 等设备）。
> 现状: 测量行(F=)、谱峰行(S=/A=)、波形帧(0x83)、命令 0x81/0x85/0x87 **全部已上板实现并验证**；0x82/0x84 未实现(不安排)。

> **v1.18 变更（新增上行帧 3：幅度谱帧；上位机可开始做频谱图/瀑布图）**
> 1. 新增下行命令 **`0x8E`**：请求一帧幅度谱 → FPGA 触发一次自研 FFT 采集，
>    完成后回 **518 字节**二进制谱帧：`5A A5 | 02 | 02 00 | 512B | SUM`（详见 §2.9）。
> 2. 512 字节 = bin 0..511 的幅度（8bit 对数压缩，步进约 0.38dB，动态范围约 96dB），
>    覆盖 0~25kHz；帧耗时约 11.2ms，可 10~20 帧/s 连续请求。
> 3. 用途：频谱柱状图 + **瀑布图**（扫频时出现一条斜线）。
> 4. 对旧功能零影响：不请求就不发；测量/波形/自研FFT 行行为不变。
>
> **v1.17 变更（⚠️ 文本行有破坏性改动，上位机必须跟着改）**
> 1. **`V=` 字段从 3 位 ADC 计数(LSB) 改为 4 位毫伏(mV)**：
>    旧 `F=0100000Hz V=134` → 新 `F=0100000Hz V=1047`。
>    测量行总长 19 → **20 字节**（整帧 45 → **46 字节**）。
> 2. 新增下行命令 **`0x8C` 电压标定**（写 KN = 每 LSB 多少 mV ×1024）。
>    上电默认 `KN=8000` → 7.8125 mV/LSB（按 AD9280 0~2V 量程）；
>    **这是假设值，必须用万用表实测标定后改**，见 §2.8。
> 3. Python 解析正则：`rb"F=(\d{7})Hz V=(\d{3})"` → `rb"F=(\d{7})Hz V=(\d{4})"`，
>    字段名建议 `vpp_lsb` → `vpp_mv`（单位变了，名字不改会静默按错单位算）。
>
> **v1.16 变更（帧格式不变，仅语义收紧；上位机无需改解析）**
> 1. 自研 FFT 的 `S2=/S3=` 现在是**物理上分离**的谱线（最小间隔 ≥4bin + 幅度 ≥主峰/8），
>    不满足报 `0000000`；旧的"同主瓣相邻 bin"假峰（如 1025）不再出现。详见 §2.3。
> 2. 自研 FFT 输入映射修正（偏移二进制→补码），正弦/方波的谐波结构才正确。
> 3. **原始波形帧(0x83)的样点定义不变**（仍是偏移二进制，中点 128），上位机画图逻辑不用改。

## 2. 上行帧 1：测量结果行（ASCII，已实现 ✅）

FPGA 每约 10ms 主动发一行，**固定宽度、无前导去零**，方便解析：

```
F=0100000Hz V=1047\r\n
```

- 共 20 字节：`F=` + 7 位频率(Hz) + `Hz ` + `V=` + **4 位峰峰值(mV)** + `\r\n`
- **频率原理（09-05 起已升级）**：自动切换——高频用闸门计数、低频用测周法，覆盖 **100Hz~1MHz 误差<1%**
- **Vpp 单位（v1.17 起）**：`V=` 后是 **毫伏(mV)**，0~9999，超出饱和到 9999。
  由 `mV = Vpp_LSB × KN ÷ 1024` 算出（`vpp_mv.v`），`KN` 是 0x8C 可写的标定系数。
  **默认 KN=8000 只是"按 AD9280 0~2V 量程"的假设值**；要拿它当"电压表"用，
  必须按 §2.8 用万用表标定一次。调试时可把 KN 设成 1024，此时 V 就是原始 ADC 计数。
- **行尾**：`\r\n`（09-08 已修复固件漏发 `\n`；解析器建议兼容只带 `\r` 的旧数据）

**Python 解析示例：**

```python
import serial, re
ser = serial.Serial("COM3", 460800, timeout=1)   # v1.8 提速 460800; 换成你的 COM 口
pat = re.compile(rb"F=(\d{7})Hz V=(\d{4})\r\n")  # v1.17: V 是 4 位 mV
while True:
    line = ser.readline()
    m = pat.match(line)
    if m:
        freq_hz = int(m.group(1))   # 例: 1000000
        vpp_mv  = int(m.group(2))   # 例: 1047  -> 1047 mV
        print(f"freq={freq_hz}Hz  vpp={vpp_mv} mV")
```

## 2.2 上行帧 1c：占空比/脉宽行（D= / W=，v1.5 新增）

紧跟在测量行之后（同一测量周期内最多两行）：

```
D=050.0% W=00500us\r\n
```

- `D=` 占空比：高电平时间/周期 ×100%，**固定宽度** `xxx.x`（0.0~100.0）
- `W=` 脉宽（高电平时间）：固定 5 位整数 `us`（0~99999）
- 双音/正弦下 duty 仍有意义（正弦≈50%）；方波测量最直观
- 解析建议：与 F= 行同款正则 `^D=(\d{3}\.\d)% W=(\d{5})us$`

## 2.3 上行帧 1d：自研FFT结果行（SF=/S2=/S3=；v1.12 恢复，v1.13 起三峰）

发 `0x8A` 触发一次，依次回三行：`SF=xxxxxxxHz`（第一峰）、`S2=`（第二峰）、`S3=`（第三峰），分辨率 48.8Hz。

> **【9/28 口径更新（本版替换 9/27 版）】** 自研通路的 S2/S3 已加**最小间隔 + 幅度门限**，
> 假峰问题**已修复**：现在 SF/S2/S3 是**物理上互相分离的三条谱线**。
> 判据：后选的峰必须离已选峰 **≥4 bin（≈195Hz，正好等于主瓣宽度）**，
> 且幅度 **≥ 主峰/8（−18dB）**；不满足就报 `0000000` = "没有有效峰"。并且显式跳过 bin0（直流）。
> - **1kHz 方波**：`SF=0000976`(基波 bin20) / `S2=002978`(3 次谐波 bin61) / `S3=004980`(5 次谐波 bin102)
>   —— Δf = 50000/1024 = 48.828Hz；1000Hz 落在 bin **20.480**（非整数），
>   所以 3kHz→bin61.44、5kHz→bin102.40。**判据留 ±1 bin（±49Hz）容差。**
>   （仿真用整周期激励会得到 bin60/bin100 = 2929/4882，那是仿真的 bin，不是板子的。）
>   —— 就是"基波 + 3/5 次谐波"，可以直接当谐波结构讲。
> - **1kHz 正弦**：`SF=0000976` / `S2=0000000` / `S3=0000000` —— 单峰、无假峰。
> - **两个靠得很近的音（如 1k+1.1k，间距 2 bin < 主瓣 4 bin）**：报 `S2=S3=0`，
>   即诚实回答"本帧分不开"；分辨率边界 = 1024 点 @50kHz ≈ 48.8Hz（主瓣 195Hz）。
> - 旧的 `S2=0001025`（bin21，与基波同主瓣）**已不再出现**。
> 回归用例与期望值见 `sim/fft_check/`（`bash sim/fft_check/run_fft_check.sh`，**五场景**：方波/正弦/双音2bin/双音80bin/**非整数 bin**；
     > 其中"非整数 bin"这一条就是上面这个假峰的回归项 —— 把 `.USE_HANN` 改回 `1'b0` 它会立刻报出 `S2=1171`，即负向对照）。
> **对外表述可以放心写"三条分离谱线（基波 + 谐波）"；但若被追问分辨率极限，
> 仍要说明"两音间距 < 195Hz 时本帧无法分辨"** —— 这是诚实的工程边界，也是加分项。


自研 1024 点 Radix-2 FFT 峰值频率（F4 与 xfft IP 对比用），自动周期上报：

```
SF=0000976Hz\r\n
```

- 分辨率 = 50000/1024 ≈ 48.8Hz；1kHz 输入 → 最近 bin20 ≈ 976Hz（正常量化）
- 与 IP 的 S= 行（4096 点 ≈1001Hz）并排看 = "同信号、两种实现"对比
- **按需运行**：发 `0x8A` 后采一帧并上报一次 SF 行（v1.10 起；此前为自由跑，已改）

## 2.5 上行帧 1b：FFT 谱峰行（S= / A=，已实现，v1.2 起）

FPGA 在**测量行空闲窗口**插入 FFT 谱峰行（不会打断 F= 行）：

```
S=0001001\r\n   主峰频率(Hz, 7位)
A=0001099\r\n   第二峰频率(Hz, 7位)——仅当检测到两个分离峰时出现
```

- S= 与 A= 同格式：7 位 Hz + `\r\n`；A 行跟在 S 行后
- **A 判定门限（09-17 起）**：第二峰幅度 ≥ 主峰 **1/8** 且与主峰相隔 >2 个 bin —— 因此**方波输入时 A≈3×主峰频率（3 次谐波）**也会上报；双音（两峰等高）不受影响
- **等幅双音时 S/A 可能互换**：S=当前最大峰、A=次大峰；两音幅度几乎相等时顺序会随帧抖动（正常物理现象，不是解析 bug）
- 当前 FFT：4096 点 @50kHz 采样，分辨率 12.2Hz；1kHz 单音 → S=1001；双音 1k+1.1k → S=1001 + A=1099；**方波 1kHz → S=1001 + A≈3003**
- **注意**：频率精度受 bin 量化限制（±~6Hz）；双音模式下 F= 行会因拍频晃动，属正常物理现象，频谱用 S/A 看

**Python 解析（与 F= 共用一个 readline 循环）：**

```python
pat_f = re.compile(rb"F=(\d{7})Hz V=(\d{4})\r\n")   # v1.17: V 是 4 位 mV
pat_s = re.compile(rb"[SA]=(\d{7})\r\n")
while True:
    line = ser.readline()
    if pat_f.match(line): ...   # 测量行
    m = pat_s.match(line)
    if m:
        print("谱峰Hz:", int(m.group(1)))
```

## 3. 上行帧 2：波形数据帧（二进制，已实现 v1.3）

**请求命令**：下行 `0x83`（负载保留位，通常填 0x00）→ 例：`5A A5 83 00 01 00 84`
**触发**：先发 0x89 选触发模式（1=上升沿/2=下降沿），再发 0x83；FPGA 等到达标边沿后**写指针归零、采满一整圈 1024 个全新点**才上报 —— **帧首点=触发点**（请求后约 20.5ms 才开始回数据，属正常）
（波形帧内容固定为 50kHz×1024 点，无需参数；负载字节忽略）

**返回帧格式**（请求后约 0.1s 内返回；发送期间测量/谱峰行暂停让路）：

```
┌───────┬───────┬──────┬───────┬───────┬──────────────────────┬──────┐
│ 0x5A  │ 0xA5  │ TYPE │ LEN_H │ LEN_L │  PAYLOAD(LEN 字节)    │ SUM  │
│ 帧头1 │ 帧头2 │ 0x01 │ 0x04  │ 0x00  │  1024 个样点(每点1B)  │ 校验 │
└───────┴───────┴──────┴───────┴───────┴──────────────────────┴──────┘
```

- **帧头**：固定 `0x5A 0xA5`（解析器先搜索这对字节再读后续）
- **TYPE**：`0x01`=波形（其余类型未定义）
- **LEN**：负载字节数（大端）。当前 LEN=0x0400 → 1024 样点
- **校验 SUM**：**帧头除外**所有字节（TYPE+LEN+PAYLOAD）求和取低 8 位
- **样点**：8bit 无符号 ADC 值（直流中心 ~128），采样率 **50kHz**，1024 点 = 20.5ms
  （上位机据此画时间轴：每点 20µs）
- 解析示例：`host/wave_plot_example.py`（先读帧头 LEN 字段自适应长度）
- **注意**：看波形请设 ≤20kHz 频率（≥25kHz 会混叠）

## 5. 解析要点与排错

1. **搜帧头再解**：串口可能中途插入，永远先找 `0x5A 0xA5`，再按 LEN 取负载
2. **校验失败丢帧**：SUM 不对直接丢弃等下一帧，不要硬解
3. **测量行 vs 波形帧混发**：ASCII 行（0x46='F'开头）不会与 0x5A 帧头冲突，上位机分流处理
4. 接收线程建议用 `read()` 读字节流 + 状态机，不要用 `readline()` 收二进制帧

## 2.4a 上行帧 1e：波形识别行（TY=，v1.14）

测量帧第三行（跟在 D=/W= 行之后）：

```
TY=0\r\n    0=方波  1=正弦  2=三角  3=其他(双音/畸变/混叠/不稳)
```

- 原理：统计"近极端(|x-mid| > 0.75×幅度)"占比（理想值：方波≈100% / 正弦≈46% / 三角≈25%）

- **可信闸门**：频率 >25kHz（混叠区）或频率波动 >1.5%（双音/不稳）时，强制显示 3


## 2.7 下行命令 0x8B：扫频模式（v1.15）

```
扫频开始: 5A A5 8B 00 01 01 8D
扫频停止: 5A A5 8B 00 01 00 8C
```

- 参数（固定）：1kHz → 20kHz，步进 100Hz，每步 50ms → 约 9.5s 循环一圈
- 与"瀑布图"演示天然配套：上位机出现一条**斜线**（**已联调通过 2026-10-01**：0x8E 谱帧 + 独立小工具 `host/spectrum_waterfall.py`；主 GUI 正式集成属上位机待办）
- 扫频期间频率经"任意频率"通道设定（LED 全亮属正常）
- ⚠️ **【2026-10-01 实测更正】扫频是持续循环的，设单音频率关不掉它。**
  实测：正在扫频时发 `0x85` 设 1kHz，频率只是被"当次覆盖"，下一步扫频又把它改回去 ——
  0x8E 抓帧当场抓到的是 **2.39kHz 的谐波族**（bin49/147/245），而不是 1kHz。
  **要停扫频，必须发上面的停止帧** `5A A5 8B 00 01 00 8C`；
  凡"看静态谱线"的上位机脚本，都应先发这一帧（`host/spectrum_waterfall.py --sweep-stop` 已内置）。

## 2.8 下行命令 0x8C：Vpp 电压标定（v1.17 新增）

```
原始LSB模式 KN=1024 : 5A A5 8C 00 04 00 04 00 00 94
恢复默认   KN=8000 : 5A A5 8C 00 04 40 1F 00 00 EF
自定义     KN=xxxx : 5A A5 8C 00 04 <KN_L> <KN_H> 00 00 <SUM>
```

- 负载 4 字节：`KN_L KN_H 保留 保留`（KN 为**小端 16 位**，后两字节保留，填 00 即可）
- `KN` = **每 LSB 对应多少 mV × 1024**（Q10 定标，为了不丢 7.8125 这种小数）
- 换算（`src/vpp_mv.v`）：`mV = Vpp_LSB × KN ÷ 1024`，结果饱和到 9999
- **上电默认 KN=8000** → 7.8125 mV/LSB → 满量程 256×7.8125 = **2000 mV**。
  这个值对应 AD9280 常见的 0~2V 输入配置，**属于"出厂假设"，不是实测值**。
- **`KN=1024` 是调试专用值**：1024÷1024 = 1，此时上报的 `V=` 就是**原始 ADC 计数**，
  等于把 v1.16 的老格式"借"回来用 —— 标定第一步就读它。

### 为什么 Vpp 的换算里没有"零点偏置"（重要，别再加回去）

`Vpp` 的定义是 **最大值 − 最小值**，是一个**差分（峰峰值）量**。
信号整体被抬高或压低（直流偏置、AD9280 的 128 中点）时，max 与 min **同时平移**，
相减立刻抵消。所以 Vpp 换算里只有**增益 KN 一个待标定量**。
若硬塞一个"零点偏置"进去减，等于把一个无关的直流分量当误差扣掉，
会把读数**系统性做小** —— 那是引入错误，不是校准。
（将来若要做 Vmax/Vmin/平均值这类**绝对值**显示，那时才需要偏置项，另开模块处理。）

### 标定流程（两点法 → 实际用"一点定标 + 满量程假设"）

```
1) 发 原始LSB 帧:  5A A5 8C 00 04 00 04 00 00 94
   记下上报的 V 值 = 原始计数 N          (例: N=139)
2) 用万用表量出该信号的**真实峰峰值** V_true (mV)   (例: 1200 mV)
3) 算 KN = round(V_true × 1024 / N)      (例: 1200×1024/139 = 8840 = 0x2288)
4) 发 KN 帧:       5A A5 8C 00 04 88 22 00 00 3A
5) 回读校验:       此时 V 应显示 ≈ V_true (例: 139×8840÷1024 = 1199 mV)
```

> **验收口径（写报告用）**：标定后 100Hz~1MHz 全频段，同幅度信号读数一致（波动 <5%），
> 与万用表差值 <10%。**注意 DA 输出幅度会随频率轻微变化，这是模拟链路的真实特性，不是测量错误。**

> ⚠️ **标定值不落 Flash**：复位/重新上电后回到默认 KN=8000。固化固件时若改了默认值，
> 请同步改 `src/cmd_decoder.v` 里的 `KN_DEF`。
- **注意**：扫频时 TY 行可能常显 3（步进频率被视为"不稳"；高频段波形畸变）——属预期，演示扫频看瀑布图斜线即可（`run_waterfall_sweep.bat`）
## 2.9 上行帧 3：幅度谱帧（二进制，v1.18 新增）

**请求命令**：下行 `0x8E`（空负载）→ 例：`5A A5 8E 00 00 8E`
（FPGA 先等自研 FFT 空闲，再触发一次采集（约 22ms），完成后发送谱帧；请求到收到约 35ms。）

**返回帧格式**：

```
┌───────┬───────┬──────┬───────┬───────┬────────────────────────┬──────┐
│ 0x5A  │ 0xA5  │ 0x02 │ 0x02  │ 0x00  │  512 字节（bin0 ~ 511） │ SUM  │
└───────┴───────┴──────┴───────┴───────┴────────────────────────┴──────┘
```

- **512 字节 = 频率 bin 0~511 的幅度**（自研 1024 点 FFT，fs=50kHz，Δf=48.83Hz，
  即覆盖 **0~25kHz**；实数 FFT 共轭对称，上半轴不重复发）。
- **幅度为 8bit 对数压缩**：`y = (b<<4) | frac4`，b = 最高有效位位置（每倍频程 16 级，
  步进约 0.38dB，动态范围约 96dB）；y=0 表示无信号。
  近似还原（看相对结构用）：`mag ≈ 2^(y>>4) × (1 + (y & 15)/16)`。
- **频率轴**：`f_k = k × fs/1024`（fs 随当前时基档位，见 §2.10；**默认 T1 → 48.83Hz/bin**）。
- **SUM** = `0x02 + 0x02 + 0x00 + 512 个数据字节` 求和取低 8 位。
- **参考读数**（1kHz 方波，预期）：bin20/61/102 三根谱线，压缩码约 **209/183/173**（±3）；
  1kHz 正弦：bin20/21 两根（约 205/204），其余接近 0。
- **使用建议**：10~20 帧/s 连续请求（帧长 518B×10bit ÷ 460800 ≈ 11.2ms，链路占用 <25%）；
  配合扫频（0x8B）连续请求即可画出**瀑布图**（斜线）。
- **解析提示**：先搜帧头 `5A A5 02 02 00`，按 LEN=0x0200 取 512 字节后校验 SUM；
  SUM 不对丢帧重来（与波形帧同款容错）。

## 2.10 下行命令 0x8D：时基档位（v1.19 新增）

```
T1  50kHz (默认) : 5A A5 8D 00 01 00 8E
T2  12.5kHz      : 5A A5 8D 00 01 01 8F
T3  100kHz       : 5A A5 8D 00 01 02 90
```

- 负载 1 字节：`0`=T1 / `1`=T2 / `2`=T3（其它值按 T1 处理）
- 作用：改变**波形帧 / 自研 FFT / IP FFT** 三条通路的抽取比，即等效采样率 fs（`fs = 50MHz / decim`，见 `src/timebase.v`）：

| 档位 | decim | fs | 波形帧窗长 | 自研 FFT Δf | IP FFT 窗长 | 频谱覆盖 |
|---|---|---|---|---|---|---|
| **T1（默认）** | 1000 | 50 kHz | 20.5 ms | 48.8 Hz | 82 ms | 0~25 kHz |
| **T2** | 4000 | 12.5 kHz | 81.9 ms | **12.2 Hz** | 327 ms | 0~6.25 kHz |
| **T3** | 500 | 100 kHz | 10.2 ms | 97.7 Hz | 41 ms | 0~50 kHz |

- **所有频谱读数自动跟随 fs**（`S=`/`A=`/`SF=`/`S2=`/`S3=`）—— 换算只用 `fs_hz`，全库不再有字面量 `50000`。
- ⚠️ **`F=`（freq_meter）不受影响**：它吃 25MSPS 原始 ADC 流，与时基无关。
- ⚠️ **0x8E 谱帧的频率轴 = k × fs/1024**，上位机必须知道当前档位
  （`host/spectrum_waterfall.py --timebase N` 会自己记住并按其 fs 标轴）。
- ⚠️ **上电/复位回到 T1**；切档后测量行有 2 帧滞后（3 窗中值，非 bug）。
- **验收判据**：① 不切档时与加时基之前**逐位相同**；② **任何档位下** 1kHz 信号的自研 `SF` 都应报 **≈1000**
  （fs 变、bin 也变，但换算跟随）；③ T2 下 3k/5k 谐波仍在覆盖内（≤6.25kHz）。

- **TY 可信闸门（9/20）**：频率 >25kHz（混叠区）或**帧内**频率变化 >1.5%（双音/不稳）→ 强制显示 3

  - **代价（9/30 实测澄清）**：3 窗中值意味着**突变后有 2 帧（约 20ms）滞后**——
    改波形(0x88)/改频率(0x85) 之后，V/D/W 要过两帧才收敛；复位后**前两帧 V/D/W 显示 0**（历史槽为空）。
    这是抗噪换来的**已知代价，不是 bug**，已在 `sim/mv_check/tb_report_mv.v` 场景 S0 显式断言。
  - **改 KN(0x8C) 不受此滞后影响**：`mV` 是对 `v_s` 与 `cal_kn` 的纯组合换算，命令一落地就变。
