## 1. 物理层约定

| 项目 | 值 |
|---|---|
| 接口 | 板载 USB 转串口（CH340）→ 电脑虚拟串口 COMx |
| 波特率 | **115200** |
| 格式 | **8 数据位，无校验，1 停止位（8N1）** |
| FPGA 管脚 | TX = D17（FPGA→电脑）；RX = E14（电脑→FPGA，M5 起用） |
| 电平 | LVCMOS33（板上已转换 USB 电平） |

> 电脑端：设备管理器→端口 找 "USB Serial Port(COMx)"，用 pyserial 打开。

## 2. 上行帧 1：测量结果行（ASCII，已实现 ✅）

FPGA 每约 10ms 主动发一行，**固定宽度、无前导去零**，方便解析：

```
F=0100000Hz V=134\r\n
```

- 共 19 字节：`F=` + 7 位频率(Hz) + `Hz ` + `V=` + 3 位峰峰值 + `\r\n`
- 频率 = 10ms 闸门内上过零次数 ×100 Hz；误差 ±100Hz（0.01%~0.1%）

**Python 解析示例：**

```python
import serial, re
ser = serial.Serial("COM3", 115200, timeout=1)   # 换成你的 COM 口
pat = re.compile(rb"F=(\d{7})Hz V=(\d{3})\r\n")
while True:
    line = ser.readline()
    m = pat.match(line)
    if m:
        freq_hz = int(m.group(1))   # 例: 1000000
        vpp     = int(m.group(2))   # 例: 134
        print(f"freq={freq_hz}Hz  vpp={vpp}")
```

## 3. 上行帧 2：波形数据帧（二进制，设计稿，M5 实现）

波形无法用 ASCII 行传（数据量大），用**二进制帧**：

```
┌────────┬────────┬──────┬────────┬──────────┬──────────────────────┬────────┐
│ 0x5A   │ 0xA5   │ TYPE │ LEN_H  │ LEN_L    │  PAYLOAD(LEN 字节)    │ SUM    │
│ 帧头1  │ 帧头2  │ 1字节 │ 1字节  │ 1字节    │  负载                 │ 校验   │
└────────┴────────┴──────┴────────┴──────────┴──────────────────────┴────────┘
```

- **帧头**：固定 `0x5A 0xA5`（解析器先搜索这对字节再读后续）
- **TYPE**：`0x01`=波形；`0x02`=频谱(预留)；`0x80`以上=命令应答(预留)
- **LEN**：负载字节数（大端：高字节在前）
- **校验 SUM**：**帧头除外**所有字节（TYPE+LEN+PAYLOAD）求和，取低 8 位
- **波形负载结构（TYPE=0x01）**：
  - `FS_CODE` 1 字节：采样率代号（`0`=50MHz 全速，`1`=1/10 降采样 5MHz，`2`=1/100 500kHz，`3`=1/1000 50kHz——低频测量用）
  - 之后 **1024 个波形样点**，每点 1 字节（0~255，中心 128）
  - 每样点时间 = 1/(50MHz/降采样比) → 上位机据此画时间轴

> 波形帧只在收到「请求波形」命令后发送一次（约 1024B @115200 ≈ 90ms），避免持续刷屏。

## 4. 下行命令帧（电脑 → FPGA，M5 实现）

结构同上（帧头 0x5A 0xA5），TYPE 用：

| TYPE | 功能 | 负载 |
|---|---|---|
| 0x81 | 切换频率档位 | 1B: 0~3（对应 100k/200k/500k/1M） |
| 0x82 | 请求测量行 | 空（收到后 FPGA 主动发一行测量） |
| 0x83 | 请求波形 | 1B: FS_CODE（见上） |
| 0x84 | 连续测量开关 | 1B: 0=停, 1=开(默认开) |

**Python 发送示例：**

```python
def send_cmd(t, payload=b""):
    body = bytes([t]) + len(payload).to_bytes(2,"big") + payload
    s = sum(body) & 0xFF
    ser.write(b"\x5A\xA5" + body + bytes([s]))
```

## 5. 解析要点与排错

1. **搜帧头再解**：串口可能中途插入，永远先找 `0x5A 0xA5`，再按 LEN 取负载
2. **校验失败丢帧**：SUM 不对直接丢弃等下一帧，不要硬解
3. **测量行 vs 波形帧混发**：ASCII 行（0x46='F'开头）不会与 0x5A 帧头冲突，上位机分流处理
4. 接收线程建议用 `read()` 读字节流 + 状态机，不要用 `readline()` 收二进制帧
