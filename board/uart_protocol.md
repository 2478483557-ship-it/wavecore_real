## 2. 上行帧 1：测量结果行（ASCII，已实现 ✅）

FPGA 每约 10ms 主动发一行，**固定宽度、无前导去零**，方便解析：

```
F=0100000Hz V=134\r\n
```

- 共 19 字节：`F=` + 7 位频率(Hz) + `Hz ` + `V=` + 3 位峰峰值 + `\r\n`
- **频率原理（09-05 起已升级）**：自动切换——高频用闸门计数、低频用测周法，覆盖 **100Hz~1MHz 误差<1%**
- **Vpp 单位**：`V=` 后是 **ADC 原始计数差(LSB, 0~255)**，不是电压；要显示伏特需换算参数(找队长)，界面建议标 `Vpp:133 LSB`
- **行尾**：`\r\n`（09-08 已修复固件漏发 `\n`；解析器建议兼容只带 `\r` 的旧数据）

**Python 解析示例：**

```python
import serial, re
ser = serial.Serial("COM3", 115200, timeout=1)   # 换成你的 COM 口
pat = re.compile(rb"F=(\d{7})Hz V=(\d{3})\r\n")
while True:
    line = ser.readline()
    m = pat.match(line)
    if m:
        freq_hz = int(m.group(1))   # 例: 1000000
        vpp     = int(m.group(2))   # 例: 134
        print(f"freq={freq_hz}Hz  vpp={vpp}")
```

## 2.5 上行帧 1b：FFT 谱峰行（S= / A=，已实现，v1.2 起）

FPGA 在**测量行空闲窗口**插入 FFT 谱峰行（不会打断 F= 行）：

```
S=0001001\r\n   主峰频率(Hz, 7位)
A=0001099\r\n   第二峰频率(Hz, 7位)——仅当检测到两个分离峰时出现
```

- S= 与 A= 同格式：7 位 Hz + `\r\n`；A 行跟在 S 行后
- 当前 FFT：4096 点 @50kHz 采样，分辨率 12.2Hz；1kHz 单音 → S=1001；双音 1k+1.1k → S=1001 + A=1099
- **注意**：频率精度受 bin 量化限制（±~6Hz）；双音模式下 F= 行会因拍频晃动，属正常物理现象，频谱用 S/A 看

**Python 解析（与 F= 共用一个 readline 循环）：**

```python
pat_f = re.compile(rb"F=(\d{7})Hz V=(\d{3})\r\n")
pat_s = re.compile(rb"[SA]=(\d{7})\r\n")
while True:
    line = ser.readline()
    if pat_f.match(line): ...   # 测量行
    m = pat_s.match(line)
    if m:
        print("谱峰Hz:", int(m.group(1)))
```

## 3. 上行帧 2：波形数据帧（二进制，已实现 v1.3）

**请求命令**：下行 `0x83`（负载保留位，通常填 0x00）→ 例：`5A A5 83 00 01 00 84`
（波形帧内容固定为 50kHz×1024 点，无需参数；负载字节忽略）

**返回帧格式**（请求后约 0.1s 内返回；发送期间测量/谱峰行暂停让路）：

```
┌───────┬───────┬──────┬───────┬───────┬──────────────────────┬──────┐
│ 0x5A  │ 0xA5  │ TYPE │ LEN_H │ LEN_L │  PAYLOAD(LEN 字节)    │ SUM  │
│ 帧头1 │ 帧头2 │ 0x01 │ 0x04  │ 0x00  │  1024 个样点(每点1B)  │ 校验 │
└───────┴───────┴──────┴───────┴───────┴──────────────────────┴──────┘
```

- **帧头**：固定 `0x5A 0xA5`（解析器先搜索这对字节再读后续）
- **TYPE**：`0x01`=波形（其余类型未定义）
- **LEN**：负载字节数（大端）。当前 LEN=0x0400 → 1024 样点
- **校验 SUM**：**帧头除外**所有字节（TYPE+LEN+PAYLOAD）求和取低 8 位
- **样点**：8bit 无符号 ADC 值（直流中心 ~128），采样率 **50kHz**，1024 点 = 20.5ms
  （上位机据此画时间轴：每点 20µs）
- 解析示例：`host/wave_plot_example.py`（先读帧头 LEN 字段自适应长度）
- **注意**：看波形请设 ≤20kHz 频率（≥25kHz 会混叠）

## 4. 下行命令帧（电脑 → FPGA，M5 实现）

结构同上（帧头 0x5A 0xA5），TYPE 用：

| TYPE | 功能 | 负载 |
|---|---|---|
| 0x81 | 切换频率档位 | 1B: 0~3（对应 100k/200k/500k/1M） |
| 0x83 | 请求波形 | 保留位(填0x00)；回 50kHz×1024 点波形帧 |
| 0x85 | **任意频率设置**（v1.1 新增） | **4B: Hz（小端序）**；上限 12.5MHz，超限自动钳制。例：37.5kHz → `9C 92 00 00` |
| 0x87 | **第二频率设置/开启双音**（v1.2 新增） | 4B: Hz（小端序，同 0x85）。发后输出 f1+f2 叠加；任何单音设定(0x81/0x85/按键)自动回单音 |
| ~~0x82~~ | ~~请求测量行~~（**未实现，不安排**，测量行本来就持续自动发） | - |
| ~~0x84~~ | ~~连续测量开关~~（**未实现，不安排**） | - |

**0x85 完整示例（设 37.5kHz）：** `5A A5 85 00 04 9C 92 00 00 B7`
（校验：0x85+0+0x04+0x9C+0x92+0+0 = 0xB7）

**0x87 完整示例（设 1.1kHz，配合 0x85 设的 1kHz 做双音分辨演示）：** `5A A5 87 00 04 4C 04 00 00 DB`
（校验：0x87+0+0x04+0x4C+0x04 = 0xDB）

**Python 发送示例：**

```python
def send_cmd(t, payload=b""):
    body = bytes([t]) + len(payload).to_bytes(2,"big") + payload
    s = sum(body) & 0xFF
    ser.write(b"\x5A\xA5" + body + bytes([s]))
```

## 5. 解析要点与排错

1. **搜帧头再解**：串口可能中途插入，永远先找 `0x5A 0xA5`，再按 LEN 取负载
2. **校验失败丢帧**：SUM 不对直接丢弃等下一帧，不要硬解
3. **测量行 vs 波形帧混发**：ASCII 行（0x46='F'开头）不会与 0x5A 帧头冲突，上位机分流处理
4. 接收线程建议用 `read()` 读字节流 + 状态机，不要用 `readline()` 收二进制帧

## 5. F1 转发口（FPGA ↔ STM32，2026-09-15 新增）

**物理**：P1 口 `N13`=FPGA→STM32(RX)、`R14`=STM32→FPGA(TX)，LVCMOS33，115200-8N1

**数据**：STM32 侧收到的**与电脑(CH340)完全相同的字节流**——
- 测量行 `F=`、谱峰行 `S=/A=`、波形帧(0x83 二进制) 全部原样镜像

**ST 侧解析**：与 `host/serial_monitor_starter.py` 完全一致（同一协议）
